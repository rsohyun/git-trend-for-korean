# AgriciDaniel/claude-seo

> 클로드 코드(Claude Code)에서 웹사이트의 검색엔진 최적화(SEO) 상태를 진단하고 개선 계획을 세워 주는 오픈소스 플러그인입니다.

## 개요
웹사이트의 검색 순위 하락이나 AI 검색 엔진 미노출 등의 문제를 해결하기 위한 도구입니다. 기술적 SEO, 콘텐츠 품질, 구조화된 데이터 등을 종합적으로 분석합니다. 사용자는 클로드 코드 환경에서 명령어 하나로 전체 진단을 실행하고 최우선 개선 조치 목록을 받아볼 수 있습니다.

## 주요 기능
- 종합 웹사이트 진단: 여러 전문 분석 에이전트가 동시에 웹사이트를 분석해 우선순위별 개선 계획을 제시합니다.
- 기술적 SEO 검사: 크롤링 가능 여부, 색인 생성, 사이트맵, 페이지 속도 등을 확인합니다.
- 구조화된 데이터 검증: 검색 결과 노출을 돕는 Schema.org 마크업을 찾고 검증하며 작성합니다.
- AI 검색 최적화(GEO): ChatGPT, Perplexity, Gemini 등의 AI 검색 엔진에 사이트가 인용될 가능성을 분석합니다.
- 지역 및 쇼핑몰 SEO: 구글 비즈니스 프로필, 상품 페이지, 다국어 사이트 등을 세부적으로 점검합니다.

# ChromeDevTools/chrome-devtools-mcp

> AI 코딩 에이전트가 크롬 브라우저를 직접 조작하고 검사할 수 있게 해 주는 도구입니다.

## 개요
인공지능 코딩 어시스턴트가 웹 브라우저를 제어하지 못하는 불편을 해결합니다. AI가 실제 웹페이지를 열어 성능을 측정하고, 에러를 확인하고, 화면을 캡처할 수 있도록 돕습니다. 사용자는 AI 에이전트 설정 파일에 서버 정보를 추가한 뒤 대화창에 웹페이지 점검을 요청하여 결과를 받아볼 수 있습니다.

## 주요 기능
- 성능 분석: 크롬 개발자 도구를 이용해 웹페이지 성능 기록을 수집하고 개선점을 찾습니다.
- 브라우저 디버깅: 네트워크 요청을 분석하고, 화면을 캡처하며, 오류 메시지를 확인할 수 있습니다.
- 안정적인 자동화: 크롬 동작을 자동으로 실행하고 결과가 나올 때까지 안정적으로 기다립니다.

## 참고·주의
- 브라우저 내의 모든 데이터와 개인정보가 MCP 클라이언트에 노출될 수 있으므로 주의해야 합니다.
- 구글 크롬 및 테스트용 크롬 브라우저만 공식 지원합니다.

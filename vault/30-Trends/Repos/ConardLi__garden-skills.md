# ConardLi/garden-skills

> 클로드 코드(Claude Code)나 커서(Cursor) 같은 AI 코딩 에이전트에서 바로 쓸 수 있는 웹 디자인, 영상 제작, 지식 검색 등의 기능 모음입니다.

## 개요
인공지능(AI) 코딩 에이전트가 웹 디자인, 모션 그래픽, 이미지 생성 같은 복잡한 작업을 직접 수행할 수 있도록 돕는 도구입니다. 개발자가 에이전트에게 필요한 기능 모음을 연동하면, 에이전트가 지시사항에 맞춰 영상이나 디자인 결과물을 자동으로 만들어 냅니다. 사용자는 프로젝트에 필요한 기능을 내려받아 에이전트에 적용하고 원하는 작업 지시를 내리면 됩니다.

## 주요 기능
- 모션 쇼릴: 짧은 영상이나 제품 소개 애니메이션 코드를 생성합니다.
- 웹 비디오 프레젠테이션: 대본이나 글을 화면 녹화용 웹 프레젠테이션으로 바꿉니다.
- 웹 디자인 엔지니어: 시각적으로 완성도 높은 프론트엔드 디자인을 제작합니다.
- GPT 이미지 2: 인공지능 이미지 생성을 위한 프롬프트를 작성하고 생성합니다.
- 아름다운 아티글: 다양한 소스 기반의 읽기 좋은 기사나 문서를 작성합니다.
- KB 리트리버: 로컬 지식베이스에서 필요한 정보를 검색합니다.

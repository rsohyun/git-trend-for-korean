# D4Vinci/Scrapling

> 단순한 웹 페이지 요청부터 대규모 크롤링까지 웹 데이터 수집의 모든 과정을 처리할 수 있는 파이썬 프레임워크입니다.

## 개요
웹사이트에서 원하는 데이터를 빠르고 안정적으로 수집할 수 있도록 돕는 도구입니다. 웹사이트의 구조가 바뀌거나 보안 방어가 있어 데이터를 가져오기 어렵던 문제를 해결합니다. 파이썬 코드, 터미널 명령어나 AI 에이전트를 통해 기능을 실행하고 필요한 데이터를 파일로 저장할 수 있습니다.

## 주요 기능
- 웹 요청 및 상호작용: 빠른 HTTP 요청, 자바스크립트 렌더링, 보안 인증 우회 및 세션 유지를 수행할 수 있습니다.
- 데이터 파싱 및 추출: CSS 선택자와 XPath를 사용하여 원하는 요소를 정확하게 찾아내고 마크다운 등으로 변환할 수 있습니다.
- 크롤링 및 내보내기: 동시 다발적 크롤링, 프록시 순환, 자동 재시도 기능을 통해 대규모 데이터를 수집하고 파일로 저장할 수 있습니다.
- AI 및 터미널 연동: AI 에이전트와 연동하여 웹을 탐색하거나 명령어를 통해 대화형으로 데이터를 수집할 수 있습니다.

# DietrichGebert/ponytail

> AI 에이전트가 가장 게으른 시니어 개발자처럼 최소한의 코드만 작성하도록 도와주는 도구입니다.

## 개요
Ponytail은 AI 에이전트가 기존 레포지토리를 분석해 필요한 부분만 재사용하고, 불필요한 코드를 크게 줄여 줍니다. 이를 통해 코드 라인 수·시간·비용·토큰 사용량을 크게 절감하면서도 안전성을 유지합니다. npm 패키지를 설치하고 에이전트에 연결하면, 에이전트는 변경 요청만으로 간결한 구현을 반환하고, /ponytail‑review와 /ponytail‑audit 엔드포인트로 자동 검토와 전체 감사 결과를 확인할 수 있습니다.

## 주요 기능
- 코드 최소화: 동일 기능을 구현하면서 라인 수를 크게 줄입니다.
- 시간·비용 절감: 토큰 사용량·실행 시간이 감소합니다.
- 리뷰 자동화: /ponytail‑review 로 변경된 코드의 버그·보안·테스트 상황을 검증합니다.
- 전체 감사: /ponytail‑audit 로 레포 전체 위험도를 순위별로 제시합니다.
- 대시보드 밴드: Claude Code UI에 현재 작업의 비용·재사용·테스트 결과를 실시간 표시합니다.
- 다중 에이전트 지원: 20개 이상의 AI 에이전트와 호환됩니다.

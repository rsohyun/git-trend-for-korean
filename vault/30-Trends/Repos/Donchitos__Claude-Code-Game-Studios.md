# Donchitos/Claude-Code-Game-Studios

> Claude Code 개발 세션을 실제 게임 스튜디오처럼 49명의 AI 에이전트와 체계적인 작업 흐름으로 확장해 주는 도구입니다.

## 개요
혼자 AI로 게임을 만들 때 겪는 구조 부재와 품질 관리 한계를 해결합니다. 기획, 프로그래밍, 아트, QA 등 49명의 전문 에이전트와 74개의 슬래시 명령어를 제공합니다. 사용자는 Claude Code에서 명령어를 입력해 체계적인 역할 분담과 검증을 거쳐 게임을 개발할 수 있습니다.

## 주요 기능
- 스튜디오 계층 구조: 크리에이티브 디렉터부터 전문 프로그래머까지 49명의 에이전트가 역할을 나누어 협업합니다.
- 워크플로우 명령어: 슬래시 명령어로 기획, 스프린트 계획, 코드 검토, QA 테스트를 실행할 수 있습니다.
- 엔진별 맞춤 지원: Godot, Unity, Unreal Engine 5 프로젝트를 위한 전용 에이전트 세트를 제공합니다.
- 자동 품질 검증: 커밋, 푸시, 에셋 변경 시 자동으로 규칙과 품질을 검사합니다.
- 문서 및 템플릿: 게임 기획서(GDD), 아키텍처 결정서(ADR) 등 다양한 문서 템플릿을 제공합니다.

## 참고·주의
- Claude Code 환경이 필수적으로 요구됩니다.
- 일부 디렉터 에이전트는 Claude Opus 모델을 사용합니다.

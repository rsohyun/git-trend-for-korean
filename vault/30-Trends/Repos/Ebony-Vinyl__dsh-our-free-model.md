# Ebony-Vinyl/dsh-our-free-model

> dsh 플러그인을 설치하면 로그인·API 키 없이 DeepSeek V4.1 Flash, Kimi K3 등 최신 모델을 무료로 사용할 수 있습니다.

## 개요
이 플러그인은 dsh에 모델 제공 채널을 추가해 무료 LLM을 바로 이용하게 해 줍니다. 별도 계정이나 키가 필요 없으며, 설치 후 모델 선택기에서 사용 가능한 모델을 확인하고 대화를 시작하면 됩니다. 모델 목록은 상위 게이트웨이에서 실시간으로 갱신되며, 로컬 OpenAI 호환 포트로도 호출할 수 있습니다. 플러그인은 무설치·무빌드·제로 의존성으로 동작합니다.

## 주요 기능
- 무설정 사용: 설치만 하면 별도 로그인·키 입력 없이 모델을 바로 사용할 수 있습니다.
- 실시간 모델 목록 갱신: 상위 게이트웨이에서 최신 모델·컨텍스트 길이·능력을 자동으로 받아옵니다.
- 플러그인 내 업그레이드와 핫리로드: 설정 페이지에서 원클릭 업데이트와 즉시 적용이 가능합니다.
- 사용량 대시보드: 토큰 소비·속도·지연 등을 로컬에서 시각화하고 외부에 전송하지 않습니다.
- OpenAI 호환 로컬 포트: 다른 도구가 base URL·Key만으로 동일 모델을 호출할 수 있습니다.
- 토큰 절감 기능: 프롬프트 압축·툴 결과 압축 등으로 전송 토큰을 크게 줄입니다.

## 참고·주의
- 네트워크 연결이 필요하며, 지역 제한 모델은 사용이 차단될 수 있습니다.
- dsh 버전 0.1.5‑0.1.7‑rc.2와 호환됩니다.
- EAC 채널을 사용하려면 GitHub 로그인·Star 인증이 필요합니다.

# FareedKhan-dev/kimi-k3-in-c

> 거대한 크기의 Kimi K3 인공지능 모델을 그래픽카드 없이 일반 컴퓨터의 CPU와 적은 메모리만으로 실행할 수 있게 해 주는 프로그램입니다.

## 개요
대규모 인공지능 모델을 실행할 때 고성능 그래픽카드와 막대한 메모리가 필수로 요구되는 문제를 해결합니다. C99 언어로 작성되어 복잡한 프레임워크나 외부 라이브러리 없이 가볍게 작동합니다. 사용자는 명령어 실행을 통해 일반 노트북이나 데스크탑 환경에서도 거대 모델의 연산 결과를 얻을 수 있습니다.

## 주요 기능
- 그래픽카드 미사용: GPU 없이 오직 CPU와 시스템 메모리만으로 대규모 인공지능 모델을 구동합니다.
- 저메모리 실행: 2조 개가 넘는 매개변수를 가진 모델을 8GB 수준의 적은 메모리로 처리할 수 있습니다.
- 이식성 높은 C99 구현: 복잡한 프레임워크나 외부 라이브러리 없이 C99 표준만으로 가볍고 빠르게 동작합니다.
- 환경 맞춤형 프리셋: 사용자의 컴퓨터 사양에 맞춰 성능과 메모리 사용 방식을 조절할 수 있습니다.

## 참고·주의
- 모델 용량이 매우 크기 때문에 디스크 공간과 처리 시간에 여유가 필요합니다.

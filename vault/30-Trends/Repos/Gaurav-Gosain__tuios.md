# Gaurav-Gosain/tuios

> 터미널 화면을 여러 개로 나누고 AI 코딩 에이전트의 상태를 한눈에 관리할 수 있게 해 주는 터미널 창 관리자입니다.

## 개요
터미널 창을 효율적으로 배치하고 관리하지 못해 여러 작업을 동시에 추적하기 어려운 문제를 해결합니다. 백그라운드에서 동작하는 프로그램이 세션을 유지하고 여러 기기를 연결해 주어, 사용자는 화면을 분할하고 에이전트들의 상태를 확인하며 작업을 이어갈 수 있습니다. 빔(Vim)과 유사한 단축키로 창을 조작하며, 설정에 따라 다양한 레이아웃으로 터미널을 구성할 수 있습니다.

## 주요 기능
- 창 분할 관리: 터미널 화면을 여러 개의 창으로 나누어 동시에 여러 작업을 수행할 수 있습니다.
- 세션 유지: 터미널 창을 닫거나 재시작해도 작업 중이던 세션과 상태가 유지됩니다.
- 에이전트 상태 추적: 터미널 창에서 실행 중인 코딩 에이전트들의 상태를 모니터링하고 메시지를 주고받을 수 있습니다.
- 키보드 및 마우스 제어: 빔 스타일의 단축키와 마우스 상호작용으로 창과 워크스페이스를 빠르게 전환할 수 있습니다.
- 명령 팔레트:주요 기능과 명령어를 간편하게 검색하고 실행할 수 있는 팔레트를 제공합니다.

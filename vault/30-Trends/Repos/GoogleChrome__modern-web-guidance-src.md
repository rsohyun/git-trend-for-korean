# GoogleChrome/modern-web-guidance-src

> 코딩 에이전트가 구형 웹 기술 대신 최신 표준 웹 기술과 브라우저 기능을 사용하도록 안내하는 개발 도구입니다.

## 개요
대형 언어 모델의 학습 데이터에 포함된 오래된 코드로 인해 코딩 에이전트가 비효율적인 구형 패턴을 생성하는 문제를 해결합니다. 최신 브라우저 API, 성능 최적화, 접근성 지침을 압축된 형태로 제공하여 에이전트가 고성능의 현대적인 웹 코드를 작성하도록 유도합니다. 명령어를 통해 대화형으로 설치하거나 소스 코드에서 관련 가이드를 검색하여 활용할 수 있습니다.

## 주요 기능
- 가이드 설치 마법사: 대화형 설정 도구를 통해 프로젝트에 모던 웹 가이드를 손쉽게 설치할 수 있습니다.
- 가이드 검색 및 조회: 특정 UI 구현이나 웹 기능에 대한 최신 가이드 문서를 명령어로 직접 찾을 수 있습니다.
- 레거시 코드 진단: 소스 코드에서 구형 패턴을 찾아내어 최신 웹 기술로 개선할 수 있도록 검사합니다.
- 사용자 경험 최적화: 뷰 전환 애니메이션과 스크롤 효과 등 매끄러운 시각 효과를 적용하는 방법을 안내합니다.
- 성능 및 접근성 향상: 브라우저 기본 기능을 활용해 속도를 높이고 웹 접근성을 기본으로 갖추도록 돕습니다.

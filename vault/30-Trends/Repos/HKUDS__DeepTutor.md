# HKUDS/DeepTutor

> DeepTutor는 개인 맞춤형 평생 학습을 제공하는 AI 기반 튜터링 플랫폼입니다.

## 개요
DeepTutor는 사용자의 학습 이력과 목표를 기반으로 맞춤형 학습 경로와 실시간 피드백을 제공하는 도구입니다. 기존 온라인 강의는 일관된 관리와 개인화가 부족한데, 이 플랫폼은 지속적인 튜터링과 지식 관리로 그 문제를 해결합니다. 사용자는 Python 3.11+ 환경에 설치 후 웹 인터페이스에 로그인하면 학습 워크스페이스가 열리고, 원하는 과목을 선택해 연속적인 연습·평가·피드백을 받을 수 있습니다.

## 주요 기능
- 맞춤형 학습 경로: 사용자의 수준과 목표에 맞춰 자동으로 학습 플랜을 생성합니다.
- 실시간 피드백 및 채팅: AI 튜터와 대화형으로 질문하고 즉시 답변을 받습니다.
- 다양한 학습 자료 통합: PDF, 비디오, 퀴즈 등 여러 형식의 콘텐츠를 하나의 워크스페이스에서 관리합니다.
- 학습 기록 및 복구: 대화와 진행 상황을 저장해 언제든 재개하거나 복구할 수 있습니다.
- 플러그인·확장 지원: 외부 도구와 연동해 추가 기능을 손쉽게 확장할 수 있습니다.

## 참고·주의
- Python 3.11 이상과 Node.js(Next.js 16) 환경이 필요합니다.
- 인터넷 연결이 없으면 클라우드 기반 AI 모델 및 외부 콘텐츠를 사용할 수 없습니다.
- 대규모 모델 사용 시 GPU가 권장되지만 필수는 아닙니다.

# Hao0321/video-autopilot-kit

> 유튜브와 숏폼 동영상의 기획, 편집 계획, 검증을 자동화하고 무료 데스크톱 편집기 Editkin과 연동해 영상을 완성하는 프레임워크입니다.

## 개요
이 도구는 반복되는 유튜브와 숏폼 영상 제작 과정에서 기획과 품질 검증을 자동화하여 영상 제작 효율을 높여 줍니다. 수동 편집 과정에서 발생하는 기준 미달이나 검증 누락 문제를 해결하기 위해, AI 에이전트와 편집기 사이의 실행 계약을 통해 안전하고 일관된 편집안을 만들어 냅니다. 사용자는 온보딩 질문지에 자신의 채널 정보를 입력하고 편집할 소재를 지정한 뒤, 제공되는 명령어와 연동된 편집기를 통해 검증된 편집 결과물을 얻습니다.

## 주요 기능
- 편집 계획 검증: AI가 세운 편집 계획이 정해진 품질 기준과 규칙을 만족하는지 자동으로 확인합니다.
- Editkin 연동: 무료 데스크톱 편집기인 Editkin과 통신하여 실제 렌더링과 효과 적용 작업을 수행합니다.
- 숏폼 및 장편 지원: 30초 이내의 짧은 숏폼부터 여러 장으로 구성된 긴 영상까지 일관된 흐름으로 자동화합니다.
- 시각적 품질 검사: 렌더링 전후로 화면 구성과 자막, 템플릿 배치가 올바른지 검사하여 오류를 막습니다.
- 오프라인 예제 실행: 실제 영상 소재나 외부 계정 없이도 파이썬 명령어만으로 전체 작업 흐름을 테스트할 수 있습니다.

## 참고·주의
- 실제 영상 렌더링과 편집을 위해서는 외부 데스크톱 프로그램인 Editkin의 별도 설치가 필수입니다.
- Editkin 0.16.0 버전은 현재 Windows 환경만 지원합니다.

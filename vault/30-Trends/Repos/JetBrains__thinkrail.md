# JetBrains/thinkrail

> AI 코딩 에이전트와 연동되어 프로젝트를 학습하고 스스로 기능을 확장하는 AI 중심 개발 환경입니다.

## 개요
AI 코딩 에이전트를 활용해 코드를 작성할 때 여러 작업을 동시에 관리하기 어려운 문제를 해결합니다. 독립된 작업 공간에서 에이전트와 대화하며 코드를 수정하고, 진행 상황을 시각적으로 확인합니다. JetBrains AI 또는 외부 AI 제공업체 계정을 연결하여 사용할 수 있습니다.

## 주요 기능
- 격리된 작업 공간: 메인 코드에 영향을 주지 않고 여러 작업을 독립된 가상 공간에서 동시에 수행할 수 있습니다.
- 실시간 AI 채팅: 여러 AI 세션을 동시에 실행하며 에이전트의 응답 속도와 토큰 사용량을 실시간으로 확인할 수 있습니다.
- 프로젝트 문서화 연동: 프로젝트 구조를 정의하는 문서 파일을 에이전트가 직접 읽고 수정하며 지속해서 학습합니다.
- 통합 명령어 팔레트: 단축키로 대화, 작업 공간, 설정을 빠르게 검색하고 실행할 수 있습니다.
- 오프라인 및 커스텀 모델 지원: 로컬에서 실행 중인 AI 모델이나 회사 전용 LLM 게이트웨이를 연결하여 사용할 수 있습니다.

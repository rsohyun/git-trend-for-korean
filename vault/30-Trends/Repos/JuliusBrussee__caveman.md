# JuliusBrussee/caveman

> AI 코딩 에이전트의 답변을 핵심만 남기도록 줄여서 토큰 비용을 크게 아껴 주는 프록시 및 도구입니다.

## 개요
AI 에이전트가 길고 불필요한 설명을 덧붙이느라 토큰을 낭비하는 문제를 해결합니다. 에이전트가 주고받는 답변과 로그의 양을 줄여서 동일한 작업 성능을 더 낮은 비용으로 유지합니다. 명령어를 한 번 실행하여 설치하면 사용 중인 에이전트와 연동되어 토큰 사용량이 줄어든 결과를 바로 확인할 수 있습니다.

## 주요 기능
- 말 줄이기: 에이전트가 인사말이나 불필요한 설명 없이 핵심 답변만 간결하게 출력합니다.
- 로그 압축: 모델이 읽기 전에 로그나 JSON, CSV 같은 방대한 데이터를 먼저 압축합니다.
- 작업 자동 최적화: 요청마다 가장 알맞은 모델과 연산 수준을 자동으로 선택합니다.
- 스크립트 재사용: 에이전트가 작성한 코드를 보관했다가 다시 실행하여 토큰 소비를 줄입니다.
- 웹 페이지 압축: 에이전트가 참고하는 웹 페이지를 가볍게 줄여서 가져옵니다.

## 참고·주의
- Node.js 22.13 버전 이상이 필요합니다.

# JustVugg/colibri

> 수백억에서 수천억 파라미터에 달하는 대형 오픈소스 AI 모델을 그래픽카드나 고성능 장비 없이 일반 컴퓨터에서 실행할 수 있게 해 주는 고성능 추론 엔진입니다.

## 개요
대형 언어 모델의 일부분만 메모리에 상주시키고 나머지는 디스크에서 실시간으로 불러오는 방식으로 작동합니다. 고성능 그래픽카드가 없어 대형 AI 모델을 쓰기 어렵던 문제를 해결합니다. 실행 파일 하나로 모델을 설치한 뒤 웹 브라우저나 로컬 API 서버 형태로 사용할 수 있습니다.

## 주요 기능
- 모델 맞춤 추천: 내 컴퓨터의 메모리와 저장공간을 분석해 실행 가능한 모델을 알아서 골라 줍니다.
- 중단점 이어받기: 대용량 모델 파일을 내려받다가 끊겨도 처음부터 다시 받을 필요 없이 이어서 받을 수 있습니다.
- 다양한 하드웨어 지원: 그래픽카드 없이 CPU만으로도 동작하며, 엔비디아 CUDA와 Vulkan을 통해 그래픽카드 가속도 지원합니다.
- 오픈 API 연동: OpenAI 및 Anthropic 호환 API를 제공해 다른 프로그램에서도 로컬 AI 모델을 바로 불러다 쓸 수 있습니다.

## 참고·주의
- 최소 8GB 이상의 시스템 메모리와 모델에 따라 수십 GB의 여유 디스크 공간이 필요합니다.

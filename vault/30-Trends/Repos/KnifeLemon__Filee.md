# KnifeLemon/Filee

> Filee는 드래그 앤 드롭으로 263가지 파일 형식을 오프라인에서 변환해 주는 무료 오픈소스 프로그램입니다.

## 개요
Filee는 로컬에서 동작하는 파일 변환 도구로, 별도의 Office나 클라우드 업로드 없이 이미지, 문서, 영상 등 다양한 형식을 변환합니다. 사용자는 프로그램을 설치한 뒤, Ctrl(또는 Option) 키를 누른 상태에서 파일을 끌어다 커서에 나타나는 도넛 형태의 포맷 목록에 놓으면 변환이 시작됩니다. 변환된 파일은 원본과 같은 폴더에 저장되며, 배치 변환과 폴더 감시 기능도 제공합니다. Windows, macOS, Linux를 지원하며, 최신 버전은 자동 업데이트됩니다.

## 주요 기능
- 도넛 UI: 키를 누른 채 파일을 끌어다 포맷 목록에 놓아 바로 변환합니다.
- 263가지 포맷 지원: 이미지, PDF, Office 문서, HWP, 영상·오디오, 전자책, 아카이브 등 다양한 형식을 변환합니다.
- 오프라인 변환: 파일이 로컬에 머무르며 업로드가 전혀 없으므로 개인정보가 보호됩니다.
- 배치·병렬 변환: 여러 파일을 동시에 처리하고, 복합 변환 경로를 자동으로 찾아줍니다.
- 폴더 감시: 지정한 폴더에 새 파일이 들어오면 자동으로 변환합니다.
- Crop 기능: 이미지 변환 전 원하는 영역을 선택해 잘라낼 수 있습니다.

## 참고·주의
- Windows 10/11에서 최신 누적 업데이트가 필요합니다. 오래된 시스템은 하드웨어 스택 보호(CET)와 .NET 호환 문제로 실행되지 않을 수 있습니다.
- macOS 13+는 아직 notarized되지 않아 첫 실행 시 시스템 설정에서 ‘Open Anyway’ 허용이 필요합니다.
- Linux는 Ubuntu 22.04 이상이 요구되며, Python 3이 필요합니다. Wayland에서는 드롭 존이나 파일 관리자 우클릭 메뉴를 사용해야 합니다.

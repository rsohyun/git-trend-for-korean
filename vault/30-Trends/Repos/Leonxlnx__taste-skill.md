# Leonxlnx/taste-skill

> AI 코딩 에이전트가 흔한 템플릿 대신 실제 기업 수준의 전문적인 웹사이트와 디자인을 만들 수 있도록 돕는 에이전트 스킬입니다.

## 개요
AI가 만드는 웹사이트가 흔하고 획일화되는 문제를 해결합니다. 에이전트가 이 스킬을 활용하여 디자인 방향성을 잡고, 실제 사진과 아이콘을 배치하며, 브라우저 체커로 직접 검증한 완성도 높은 웹 페이지를 제작합니다. 사용자는 코딩 에이전트에 스킬을 설치한 뒤 웹사이트 제작이나 개편을 요청하면 됩니다.

## 주요 기능
- 디자인 토큰 및 레이아웃 관리: 비즈니스 성격에 맞는 색상 팔레트와 폰트, 히어로 레이아웃을 자동 지정합니다.
- 실제 제품 UI 및 사진 활용: 실제 브랜드 아이콘, UI 조각, 검증된 아카이브 사진을 활용해 시각적 완성도를 높입니다.
- 브라우저 검증 체커: 제작된 웹페이지가 정해진 디자인 규칙을 엄격하게 지켰는지 실제 브라우저 환경에서 검증합니다.
- 효과 및 인터랙션 제어: 기술·게임 페이지에만 셰이더 효과나 스크롤 장면 같은 창의적인 인터랙션을 적용합니다.

## 참고·주의
- Node 22 이상 버전과 Chrome, Edge, 또는 Chromium 브라우저가 필요합니다.
- 오프라인에서는 기본 포함된 Wikimedia Commons 사진을 사용하며, 추가 사진이나 아이콘을 받을 때 네트워크 연결이 필요합니다.

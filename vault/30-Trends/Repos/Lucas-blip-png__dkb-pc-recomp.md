# Lucas-blip-png/dkb-pc-recomp

> 닌텐도 스위치 2 게임인 '동키콩 바난자'를 에뮬레이터 없이 윈도우와 리눅스에서 직접 실행할 수 있게 변환해 주는 프로그램입니다.

## 개요
게임의 원본 코드를 미리 C 언어로 변환한 뒤 컴퓨터에 맞는 하나의 실행 파일로 만들어 주는 도구입니다. 스위치용 게임 코드를 그대로 실행할 때 생기는 성능 저하와 에뮬레이터 구동의 불편함을 해결합니다. 사용자가 직접 추출한 게임 파일을 제공된 설치 도구에 넣고 실행하면, Vulkan 그래픽 기술을 이용해 네이티브 앱처럼 게임을 즐길 수 있습니다.

## 주요 기능
- 성능 조절: 하드웨어 사양에 맞춰 성능 프리셋과 예상 프레임 비율을 선택할 수 있습니다.
- 화면 품질 향상: NVIDIA DLSS 및 AMD FSR 화질 모드를 이름으로 간편하게 지정할 수 있습니다.
- 로컬 협동 플레이: 두 번째 게임패드를 연결해 폴린 캐릭터로 함께 게임을 즐길 수 있습니다.
- 간편한 설치 도구: 제공되는 런처를 통해 게임 파일 빌드부터 업데이트까지 원클릭으로 관리할 수 있습니다.

## 참고·주의
- 게임 파일은 포함되어 있지 않으며, 사용자가 직접 소유한 콘솔에서 추출한 파일이 필요합니다.

# NVIDIA/SkillEvaluator

> AI 에이전트의 성능과 안전성을 평가하고 개선하는 다단계 프레임워크입니다.

## 개요
AI 에이전트가 사용하는 지침과 파일(스킬)의 품질을 검증하여 에이전트 행동에 미치는 영향을 측정하는 도구입니다. 스킬의 형식 오류나 보안 문제를 조기에 발견하고 중복을 걸러내지 못하는 문제를 해결합니다. 사용자는 명령어를 통해 로컬이나 CI 환경에서 스킬을 검사하고 품질 점수와 피드백 보고서를 얻을 수 있습니다.

## 주요 기능
- 품질 검증: LLM 없이도 스킬의 정적 품질 점수와 결과를 확인할 수 있습니다.
- 루브릭 평가: AI 모델 기반의 채점 기준을 적용하여 상세한 피드백을 받을 수 있습니다.
- CI 연동: 깃허브나 깃랩 등에서 풀 리퀘스트마다 변경된 스킬을 자동으로 검사할 수 있습니다.
- 라이브 평가: 실제 샌드박스 환경에서 스킬이 에이전트의 작업 결과에 미치는 영향을 측정할 수 있습니다.

## 참고·주의
- 모델 API 키, 외부 스캐너, 도커 등 추가 도구와 유료 계정이 필요할 수 있습니다.

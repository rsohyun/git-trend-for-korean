# NVIDIA/auto-ontology

> 기업 메타데이터를 바탕으로 지식 그래프와 시맨틱 레이어를 구축해, AI 에이전트와 LLM이 정확하고 신뢰할 수 있는 데이터 분석을 하도록 돕는 파이썬 프레임워크입니다.

## 개요
기업 데이터의 의미와 구조가 시스템마다 달라 AI 에이전트가 잘못된 답변을 내놓는 문제를 해결합니다. 기업 메타데이터를 수집해 신뢰할 수 있는 지식 그래프와 의미 정의 레이어를 만들고, 이를 MCP, CLI, API를 통해 에이전트에 제공합니다. 사용자는 도커 콤포즈(Docker Compose)로 환경을 실행하고 웹 인터페이스나 API를 통해 자연어로 데이터를 질문하며, 에이전트가 올바른 SQL 쿼리와 출처를 함께 반환하는 결과를 확인할 수 있습니다.

## 주요 기능
- 자연어 데이터 조회: 질문을 SQL로 변환하여 연결된 데이터베이스에서 실행하고 결과를 가져올 수 있습니다.
- 시맨틱 카탈로그 구축: 관계형 데이터베이스의 메타데이터를 바탕으로 의미 기반의 지식 그래프와 온톨로지 레이어를 생성합니다.
- 권한 관리 및 인증: 웹 인터페이스에서 사용자 인증과 역할 기반 접근 제어(RBAC)를 지원합니다.
- 웹 인터페이스 제공: 채팅, 데이터 분석, 카탈로그 관리 등을 수행할 수 있는 화면을 제공합니다.
- 유연한 배포 지원: 도커 콤포즈(Docker Compose)나 쿠버네티스(Kubernetes) 환경에서 손쉽게 실행할 수 있습니다.

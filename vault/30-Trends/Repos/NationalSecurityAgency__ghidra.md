# NationalSecurityAgency/ghidra

> 컴파일된 프로그램을 분석하고 내부 구조를 파악할 수 있게 해 주는 소프트웨어 역공학 분석 도구입니다.

## 개요
소스 코드가 없는 프로그램이나 악성코드가 어떻게 동작하는지 분석할 수 있도록 돕는 프로그램입니다. 프로그램 내부 구조를 파악하기 어렵고 복잡한 대규모 분석 작업을 해결하지 못하는 문제를 겪는 분석가를 위해 만들어졌습니다. 프로그램을 설치하고 실행한 뒤 분석할 파일을 불러오면, 코드를 해독하고 시각화하여 상세한 분석 결과를 얻을 수 있습니다.

## 주요 기능
- 코드 역조립 및 디컴파일: 기계어로 된 컴파일된 코드를 사람이 읽기 쉬운 형태로 변환합니다.
- 다양한 프로세서 지원: 시중의 다양한 프로세서 명령어 세트와 실행 파일 형식을 폭넓게 지원합니다.
- 그래프 및 시각화: 프로그램의 실행 흐름과 구조를 시각화하여 쉽게 파악할 수 있게 돕습니다.
- 자동화 및 스크립트: Java 또는 Python을 사용하여 반복 작업을 자동화하고 확장 기능을 개발할 수 있습니다.

## 참고·주의
- 일부 버전에는 알려진 보안 취약점이 있으므로 사용 전에 보안 권고 사항을 확인해야 합니다.
- 프로그램을 실행하려면 JDK 25 64-bit 설치가 필요합니다.

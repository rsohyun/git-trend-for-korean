# Nutlope/hallmark

> Hallmark는 Claude Code, Codex, Cursor 등 AI 코딩 에이전트용 디자인 스킬로, AI가 만든 흔적을 제거하고 깔끔한 웹 페이지를 자동 생성합니다.

## 개요
Hallmark는 AI 코딩 에이전트가 웹 페이지를 디자인할 때 AI 특유의 흔적을 검출하고 제거해 줍니다. 흔히 보이는 AI 슬롭(눈에 띄는 머리글 아이콘, 색상 강조 등)을 자동으로 감지해 깔끔한 디자인을 보장합니다. 사용자는 Node 18 이상으로 스킬을 설치하고 `/hallmark <프롬프트>` 혹은 URL·앱을 지정하면 48가지 테마 중 적합한 것을 선택해 페이지를 생성하고, 브라우저 기반 렌더링 검증과 슬롭 린트가 수행됩니다. 필요 시 `redesign`이나 `audit` 명령으로 기존 페이지를 재구성하거나 검토할 수 있습니다.

## 주요 기능
- 테마 선택: 48가지 테마 중 적합한 재료를 자동으로 골라 페이지 레이아웃을 구성합니다.
- AI 슬롭 린트: 눈에 띄는 AI‑generated 흔적을 실시간 브라우저 렌더링으로 검사하고 제거합니다.
- 맞춤 페이지: 사용자 프롬프트만으로 완전 맞춤형 디자인을 생성합니다.
- 재디자인·감사: 기존 HTML을 입력해 레이아웃을 유지하면서 새 디자인을 적용하거나 문제점을 보고합니다.
- 실사진 사용: 755개의 공개 라이선스 사진을 주제에 맞게 자동 선택·크레딧을 삽입합니다.

## 참고·주의
- Node 18 이상이 필요합니다.
- 전체 렌더링·슬롭 린트를 사용하려면 puppeteer‑core와 Chrome가 설치되어 있어야 합니다.
- 테마와 사진을 다운로드하려면 인터넷 연결이 필요합니다.

# Orkas-AI/Orkas

> Orkas는 데스크톱에서 목표를 입력하면 여러 AI 에이전트가 협업해 작업을 자동으로 수행하고 결과물을 제공하는 로컬 AI 팀입니다.

## 개요
Orkas는 로컬에서 실행되는 멀티 에이전트 데스크톱 앱으로, 목표를 입력하면 Commander가 작업을 분할하고 16개의 전문 에이전트와 코딩·개인 에이전트를 호출합니다. 프로젝트에 목표, 규칙, 메모리, 파일을 저장해 대화가 중단돼도 이어서 진행됩니다. 사용자는 앱을 설치하고 목표를 입력하면 에이전트가 자동으로 작업을 수행하고 완성된 결과물을 로컬에서 검토할 수 있습니다.

## 주요 기능
- 프로젝트 관리: 목표, 규칙, 메모리, 파일을 한곳에 저장해 작업 흐름을 지속합니다.
- 자동 To‑do 진행: Auto‑advance 기능으로 에이전트가 다음 작업을 스스로 수행합니다.
- 스케줄 자동화: 시간 단위(시간·일·주·월)로 반복 작업을 예약 실행합니다.
- 다양한 커넥터: Gmail, Google Calendar, Notion, Slack 등 외부 서비스와 연동합니다.
- 전문 에이전트 제공: 연구·콘텐츠·미디어·코드·이커머스 등 16개의 특화 에이전트를 기본 탑재합니다.
- 키 기반 모델 선택: 내장 모델(500 크레딧) 또는 Claude·OpenAI·Gemini 등 외부 API 키를 사용할 수 있습니다.

## 참고·주의
- macOS와 Windows 전용이며, 외부 모델을 사용하려면 해당 서비스의 API 키가 필요합니다.

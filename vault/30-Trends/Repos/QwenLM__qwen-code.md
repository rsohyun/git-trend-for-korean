# QwenLM/qwen-code

> 터미널, 편집기, 데스크톱 등 다양한 환경에서 코딩 작업을 도와주는 오픈소스 AI 코딩 에이전트입니다.

## 개요
사용자의 코딩 작업을 자동화하고 프로젝트 분석을 돕는 오픈소스 AI 코딩 도구입니다. 복잡한 개발 과정에서 반복적인 작업과 코드 이해에 겪는 불편을 해결해 줍니다. 터미널이나 지원되는 개발환경에서 실행한 뒤 자연어로 질문하거나 명령을 입력하여 결과를 얻습니다. 다양한 AI 모델과 외부 플랫폼을 연동하여 작업할 수 있습니다.

## 주요 기능
- 자동 메모리 및 기술 관리: AI가 스스로 작업 환경을 기억하고 필요한 기능을 활용합니다.
- 다양한 모델 지원: OpenAI, Anthropic, Gemini, Qwen API 및 로컬 모델을 자유롭게 전환할 수 있습니다.
- 폭넓은 인터페이스 연동: 터미널 외에도 데스크톱 앱, 웹 화면, 주요 에디터 플러그인에서 사용할 수 있습니다.
- 메신저 연동: 텔레그램, 딩톡, 위챗, 페이슈 등을 통해 외부에서도 AI 에이전트와 소통할 수 있습니다.

## 참고·주의
- NPM 설치 방식 사용 시 Node.js 22 버전 이상이 필요합니다.

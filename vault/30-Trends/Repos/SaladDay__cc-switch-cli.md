# SaladDay/cc-switch-cli

> Claude Code, Codex, Gemini 등 여러 AI 개발 도구의 계정과 API 제공자를 한눈에 관리하고 손쉽게 전환할 수 있는 크로스플랫폼 도구입니다.

## 개요
다양한 AI 개발 도구를 사용할 때 매번 API 키나 설정을 일일이 바꿔야 하는 번거로움을 해결해 줍니다. 대화형 화면(TUI)이나 명령어를 통해 원하는 AI 제공자와 계정을 간편하게 선택하고 바로 적용할 수 있습니다. WebDAV를 통한 설정 동기화 기능도 지원하여 여러 환경에서 일관되게 쓸 수 있습니다.

## 주요 기능
- 상호작용 화면(TUI): 전체 화면 인터페이스로 제공자와 계정을 직관적으로 관리할 수 있습니다.
- 빠른 제공자 전환: 명령어 한 줄로 사용할 AI 서비스나 계정을 즉시 바꿀 수 있습니다.
- 연결 상태 확인: 각 제공자의 스트리밍 응답 정상 여부를 미리 점검할 수 있습니다.
- 설정 동기화: WebDAV 기능을 이용해 여러 기기 간에 설정을 그대로 동기화할 수 있습니다.
- 개별 실행: 전역 설정을 바꾸지 않고 특정 제공자로 AI 도구를 곧바로 실행할 수 있습니다.

# TauricResearch/TradingAgents

> 인공지능 에이전트들이 협력하여 금융 시장 상황을 분석하고 매매 전략을 세워 주는 다중 에이전트 트레이딩 프레임워크입니다.

## 개요
여러 대의 언어 모델을 활용해 실제 금융 트레이딩 회사의 의사결정 구조를 모방하는 도구입니다. 복잡한 시장 분석 과정에서 발생하는 정보 수집의 번거로움과 주관적 판단의 한계를 해결합니다. 사용자는 다양한 AI 모델과 데이터 연동 설정을 마친 뒤 분석을 실행하여 종합적인 투자 리포트와 매매 결정을 얻을 수 있습니다.

## 주요 기능
- 전문가별 에이전트 협업: 기본적 분석가, 기술적 분석가, 심리 분석가 등이 모여 시장을 다각도로 평가합니다.
- 다양한 AI 모델 지원: OpenAI, Anthropic, Google 등 여러 언어 모델 제공자를 연결하여 사용할 수 있습니다.
- 과거 데이터 검증: 특정 시점의 데이터만을 기준으로 백테스팅을 수행하여 전략의 타당성을 검증합니다.
- 명령어 도구 제공: 명령줄 인터페이스를 통해 복잡한 과정 없이 간편하게 분석을 실행할 수 있습니다.
- 통합 리포트 생성: 분석 결과와 과거 의사결정 기록을 하나의 웹 페이지 형태로 깔끔하게 저장합니다.

## 참고·주의
- 이 도구는 연구 및 참고용이며, 실제 투자 결과에 대한 재정적 조언이나 보장을 제공하지 않습니다.

# Tencent/LoopForge

> 다양한 AI 코딩 도우미와 표준 작업 절차를 결합하여 소프트웨어 개발을 자동화하고 관리할 수 있는 셀프 호스팅 작업 공간입니다.

## 개요
AI 코딩 에이전트를 사용할 때 매번 결과가 달라지거나 검토 과정 없이 코드가 작성되는 문제를 해결합니다. 챗봇을 통해 요구사항을 지시하거나 반복 가능한 표준 작업 절차를 실행하여 코드 작성부터 풀 리퀘스트 생성까지의 과정을 자동화합니다. 사용자는 자체 서버에 도커를 통해 프로그램을 설치한 뒤 웹 인터페이스에 접속하여 에이전트의 작업을 지시하고 승인할 수 있습니다.

## 주요 기능
- 봇과 대화하기: 채팅을 통해 AI 에이전트에게 버그 수정이나 코드 작성을 지시하고 샌드박스 환경에서 결과를 확인할 수 있습니다.
- 표준 작업 절차 실행: 검증된 개발 단계를 반복 가능한 절차로 저장하여 동일한 방식으로 작업을 수행할 수 있습니다.
- 역할 분리: 기획, 구현, 검토, 테스트 등 각 개발 단계마다 서로 다른 프롬프트와 에이전트를 지정할 수 있습니다.
- 사람의 승인 제어: 중요한 단계마다 승인 게이트를 두어 작업 내용을 검토하고 승인하거나 다시 보낼 수 있습니다.
- 작업 추적 및 관리: 대화나 절차를 통해 이루어진 모든 변경 사항과 로그를 한 곳에서 확인하고 관리할 수 있습니다.

## 참고·주의
- 도커 및 도커 컴포즈가 설치된 서버 환경이 필요합니다.
- 에이전트 사용을 위한 AI 모델 API 키와 깃허브 인증 정보가 필요합니다.

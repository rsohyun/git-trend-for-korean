# The-PR-Agent/pr-agent

> 인공지능을 이용해 깃(Git) 코드 변경 사항을 자동으로 검토하고 설명해 주는 오픈소스 도구입니다.

## 개요
코드 리뷰와 설명 작성에 소요되는 시간을 줄여 주는 인공지능 기반 개발 도구입니다. 깃허브(GitHub), 깃랩(GitLab) 등의 플랫폼에서 풀 리퀘스트(PR, 개발자 간 코드 병합 요청)가 올라오면 자동으로 분석을 수행합니다. 사용자는 깃 플랫폼에 명령어를 입력하거나 깃허브 액션(GitHub Actions)을 연동하여 코드 리뷰 결과와 개선 제안을 받아볼 수 있습니다.

## 주요 기능
- 자동 코드 리뷰: 풀 리퀘스트의 변경 코드를 검토하고 잠재적인 문제점을 찾아냅니다.
- 자동 설명 생성: 코드 변경 사항이 무엇인지 요약하고 문서화합니다.
- 코드 개선 제안: 더 나은 코드 작성법과 수정 방안을 제안합니다.
- 질의응답 기능: 코드 변경 내용에 대해 자유롭게 질문하고 답변을 얻을 수 있습니다.
- 다양한 플랫폼 지원: GitHub, GitLab, Bitbucket, Azure DevOps 등 여러 깃 호스팅 서비스를 지원합니다.

## 참고·주의
- 사용하려면 OpenAI 등 인공지능 모델의 API 키와 이용 권한이 필요합니다.

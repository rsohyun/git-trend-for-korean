# Thysrael/Horizon

> 인공지능을 이용해 매일 영어와 중국어로 맞춤형 뉴스 요약 브리핑을 만들어 주는 도구입니다.

## 개요
흩어져 있는 최신 뉴스 정보를 수집하고 인공지능으로 분석하여 핵심 내용을 요약해 주는 뉴스 브리핑 도구입니다. 매일 방대한 뉴스 중에서 관심 있는 정보를 직접 찾고 정리해야 하는 번거로움을 해결해 줍니다. 사용자가 뉴스 소스와 선호하는 인공지능 모델을 설정하면, 정해진 주기에 맞춰 자동으로 요약된 뉴스 리포트를 생성해 줍니다.

## 주요 기능
- 뉴스 요약 생성: 인공지능을 활용해 수집된 뉴스를 영어와 중국어 브리핑으로 자동 변환합니다.
- 다양한 AI 모델 연동: Claude, GPT, DeepSeek, Ollama 등 다양한 인공지능 모델을 지원합니다.
- 맞춤형 뉴스 수집: 사용자가 원하는 소스의 뉴스만 골라서 모니터링할 수 있습니다.

## 참고·주의
- 사용하려는 인공지능 모델의 API 계정이나 로컬 실행 환경이 필요합니다.

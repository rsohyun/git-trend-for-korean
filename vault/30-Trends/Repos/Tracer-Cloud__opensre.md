# Tracer-Cloud/opensre

> 실패한 CI/CD 빌드의 원인을 분석하고 해결책을 찾아 수정안을 만들어 주는 오픈소스 CLI 에이전트입니다.

## 개요
CI/CD 빌드가 실패했을 때 개발자가 직접 로그를 분석하고 원인을 찾는 번거로움을 해결해 주는 도구입니다. 사용자는 터미널에서 명령어를 실행해 로그인한 뒤, 대화형 쉘이나 명령어로 실패한 빌드에 대해 묻고 수정 제안을 받을 수 있습니다. 자체 호스팅 환경과 사용자가 지정한 모델을 지원하여 빌드 안정성 유지와 원인 분석 과정을 자동화합니다.

## 주요 기능
- 실패 빌드 원인 추적: CI 빌드가 실패한 즉시 로그를 읽고 원인을 분석해 수정안을 제안합니다.
- 대화형 쉘 제공: 터미널에서 명령어와 슬래시 명령을 사용해 에이전트와 대화하며 세션을 관리할 수 있습니다.
- 헤드리스 CLI 지원: 스크립트나 CI 작업 안에서 명령어를 비인터랙티브 방식으로 실행할 수 있습니다.
- 파이썬 API 제공: 파이썬 코드 안에서 에이전트 세션을 직접 실행하고 제어할 수 있습니다.

## 참고·주의
- 초기 알파 단계의 프로젝트로 API와 연동 기능이 변경될 수 있습니다.

# Verlintas/NOIR

> 안드로이드 기기에 설치된 앱의 권한, 네트워크 주소, 데이터 유출 경로를 검사하고 안전 조치를 실행하는 데스크톱 프로그램입니다.

## 개요
스마트폰 앱이 어떤 개인정보에 접근하고 어디로 데이터를 전송하는지 파악하기 어려운 문제를 해결합니다. 컴퓨터에 기기를 연결하고 실행하면 앱 권한과 네트워크 주소를 분석해 위험도를 점수로 매기고 보고서를 만들어 줍니다. 사용자는 결과를 확인한 뒤 안전한 차단 및 설정 변경 명령을 실행하거나 되돌릴 수 있습니다.

## 주요 기능
- 권한 및 네트워크 분석: 앱이 가진 민감한 권한과 통신하는 주소를 추출해 위험도를 평가합니다.
- 데이터 흐름 파악: 수집된 권한과 네트워크 주소를 연결해 어떤 데이터가 어디로 향하는지 보여줍니다.
- 안전 조치 생성: 위험 요소에 대한 실행 가능한 설정 변경 명령과 복구 명령을 자동으로 만듭니다.
- 심층 코드 검사: 필요시 앱을 컴퓨터로 가져와 역공학 도구(jadx)로 고위험 코드 호출을 직접 검색합니다.
- 오프라인 실행: 인터넷에 연결되지 않은 상태에서 작동하며 기기 데이터를 외부로 유출하지 않습니다.

## 참고·주의
- JDK 17 이상, Android platform-tools(adb), jadx 프로그램이 필요합니다.

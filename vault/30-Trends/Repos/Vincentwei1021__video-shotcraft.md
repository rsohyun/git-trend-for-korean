# Vincentwei1021/video-shotcraft

> AI 에이전트와 연동해 실제 제품 화면과 문구로 고품질 제품 홍보 영상과 편집 가능한 결과물을 만들어 주는 도구입니다.

## 개요
AI 에이전트에게 제품 홍보 영상을 만들어 달라고 요청하면 웹페이지나 화면을 캡처해 세련된 움직임 효과를 적용한 영상을 제작해 주는 도구입니다. 기존 영상 생성 도구와 달리 코드로 직접 화면을 그려 선명하고 브랜드에 맞춘 결과물을 얻을 수 있습니다. 사용자는 AI 에이전트에 지시어를 입력하거나 템플릿을 골라 실행하면, 자동으로 스토리보드를 구성하고 편집 가능한 MP4 파일과 프로젝트 파일을 완성해 줍니다.

## 주요 기능
- 에이전트 연동 제작: Claude Code나 Codex에 자연어로 지시하면 자동으로 화면을 캡처하고 영상을 구성합니다.
- 모션 레시피 라이브러리: 124가지 카드와 150개의 움직임 효과를 조합해 원하는 연출을 만들 수 있습니다.
- 비트 동기화 및 사운드 디자인: 음악 박자에 맞춰 장면을 전환하고 음향 효과를 자동으로 맞춥니다.
- 웹 편집기 지원: Motion Workbench를 통해 브라우저 환경에서 완성된 영상을 자유롭게 수정할 수 있습니다.
- 영상 편집 프로그램 내보내기: 최종 결과물을 JianYing(CapCut CN) 초안 파일로 내보내어 클립과 자막을 세부 편집할 수 있습니다.

## 참고·주의
- Claude Code 또는 Codex 환경이 사전에 설정되어 있어야 합니다.

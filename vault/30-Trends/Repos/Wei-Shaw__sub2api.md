# Wei-Shaw/sub2api

> Claude, OpenAI, Gemini, Grok 등 여러 인공지능 구독을 하나로 묶어 공유하고 비용을 분할할 수 있게 해 주는 오픈소스 중계 서비스입니다.

## 개요
다양한 인공지능 모델의 구독 계정을 효율적으로 관리하고 비용을 함께 나누기 어려운 문제를 해결합니다. 사용자는 Docker 환경에 이 프로그램을 설치하고 설정하여 여러 인공지능 API를 하나의 통합된 창구로 이용할 수 있습니다. 각 서비스의 구독 할당량을 여러 사용자가 나누어 쓸 수 있도록 중계해 줍니다.

## 주요 기능
- 통합 API 게이트웨이: Claude, OpenAI, Gemini, Grok 등의 구독을 하나의 인터페이스로 연결합니다.
- 비용 효율적 공유: 여러 사용자가 구독을 함께 사용하여 사용 비용을 효과적으로 분할할 수 있습니다.
- 원스톱 중계 서비스: 여러 플랫폼의 인공지능 API 요청을 일괄적으로 처리하고 관리합니다.

## 참고·주의
- 이 프로젝트를 사용하면 Anthropic 등 업스트림 제공업체의 서비스 약관을 위반할 수 있으며, 계정 정지 등의 위험은 사용자가 직접 부담합니다.
- 이용 시 거주 지역의 관련 법규를 준수해야 합니다.

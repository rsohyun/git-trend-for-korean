# ZhuLinsen/daily_stock_analysis

> 인공지능 대형 모델을 활용해 여러 국가의 주식 시장 데이터를 수집하고 분석해 주는 스마트 주식 분석 시스템입니다.

## 개요
다양한 글로벌 시장의 주가와 실시간 뉴스를 수집해 종목별 투자 분석 보고서를 자동으로 만들어 주는 도구입니다. 복잡한 금융 데이터와 최신 뉴스를 사람이 직접 찾아 정리해야 하는 번거로움을 해결해 줍니다. 사용자가 관심 있는 종목과 인공지능 API 키를 설정하면, 매일 지정된 시간에 정돈된 투자 분석 보고서와 대시보드를 이메일이나 메신저로 받아볼 수 있습니다.

## 주요 기능
- AI 决策报告: 핵심 결론, 점수, 추세, 매수·매도 시점, 위험 경고 등이 포함된 종합 투자 분석 보고서를 생성합니다.
- 多市场数据聚合: A주, 홍콩, 미국, 일본, 한국, 대만 등 여러 국가의 주식 시장 데이터와 재무 정보를 함께 수집합니다.
- 智能导入与补全: 이미지나 엑셀 파일, 클립보드에 있는 종목 정보를 그대로 가져와 간편하게 등록할 수 있습니다.
- Agent 策略问股: 15가지 내장 투자 전략을 활용해 다중 질의 방식으로 종목을 심층 분석할 수 있습니다.
- 自动化与推送: 기업微信, 飞书, 텔레그램, 디스코드, 슬랙, 이메일 등 다양한 채널로 분석 결과를 자동으로 전송합니다.

## 참고·주의
- 인공지능 모델 API 키와 주식 시장 데이터나 뉴스 검색을 위한 외부 서비스 계정이 필요할 수 있습니다.

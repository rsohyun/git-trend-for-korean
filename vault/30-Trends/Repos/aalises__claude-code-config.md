# aalises/claude-code-config

> Claude Code 도구를 확장하여 다중 AI 에이전트 토론, 세션 맥락 관리, 코드 검증 기능을 제공하는 개인용 설정 모음입니다.

## 개요
Claude Code 환경에서 개발 효율을 높이기 위한 커스텀 명령어와 자동화 도구 모음입니다. AI가 작성한 계획이나 코드를 다른 AI와 토론시키고, 작업 내용을 쉽게 공유하거나 복원하지 못하는 불편을 해결합니다. 저장소를 복제한 뒤 명령어 파일을 설정 폴더에 연결하면, 다양한 슬래시 명령어를 통해 에이전트 간 토론과 세션 관리를 바로 시작할 수 있습니다.

## 주요 기능
- 코드 검증 및 토론: 다른 AI 에이전트와 구현한 코드나 작성한 계획을 여러 차례 교차 검증하고 수정할 수 있습니다.
- 세션 맥락 내보내기: 현재 대화 내용, 결정 사항, 탐색한 파일을 구조화된 문서로 정리하고 클립보드에 복사합니다.
- 작업 내용 복원: 저장된 세션 맥락과 최근 변경 사항을 읽어와 이전 작업 이력을 빠르게 파악할 수 있습니다.
- 이슈 분석: 외부 이슈 추적 도구의 링크를 입력받아 코드베이스를 분석하고 구조화된 구현 계획을 세워 줍니다.
- 변경 사항 요약: PR이나 메신저에 바로 붙여넣을 수 있는 깔끔한 브랜치 변경 요약본을 자동으로 생성합니다.

## 참고·주의
- macOS의 pbcopy 또는 Linux의 xclip 명령어가 필요합니다.
- 외부 AI 에이전트 도구와 Notion, Linear MCP 서버가 필요할 수 있습니다.

# addyosmani/agent-skills

> 시니어 개발자의 개발 방식과 품질 기준을 AI 코딩 도구에 주입해 주는 실무형 엔지니어링 기술 모음입니다.

## 개요
AI 코딩 도구가 개발 전 과정에서 일관된 모범 사례와 검증 절차를 따르도록 돕는 도구입니다. AI가 제멋대로 코드를 작성하거나 품질 기준을 놓치는 문제를 해결합니다. 전용 명령어와 스킬을 프로젝트에 설치하면 AI가 기획, 설계, 구현, 테스트, 검토 단계를 시니어 개발자처럼 수행합니다.

## 주요 기능
- 슬래시 명령어 연동: 개발 주기에 맞춘 9개의 명령어로 적절한 스킬을 자동으로 실행할 수 있습니다.
- 자동 빌드 모드: 한 번 승인된 계획을 바탕으로 AI가 각 단계를 개별 테스트와 커밋을 거치며 자율적으로 구현합니다.
- 자동 스킬 활성화: API 설계나 UI 구현 등 작업 내용에 따라 필요한 전문 스킬이 자동으로 작동합니다.
- 다양한 AI 도구 지원: Claude Code, Cursor, Copilot 등 70개 이상의 AI 코딩 도구에 쉽게 설치할 수 있습니다.

## 참고·주의
- 단일 스킬만 설치할 경우 보조 체크리스트 파일 경로가 누락될 수 있으므로 전체 저장소를 연동하거나 필요한 파일을 직접 복사해야 합니다.

# ag-ui-protocol/ag-ui

> AI 에이전트와 사용자 인터페이스를 쉽게 연결할 수 있게 해 주는 표준 프로토콜입니다.

## 개요
AI 에이전트를 프론트엔드 애플리케이션에 매끄럽게 통합하는 도구입니다. 에이전트와 웹 앱 간의 표준화된 통신 수단이 없어 연동이 복잡했던 문제를 해결합니다. 제공되는 명령어와 미들웨어를 활용해 에이전트 백엔드와 사용자 화면을 연결하면 실시간 상호작용 기능을 구현할 수 있습니다.

## 주요 기능
- 실시간 채팅: 에이전트와 실시간으로 메시지를 스트리밍하며 대화할 수 있습니다.
- 상태 동기화: 에이전트와 프론트엔드 간의 상태를 양방향으로 실시간 동기화합니다.
- 생성형 UI: 에이전트 응답에 맞춰 구조화된 메시지와 화면 요소를 동적으로 생성합니다.
- 컨텍스트 강화: 실시간 사용자 상황 정보를 에이전트에 전달하여 맥락을 유지합니다.
- 프론트엔드 도구 연동: 사용자 인터페이스에서 직접 에이전트가 사용하는 도구를 호출할 수 있습니다.

# alibaba/open-code-review

> 알리바바 그룹에서 검증된 대규모 코드 리뷰 도구로, AI와 규칙 기반 파이프라인을 결합해 정확한 코드 결함을 찾아 줍니다.

## 개요
대규모 소프트웨어 개발에서 코드 리뷰의 누락이나 부정확한 피드백 문제를 해결하기 위해 만들어진 AI 코드 리뷰 도구입니다. 정밀한 규칙 매칭과 AI 에이전트를 결합한 하이브리드 방식을 사용하여 코드 변경 사항을 분석합니다. 사용자는 명령어를 통해 코드를 스캔하고 정밀한 줄 단위 리뷰 코멘트를 자동으로 생성받을 수 있습니다.

## 주요 기능
- 하이브리드 아키텍처: 규칙 기반 파이프라인과 인공지능 에이전트를 결합해 정확하고 효율적인 리뷰를 수행합니다.
- 줄 단위 정밀 피드백: 실제 코드 위치에 정확히 맞춘 상세한 리뷰 코멘트를 생성합니다.
- 내장 다국어 규칙셋: 널 포인터 예외(NPE), 스레드 안전성, 보안 취약점 등 다양한 개발 언어별 규칙을 제공합니다.
- 오픈 API 호환: OpenAI 및 Anthropic 등 다양한 인공지능 모델 엔드포인트와 연동할 수 있습니다.

## 참고·주의
- 사용하려면 OpenAI 또는 Anthropic 등 호환되는 인공지능 모델의 API 계정이나 엔드포인트가 필요합니다.

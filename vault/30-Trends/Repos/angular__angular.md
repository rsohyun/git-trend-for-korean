# angular/angular

> 웹, 모바일 등 다양한 환경에서 동작하는 웹 애플리케이션을 만들 수 있는 개발 플랫폼입니다.

## 개요
TypeScript와 JavaScript를 활용해 확장성이 높은 웹 애플리케이션을 구축할 수 있도록 돕는 도구입니다. 복잡한 웹 화면 구성과 데이터 관리를 체계적으로 처리할 수 있는 문제를 해결합니다. 전용 명령줄 도구를 설치하고 프로젝트를 생성한 뒤 실행하여 웹 앱 개발을 시작할 수 있습니다. 크로스플랫폼을 지원하며 강력한 개발 도구와 풍부한 생태계를 제공합니다.

## 주요 기능
- 컴포넌트 및 템플릿: 화면 요소를 독립적인 부품으로 나누어 재사용할 수 있습니다.
- 폼 관리: 사용자 입력 데이터를 쉽게 검증하고 처리할 수 있습니다.
- 서버 사이드 렌더링: 서버에서 미리 화면을 그려 빠르게 불러올 수 있습니다.
- 지연 로딩: 필요한 시점에만 코드를 불러와 앱 실행 속도를 높일 수 있습니다.
- 애니메이션: 웹 화면에 부드러운 움직임 효과를 추가할 수 있습니다.

## 참고·주의
- 사용하기 전에 Node.js와 패키지 관리자 설치가 필요합니다.

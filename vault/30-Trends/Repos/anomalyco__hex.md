# anomalyco/hex

> 키를 누른 채 말하면 텍스트를 인식해 현재 창에 붙여 주는 로컬 음성 입력 도구입니다.

## 개요
Hex는 macOS, Windows, Linux에서 동작하는 로컬 음성 입력 프로그램입니다. 키를 눌러 말하면 실시간으로 음성을 텍스트로 변환해 현재 활성 앱에 바로 붙여 줍니다. 첫 실행 시 음성 모델을 다운로드하고 나면 인터넷 연결 없이도 동작합니다. 사용자는 설치 후 단축키를 설정하고, 누른 채로 말하면 자동으로 텍스트가 입력됩니다.

## 주요 기능
- 실시간 음성 전사: 말을 하면 즉시 텍스트로 변환합니다.
- 로컬 처리: 변환이 기기 내에서 이루어져 개인정보가 외부로 나가지 않습니다.
- 크로스 플랫폼 지원: macOS, Windows, Linux 모두에서 사용할 수 있습니다.
- 키보드 단축키 활성화: 지정한 키를 누른 상태에서 말하면 자동으로 입력됩니다.
- 실험적 기능 랩스: 사이드바 하단 Labs에서 새로운 기능을 시험해 볼 수 있습니다.
- 다양한 설치 방법: Homebrew, AUR, 스크립트, Nix 등으로 간편히 설치합니다.

## 참고·주의
- 첫 실행 시 음성 모델을 다운로드하려면 인터넷 연결이 필요합니다.
- 마이크 사용 권한을 부여해야 음성 인식이 가능합니다.
- 지원되는 OS와 아키텍처에서만 동작합니다.

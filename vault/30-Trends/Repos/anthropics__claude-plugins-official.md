# anthropics/claude-plugins-official

> 앤스로픽(Anthropic)이 직접 관리하는 공식 Claude Code 플러그인 모음 저장소입니다.

## 개요
Claude Code의 기능을 확장할 수 있는 다양한 공식 및 외부 플러그인을 모아 둔 디렉토리입니다. 개발자는 자신의 도구를 등록해 공유할 수 있고, 사용자는 필요한 플러그인을 쉽게 찾아 설치할 수 있습니다. Claude Code 안에서 명령어나 검색 메뉴를 통해 원하는 플러그인을 간편하게 추가할 수 있습니다.

## 주요 기능
- 공식 플러그인 제공: 앤스로픽 팀이 직접 개발하고 관리하는 내부 플러그인을 이용할 수 있습니다.
- 외부 파트너 플러그인 탐색: 파트너와 커뮤니티가 기여한 검증된 서드파티 플러그인을 찾을 수 있습니다.
- 간편한 설치: 마켓플레이스에서 명령어 하나로 필요한 플러그인을 바로 설치할 수 있습니다.
- 직접 검색 기능: Claude Code 내부 검색 메뉴를 통해 플러그인을 찾아볼 수 있습니다.
- 플러그인 등록 신청: 양식을 통해 새로운 외부 플러그인을 마켓플레이스에 제출할 수 있습니다.

## 참고·주의
- 설치하려는 서드파티 플러그인의 신뢰성과 포함된 소프트웨어는 앤스로픽이 검증하지 않으므로 사용자가 직접 확인해야 합니다.

# anthropics/claude-quickstarts

> Claude API를 활용해 고객 지원, 금융 분석, 컴퓨터 제어, 브라우저 자동화 등 다양한 AI 애플리케이션을 빠르게 개발할 수 있도록 돕는 예제 프로젝트 모음입니다.

## 개요
Claude API를 활용하여 실제 동작하는 AI 애플리케이션을 처음부터 직접 구현해야 하는 번거로움을 해결해 주는 도구입니다. 고객 지원 상담원, 금융 데이터 분석가, 컴퓨터 및 브라우저 제어 에이전트 등 다양한 목적의 완성도 높은 기초 코드를 제공합니다. 사용자는 원하는 프로젝트를 내려받아 API 키를 설정한 뒤 바로 실행하거나 자신의 서비스에 맞게 코드를 수정할 수 있습니다. 각 프로젝트는 최신 API 기능과 연동 패턴을 그대로 보여 주어 개발 시간을 크게 줄여 줍니다.

## 주요 기능
- 고객 지원 상담원: 지식 기반을 활용해 고객의 질문에 답하는 AI 지원 시스템을 구축할 수 있습니다.
- 금융 데이터 분석가: 대화형 데이터 시각화 기능을 통해 채팅으로 금융 데이터를 분석할 수 있습니다.
- 컴퓨터 제어 데모: 데스크톱 화면을 인식하고 직접 마우스와 키보드를 제어하는 AI 에이전트를 실행할 수 있습니다.
- 브라우저 자동화: 웹사이트를 탐색하고 요소를 조작하며 양식을 채우는 브라우저 에이전트를 만들 수 있습니다.
- 자율 코딩 에이전트: 여러 세션에 걸쳐 완전한 애플리케이션을 스스로 구축하는 개발용 에이전트를 활용할 수 있습니다.
- 관리형 에이전트 연동: 슬랙, 텔레그램, 디스코드 등 다양한 메신저와 연동되는 지속형 AI 에이전트 앱을 만들 수 있습니다.

## 참고·주의
- 이 프로젝트를 사용하려면 유효한 Claude API 키가 필요합니다.

# anthropics/knowledge-work-plugins

> 클로드(Claude)를 각 직무별 전문가로 만들어 주는 오픈소스 플러그인 모음입니다.

## 개요
직장인이 반복적인 업무를 줄이고 일관된 결과물을 낼 수 있도록 돕는 도구입니다. 사내 도구와 업무 방식을 일일이 설명해야 하는 불편함을 해결합니다. 플러그인을 설치하면 직무별 전문 지식과 외부 도구 연동 기능이 클로드에 추가됩니다.

## 주요 기능
- 직무별 맞춤 전문가 설정: 영업, 마케팅, 법무, 재무 등 다양한 직무에 특화된 기능을 클로드에 추가할 수 있습니다.
- 외부 업무 도구 연동: 슬랙, 노션, 지라 등 업무에 사용하는 다양한 도구와 데이터를 클로드와 연결할 수 있습니다.
- 자동 실행 기술: 질문 내용에 맞춰 필요한 업무 지식과 절차를 클로드가 스스로 불러와 적용합니다.
- 전용 명령어 제공: 회의 준비나 보고서 작성 같은 특정 작업을 바로 실행하는 명령어를 사용할 수 있습니다.
- 맞춤형 플러그인 제작: 회사의 고유한 도구와 업무 방식에 맞춰 기존 플러그인을 수정하거나 새로 만들 수 있습니다.

## 참고·주의
- 클로드 코워크(Claude Cowork) 또는 클로드 코드(Claude Code) 프로그램이 필요합니다.
- 외부 도구 연동을 위해 각 서비스의 계정이나 접근 권한이 필요할 수 있습니다.

# anthropics/skills

> 인공지능(AI) 모델인 클로드(Claude)가 특정 작업을 더 잘 수행하도록 안내하는 지침과 스크립트 모음입니다.

## 개요
클로드가 문서 작성, 데이터 분석, 디자인 등 전문적인 업무를 일관되게 처리하지 못하는 문제를 해결합니다. 저장소에서 필요한 기능을 골라 클로드에 적용하면, 사용자가 원하는 방식으로 복잡한 작업을 자동으로 수행할 수 있습니다. 개발자와 사용자는 제공되는 모음이나 양식을 참고해 자신만의 맞춤형 기능을 직접 만들 수 있습니다.

## 주요 기능
- 문서 처리: 워드, PDF, 파워포인트, 엑셀 파일을 읽고 만드는 기능을 클로드에 추가할 수 있습니다.
- 작업 자동화: 디자인 가이드 준수나 데이터 분석 같은 반복 업무를 일정한 방식으로 처리하게 만듭니다.
- 기능 확장: 웹 앱 테스트나 서버 생성 등 기술적인 작업에서 클로드의 성능을 높여 줍니다.
- 맞춤형 제작: 제공되는 양식과 지침을 활용해 나만의 전문 작업 방식을 새로 만들 수 있습니다.

## 참고·주의
- 일부 문서 편집 기능은 오픈소스가 아니며, 시연 및 교육 목적으로만 제공됩니다.

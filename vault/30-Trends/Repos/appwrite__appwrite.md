# appwrite/appwrite

> 인공지능 에이전트와 개발자가 앱을 쉽게 만들고 확장할 수 있도록 인증, 데이터베이스, 저장소 등을 통합 제공하는 오픈소스 백엔드 플랫폼입니다.

## 개요
앱 개발에 필요한 다양한 백엔드 기능을 한곳에 모아 제공하여, 개발자가 직접 서버를 구축하고 연동하는 번거로움을 해결해 주는 도구입니다. MCP(AI 에이전트가 외부 도구를 호출하는 표준 방식)를 기본 지원하므로, 코딩 에이전트가 라이브 프로젝트에 직접 접근하여 코드를 조작할 수 있습니다. 사용자는 클라우드 서비스를 이용하거나 도커(Docker)를 통해 직접 서버에 설치하여 프로젝트를 시작할 수 있습니다.

## 주요 기능
- 인증: 이메일, SMS, 소셜 로그인, 익명 세션 등을 통해 사용자를 안전하게 인증할 수 있습니다.
- 데이터베이스: 기본 데이터베이스나 관리형 PostgreSQL 및 MySQL을 선택하여 데이터를 관리할 수 있습니다.
- 저장소: 압축, 암호화, 이미지 변환 기능이 포함된 파일 저장소를 활용할 수 있습니다.
- 서버리스 함수: 보안이 격리된 런타임 환경에서 이벤트 기반의 서버리스 코드를 실행할 수 있습니다.
- 실시간 동기화: 프로젝트 내에서 발생하는 이벤트를 실시간으로 구독하고 반응할 수 있습니다.
- 메시징 및 방화벽: 이메일, 푸시 알림 전송과 트래픽 규칙 설정을 통한 앱 보호가 가능합니다.

## 참고·주의
- 직접 설치하려면 도커(Docker)가 설치되어 있어야 합니다.

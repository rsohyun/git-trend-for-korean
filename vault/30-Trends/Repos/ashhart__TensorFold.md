# ashhart/TensorFold

> 애플 실리콘과 엔비디아 그래픽카드에서 파이썬 설치 없이 언어 모델을 직접 실행하고 서비스할 수 있는 추론 엔진입니다.

## 개요
파이썬이나 별도의 머신러닝 라이브러리 없이 가벼운 바이너리 파일 하나로 대규모 언어 모델을 로컬 환경에서 구동하는 도구입니다. 복잡한 의존성 설치나 환경 설정 없이 명령어 몇 줄로 모델을 다운로드하고 API 서버를 띄울 수 있습니다. 사용자는 터미널에서 모델을 내려받은 뒤 서버를 실행하고, 표준 API 요청을 보내 대화형 응답을 받아볼 수 있습니다.

## 주요 기능
- 모델 직접 구동: 파이썬이나 MLX 설치 없이 Metal 및 CUDA 커널을 통해 언어 모델을 직접 실행합니다.
- 다양한 API 지원: OpenAI 및 Anthropic 호환 API를 통해 채팅, 완성, 메시지 기능을 제공합니다.
- 웹 인터페이스 제공: 내장된 로컬 웹 앱을 통해 모델을 손쉽게 선택하고 대화할 수 있습니다.
- 병렬 요청 관리: 메모리 용량에 맞춰 동시 처리 요청 수를 자동 또는 수동으로 조절할 수 있습니다.

## 참고·주의
- 리눅스 환경에서는 글립씨(glibc) 2.28 이상과 엔비디아 드라이버 R580(CUDA 13.0) 이상이 필요합니다.

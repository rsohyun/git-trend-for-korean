# astral-sh/ruff

> 기존 파이썬 코드 검사 및 정렬 도구보다 최대 100배 이상 빠른 통합 파이썬 린터 및 포맷터입니다.

## 개요
파이썬 코드의 오류와 스타일 문제를 검사하고 보기 좋게 정리해 주는 도구입니다. 기존 도구들이 느려서 전체 코드베이스를 검사하는 데 오랜 시간이 걸리는 문제를 해결합니다. 사용자는 명령어를 실행해 파이썬 코드의 오류를 자동으로 고치거나 형식을 통일된 기준으로 정렬할 수 있습니다. 900개가 넘는 검사 규칙을 지원하며 별도의 설정 파일로 프로젝트 환경에 맞게 동작을 바꿀 수 있습니다.

## 주요 기능
- 초고속 코드 검사: 기존 도구보다 수십 배 빠른 속도로 파이썬 코드의 오류와 스타일 문제를 검사합니다.
- 자동 코드 수정: 사용하지 않는 가져오기 구문 삭제 등 발견된 오류를 자동으로 고쳐 줍니다.
- 코드 포맷팅: Black 등 기존 포맷터와 완벽하게 호환되는 방식으로 코드를 일관되게 정렬합니다.
- 내장 캐싱: 변경되지 않은 파일은 다시 검사하지 않고 건너뛰어 실행 시간을 줄여 줍니다.
- 풍부한 검사 규칙: 900개가 넘는 내장 규칙을 제공하여 다양한 코딩 표준과 플러그인을 대체합니다.

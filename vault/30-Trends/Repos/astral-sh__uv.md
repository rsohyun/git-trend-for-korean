# astral-sh/uv

> 파이썬 패키지와 프로젝트를 매우 빠르게 관리할 수 있는 통합 도구입니다.

## 개요
파이썬 환경 설정과 패키지 설치 과정이 느리고 여러 도구를 따로 써야 하는 불편함을 해결합니다. 기존 pip 명령어를 그대로 대체하면서도 훨씬 빠른 속도로 패키지를 설치하고 가상환경을 관리할 수 있습니다. 전용 설치 명령어로 도구를 내려받은 뒤 명령어 하나로 파이썬 버전 관리부터 패키지 설치까지 처리할 수 있습니다.

## 주요 기능
- 패키지 관리 통합: pip, poetry, virtualenv 등 여러 도구의 기능을 하나의 명령어로 통합해서 사용할 수 있습니다.
- 초고속 패키지 설치: 기존 파이썬 패키지 관리 도구보다 훨씬 빠른 속도로 의존성을 분석하고 설치합니다.
- 파이썬 버전 관리: 별도의 도구 없이 필요한 파이썬 버전을 직접 설치하고 쉽게 전환할 수 있습니다.
- 독립 실행형 스크립트 실행: 단일 파일로 된 파이썬 스크립트의 의존성을 자동으로 관리하고 격리된 환경에서 실행합니다.
- 도구 실행 및 설치: 파이썬 패키지로 배포된 커맨드라인 도구를 임시 또는 영구 환경에 간편하게 설치하고 실행할 수 있습니다.

# block/buzz

> 사람과 AI 에이전트가 같은 방에서 함께 대화하고 코드를 빌드할 수 있는 자체 호스팅 작업 공간 플랫폼입니다.

## 개요
채팅, 코드 관리, CI 대시보드 등이 따로 놀아 발생하는 소통 불편을 해결하는 도구입니다. 모든 메시지와 Git 이벤트가 하나의 이벤트 로그로 기록되어 사람과 에이전트가 동일한 방식으로 협업할 수 있습니다. 사용자는 릴레이 서버를 직접 실행하거나 데스크톱 앱을 연결하여 하나의 통합된 공간에서 팀 작업을 수행할 수 있습니다.

## 주요 기능
- 에이전트 협업: AI 에이전트를 봇이 아닌 팀원처럼 채널에 초대하여 대화와 작업을 함께 진행할 수 있습니다.
- 통합 이벤트 로그: 대화, 패치, 워크플로 실행 결과 등을 하나의 프로토콜과 검색 인덱스로 관리합니다.
- 브랜치 채널: 기능 브랜치가 만들어지면 그에 맞는 방이 생성되어 코드 리뷰와 CI 결과를 한곳에서 볼 수 있습니다.
- 에이전트 CLI: JSON 입출력을 지원하는 에이전트 전용 CLI와 외부 도구 연동 기능을 제공합니다.
- 미디어 댓글: 영상의 특정 프레임에 직접 댓글을 남기고 토론할 수 있습니다.

## 참고·주의
- 릴레이 서버를 로컬에서 구동하려면 Docker 등 별도의 실행 환경이 필요합니다.

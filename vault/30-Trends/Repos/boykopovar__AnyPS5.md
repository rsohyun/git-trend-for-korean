# boykopovar/AnyPS5

> 플레이스테이션 5(PS5)용 프로그램과 게임을 리눅스와 윈도우에서 실행할 수 있는 파일로 자동으로 변환해 주는 도구입니다.

## 개요
플레이스테이션 5 전용 프로그램을 다른 운영체제에서도 실행할 수 있게 바꿔 주는 변환 도구입니다. 복잡한 에뮬레이터나 별도의 실행 과정을 거치지 않고, 시스템에 맞는 형식으로 직접 변환하여 실행 성능을 높여 줍니다. 웹 브라우저나 전용 도구를 통해 파일을 변환하고 필요한 설정을 거쳐 사용할 수 있습니다.

## 주요 기능
- 파일 형식 변환: 플레이스테이션 5용 실행 파일을 리눅스와 윈도우에서 바로 쓸 수 있는 형식으로 바꿔 줍니다.
- 동적 연결 지원: 시스템 라이브러리를 구현하여 원활한 프로그램 실행을 돕습니다.
- 셰이더 재컴파일: 그래픽 처리에 필요한 셰이더 코드를 표준 형식으로 변환합니다.
- 입력 장치 지원: 게임 패드와 키보드, 마우스 조작을 설정하여 사용할 수 있습니다.

## 참고·주의
- 이 도구는 저작권이 있는 소프트웨어나 게임 파일, 암호키를 포함하거나 배포하지 않으며 사용자가 직접 준비해야 합니다.

# cbcoutinho/nextcloud-mcp-server

> 클로드, 지피티 같은 AI 비서가 자연어로 넥스트클라우드 데이터에 접근해 메모, 캘린더, 파일 등을 관리할 수 있게 해 주는 서버 프로그램입니다.

## 개요
이 도구는 외부 AI 비서와 개인 클라우드 저장소인 넥스트클라우드를 서로 연결해 주는 프로그램입니다. AI가 넥스트클라우드 내부의 다양한 앱을 직접 조작하지 못하는 불편을 해결합니다. 사용자는 데스크톱이나 개발환경의 AI 비서 설정에 이 서버를 등록하여 대화하듯 클라우드 데이터를 조회하고 수정할 수 있습니다. 넥스트클라우드와 독립된 별도의 서버로 실행되며 다양한 배포 방식을 지원합니다.

## 주요 기능
- 110개 이상의 도구 제공: 10개 이상의 넥스트클라우드 앱을 포괄하는 상세한 API 기능 제공
- 다양한 앱 지원: 노트, 캘린더, 연락처, 파일, 덱, 요리책, 메일 등 폭넓은 데이터 관리
- 문서 처리: PDF, DOCX, 이미지에서 OCR 및 텍스트 추출 기능 제공
- 시맨틱 검색: 벡터 기반의 실험적 검색을 통해 노트, 파일, 뉴스 등을 의미 기반으로 탐색
- 유연한 배포: 도커, 쿠버네티스, 가상머신 또는 로컬 환경에서 직접 실행 가능
- 태그 기반 파일 제외: 특정 넥스트클라우드 시스템 태그를 지정해 민감한 파일이나 폴더를 AI 접근에서 차단

## 참고·주의
- 넥스트클라우드 계정과 로그인 비밀번호 대신 앱 전용 비밀번호 생성이 필요합니다.

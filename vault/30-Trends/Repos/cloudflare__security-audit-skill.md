# cloudflare/security-audit-skill

> 코딩 에이전트를 보안 감사 도구로 전환해, 다단계 검증과 기계 판독 가능한 결과를 제공하는 스킬입니다.

## 개요
security-audit 스킬은 AI 기반 코딩 에이전트가 코드베이스를 체계적으로 분석하도록 설계되었습니다. Reconnaissance, hunting, 검증 등 6단계 프로세스로 취약점 탐색과 근거 있는 보고서를 자동 생성해, 수동 감사의 불완전성을 해소합니다. 스킬을 설치한 뒤 에이전트에게 ‘security audit <대상>’ 명령을 내리면, 각 단계별 서브 에이전트가 격리 실행되어 findings.json 및 REPORT.md 등 구조화된 파일을 출력합니다. 검증 스크립트는 Node.js만 필요하며, 결과는 JSON 스키마에 맞춰 독립 검증됩니다.

## 주요 기능
- Reconnaissance: 코드 구조·신뢰 경계·입력 표면을 자동 매핑하고 coverage-ledger.json을 생성합니다.
- Coverage-led hunting: 격리된 하운터가 레저 단위별로 검사를 수행해 미탐지 영역을 찾아냅니다.
- Candidate validation: 각 후보 취약점을 새로운 검증 에이전트가 반증 시도해 신뢰성을 확보합니다.
- Structured output: 확인·검증 필요·거부 결과를 findings.json에 기록하고 report-schema.json으로 검증합니다.
- Independent verification: 최종 레코드와 교체된 자료를 별도 에이전트가 다시 검증해 편향을 방지합니다.
- Target-neutral reporting: 검증된 기록을 기반으로 REPORT.md, FINDINGS-DETAIL.md 등을 자동 생성합니다.

## 참고·주의
- 코딩 에이전트가 도구 사용 및 병렬 서브 에이전트를 지원해야 합니다.
- 검증 스크립트 실행을 위해 Node.js가 필요합니다.
- 외부 네트워크 차단·리소스 제한·쓰기 경로 제한 등 OS 수준 샌드박스가 필수입니다.
- 결과 파일은 명시적 디렉터리 지정 시에만 대상 레포에 기록됩니다.

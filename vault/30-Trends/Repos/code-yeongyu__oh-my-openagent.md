# code-yeongyu/oh-my-openagent

> 다양한 AI 모델과 에이전트를 조합해 복잡한 개발 및 리서치 작업을 자동으로 처리해 주는 터미널 기반 AI 에이전트 도구입니다.

## 개요
사용자의 지시를 받아 코드 작성, 대규모 자료 조사, 문서화 등 복잡한 실무 작업을 스스로 수행하는 AI 에이전트 도구입니다. 기존 AI 모델이 문맥을 잊거나 복잡한 작업을 한 번에 처리하지 못하는 불편을 해결합니다. 설치 후 터미널에서 명령어를 실행하고 작업 내용을 입력하면, 내장된 에이전트들이 협력하여 완성된 결과물을 만들어 냅니다.

## 주요 기능
- ultrawork 기능: 복잡한 작업을 시작하기 전에 코드를 분석하고 계획을 세워 단계별로 검증하며 수행
- mass ulw 기능: 프롬프트 하나로 수많은 에이전트를 병렬 그래프 구조로 실행하여 대규모 작업 처리
- 기억 시스템: 이전 작업 기록을 마크다운 파일로 저장하여 에이전트가 실수를 반복하지 않도록 지원
- 다양한 모델 연동: Claude, ChatGPT, Kimi, GLM 등 여러 유료 구독 및 모델을 하나의 환경에서 함께 사용
- 맞춤형 기술 내장: 웹 브라우저 제어 등 실무에 필요한 전문 지식과 기술을 작업에 맞춰 불러와 사용

## 참고·주의
- Claude, ChatGPT, Kimi, GLM 등의 유료 구독 계정이 필요할 수 있습니다.

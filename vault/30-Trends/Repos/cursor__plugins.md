# cursor/plugins

> Cursor 에디터에서 활용할 수 있는 공식 플러그인과 사양을 모아둔 저장소입니다.

## 개요
Cursor AI 에디터의 기능을 확장하여 개발 생산성을 높이고 외부 서비스와 연동할 수 있도록 돕는 도구입니다. 개발 과정에서 반복되는 워크플로우를 자동화하고 코드 품질을 관리하는 데 겪는 불편을 해결합니다. 저장소에서 필요한 플러그인을 선택해 설치하면 에디터 내에서 바로 관련 기능을 활용할 수 있습니다.

## 주요 기능
- 코드 리뷰 및 보안 감사: 작성한 코드를 심층적으로 분석하고 품질을 검토할 수 있습니다.
- 외부 서비스 연동: 구글 드라이브, 지메일, 깃허브 등 다양한 업무 도구를 에디터 내에서 제어할 수 있습니다.
- 에이전트 워크플로우: AI 에이전트가 복잡한 작업을 병렬로 나누어 처리하도록 지시할 수 있습니다.
- 학습 및 기술 매핑: 개발 학습 계획과 회고를 체계적으로 관리할 수 있습니다.
- 플러그인 제작 지원: 새로운 에이전트 플러그인을 직접 만들고 검증할 수 있습니다.

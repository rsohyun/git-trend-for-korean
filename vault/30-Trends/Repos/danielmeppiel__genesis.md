# danielmeppiel/genesis

> AI 코딩 에이전트 시스템을 위한 아키텍처 설계와 다중 에이전트 구성을 지원하는 개발 도구입니다.

## 개요
AI 코딩 에이전트의 지시사항 파일이 비대해지고 복잡해지는 문제를 해결합니다. 에이전트가 코드를 작성하거나 작업을 수행하기 전에 체계적인 구조와 실행 계획을 먼저 설계하도록 돕습니다. 사용자가 에이전트 환경에서 명령어를 실행하면, 여러 에이전트와 규칙이 유기적으로 결합된 모듈형 설계 레이아웃과 실행 계획을 제안받습니다.

## 주요 기능
- 아키텍처 설계 자동화: 복잡한 AI 에이전트 작업에 필요한 다중 에이전트 구조와 규칙을 미리 설계합니다.
- 모듈형 구성: 거대한 지시사항 파일을 역할별로 나누어 에이전트의 집중력 저하와 행동 흔들림을 막습니다.
- 다중 에이전트 조율: 여러 관점의 검토와 의견 조율이 필요한 작업을 체계적으로 분배합니다.
- 다양한 AI 에이전트 지원: Claude Code, Cursor, GitHub Copilot 등 여러 개발 환경에서 바로 불러와 사용할 수 있습니다.

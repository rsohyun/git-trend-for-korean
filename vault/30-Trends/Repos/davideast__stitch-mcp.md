# davideast/stitch-mcp

> 구글 스티치(Stitch) 플랫폼에서 생성된 AI UI 디자인을 로컬 개발 환경으로 가져와 미리 보거나 웹사이트를 구축하고, AI 코딩 도구와 연동할 수 있게 해 주는 명령줄 도구입니다.

## 개요
구글 스티치 플랫폼의 AI 디자인을 로컬 환경으로 가져오려면 API를 통해 코드를 내려받고 구조화해야 하는 불편함이 있습니다. 이 도구는 간단한 명령어로 디자인 화면을 로컬 서버에서 미리 보거나, 아스트로(Astro) 웹사이트 프로젝트로 변환할 수 있게 해 줍니다. 또한 MCP(AI 에이전트가 외부 도구를 호출하는 표준 방식)를 지원하는 코딩 에이전트에 디자인 데이터를 전달하여 에이전트가 직접 화면 구조를 파악하고 코드를 작성하도록 돕습니다. 사용자는 명령줄에서 인증을 마치고 필요한 기능을 실행하여 디자인 데이터를 자유롭게 활용할 수 있습니다.

## 주요 기능
- 로컬 디자인 미리 보기: 프로젝트의 모든 화면을 로컬 개발 서버에서 웹 브라우저로 띄워 볼 수 있습니다.
- 웹사이트 프로젝트 생성: 디자인 화면들을 라우트에 연결하여 배포 가능한 아스트로 웹사이트로 자동 변환합니다.
- AI 에이전트 디자인 연동: IDE의 코딩 에이전트에 스티치 도구와 디자인 맥락을 프록시 형태로 전달합니다.
- 터미널 디자인 탐색: 터미널에서 프로젝트와 화면 메타데이터를 확인하고 클립보드 복사나 미리 보기를 실행할 수 있습니다.
- 간편한 설정 마법사: 한 번의 명령어로 인증과 MCP 클라이언트 설정을 안내받아 쉽게 시작할 수 있습니다.

## 참고·주의
- 구글 스티치 API 접근 권한, 구글 클라우드 계정 및 결제 활성화가 필요합니다.
- 이 도구는 구글과 공식적으로 관련이 없는 실험적인 프로젝트입니다.

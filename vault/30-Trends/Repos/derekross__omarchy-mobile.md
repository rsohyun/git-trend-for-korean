# derekross/omarchy-mobile

> 구형 픽셀 스마트폰에 아치 리눅스와 전용 사용자 인터페이스를 직접 설치하여 리눅스 모바일 환경을 쓸 수 있게 해 주는 도구입니다.

## 개요
모바일 기기에서 안드로이드 대신 리눅스 운영체제를 네이티브로 구동할 수 있게 해 주는 도구입니다. 기존 스마트폰 운영체제의 제약과 안드로이드 중심 환경에서 벗어나 리눅스 기반 커스텀 환경을 사용하고 싶어 하는 문제를 해결합니다. 사용자는 호환되는 스마트폰에 툴을 통해 시스템 이미지를 빌드하고 설치하여 리눅스 기반의 모바일 환경을 부팅하고 사용할 수 있습니다.

## 주요 기능
- 시스템 패키지 빌드: 아치 리눅스 ARM 기반의 모바일 전용 패키지를 직접 빌드할 수 있습니다.
- 루트 파일시스템 생성: 리눅스 커널과 셸 환경이 포함된 부팅용 루트 이미지를 만듭니다.
- 폰 설치 도구: 패스트부트 모드를 통해 기기에 안전하게 부팅 이미지를 설치합니다.
- 모뎀 및 센서 지원: 통신 모뎀, 화면 자동 회전, 카메라 등의 하드웨어 기능을 제어합니다.
- 화면 미러링: USB 연결을 통해 컴퓨터 화면에서 폰 화면을 그대로 보고 조작할 수 있습니다.

## 참고·주의
- 부트loader가 잠금 해제된 Pixel 7 Pro 등의 지원 기기가 필요합니다.
- 설치 과정에서 기기의 기존 사용자 데이터가 모두 삭제됩니다.
- 안정 버전이 아니므로 설치 및 사용 시 오류가 발생할 수 있습니다.

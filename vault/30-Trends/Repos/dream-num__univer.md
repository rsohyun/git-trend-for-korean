# dream-num/univer

> 스프레드시트와 문서 편집 기능을 웹 제품에 직접 넣을 수 있게 해 주는 오픈소스 오피스 SDK입니다.

## 개요
웹 애플리케이션에 오피스 편집, 계산, 공동 작업 기능을 구현할 수 있는 도구입니다. 자체 오피스 프로그램을 개발할 때 필요한 편집기와 데이터 처리 기능을 직접 구현해야 하는 번거로움을 해결합니다. 웹사이트에 코드를 연동하여 사용자가 브라우저에서 직접 문서를 편집하고 계산 기능을 사용할 수 있도록 구성합니다. 핵심 오픈소스 엔진을 통해 시트와 문서 편집 환경을 자유롭게 확장할 수 있습니다.

## 주요 기능
- 시트 편집 및 레이아웃: 셀 서식, 병합, 틀 고정, 부동 이미지, 실행 취소 및 다시 실행 기능을 제공합니다.
- 데이터 및 계산: 수식, 필터링, 정렬, 데이터 유효성 검사, 조건부 서식을 지원합니다.
- 문서 편집: 서식 있는 텍스트 편집, 문단 서식, 목록, 댓글 기능을 제공합니다.
- 플러그인 구조: 필요한 기능만 선택해서 조합할 수 있는 확장 가능한 아키텍처를 제공합니다.

## 참고·주의
- 일부 상업용 플러그인과 서버 및 AI 확장 기능은 별도로 배포 및 라이선스가 적용됩니다.

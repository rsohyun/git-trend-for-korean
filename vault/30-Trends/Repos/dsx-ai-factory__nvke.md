# dsx-ai-factory/nvke

> 자체 NVIDIA GPU 인프라에서 관리형 쿠버네티스(Kubernetes) 클러스터를 손쉽게 만들고 운영할 수 있게 해 주는 관리 도구입니다.

## 개요
엔비디아(NVIDIA) 하드웨어 환경에서 쿠버네티스 클러스터를 직접 구성하고 관리해야 하는 플랫폼 팀의 번거로움을 해결해 주는 프로그램입니다. 임시 시드(Seed) 클러스터로 관리 제어판을 구성한 뒤, 전용 API나 명령어를 통해 독립된 쿠버네티스 작업 클러스터를 생성하고 확장할 수 있습니다. 이를 통해 사용자는 자체 GPU 인프라 위에 격리된 쿠버네티스 환경을 구축하고 노드 그룹을 손쉽게 관리할 수 있습니다.

## 주요 기능
- 독립된 작업 클러스터 생성: API나 전용 명령어를 통해 고유한 제어판을 가진 쿠버네티스 클러스터를 만들 수 있습니다.
- 클러스터 생명주기 관리: 노드 그룹 생성 및 크기 조절, 쿠버네티스 버전 업그레이드 작업을 수행할 수 있습니다.
- 안전한 노드 인증: 하드웨어 보안 모듈(TPM)과 인증서를 활용해 신뢰할 수 있는 노드만 클러스터에 참여시킵니다.

## 참고·주의
- 프리뷰 단계의 프로그램이므로 실제 운영 환경(Production)에서 사용하는 것은 권장하지 않습니다.
- 설치 직후에는 API 인증이 꺼져 있고 일반 HTTP 통신을 사용하므로 별도 설정이 필요합니다.
- 관리 클러스터 자체의 자동 업그레이드나 백업 및 복구 기능은 지원하지 않습니다.

# earthtojake/text-to-cad

> AI 에이전트가 자연어 요청을 받아 3D 모델을 설계하고 제작용 파일로 만들어 주는 개발자용 도구입니다.

## 개요
이 도구는 AI 에이전트가 3D 모델링 작업을 직접 수행할 수 있도록 로컬 작업 흐름을 제공합니다. 3D 모델을 코드로 작성하고 시각화하는 과정의 번거로움을 해결합니다. 설치 후 에이전트에게 원하는 부품이나 조립품을 요청하면, 에이전트가 코드를 작성해 3D 모델을 만들고 전용 뷰어로 보여줍니다.

## 주요 기능
- 3D 모델 생성: 자연어 요청을 받아 STEP, GLB, STL, 3MF 형식의 3D 모델을 생성합니다.
- 표준 부품 검색: 나사, 베어링, 모터 같은 시중의 표준 부품을 쉽게 찾아줍니다.
- 엔지니어링 도면 작성: 부품 도면을 PDF 형식의 치수 도면으로 변환해 줍니다.
- 제조 적합성 검토: 3D 프린팅이나 CNC 가공 전에 제조 가능 여부를 미리 검사합니다.
- 로봇 구조 파일 작성: 로봇 설계에 필요한 URDF 및 SRDF 파일을 생성합니다.
- 프린터 연동: 모델을 G-code로 변환하거나 프린터로 직접 보낼 수 있습니다.

# elementalsouls/Claude-BugHunter

> Claude Code에 버그 사냥과 외부 모의 해킹(Red-team) 전문 지식을 추가해 주는 도구 모음입니다.

## 개요
인터넷에 노출된 웹 애플리케이션과 기업 인프라의 취약점을 찾고 분석하는 과정을 돕습니다. 보안 점검 시 수백 건의 실제 취약점 보고서 패턴을 바탕으로 상황에 맞는 공격 기법과 대응책을 자동으로 제시합니다. 사용자는 터미널에서 점검 대상을 자연어로 설명하기만 하면 AI가 적절한 분석 기술과 방법론을 불러와 작업을 수행합니다.

## 주요 기능
- 취약점 탐지 기술: 실제 해킹 보고서 패턴을 바탕으로 웹 앱과 API의 취약점을 정밀하게 찾을 수 있습니다.
- 기업 인프라 분석: 클라우드, 인증 시스템, VPN 등 외부 노출 자산의 보안 위험을 진단합니다.
- 자동 방법론 적용: 점검 대상에 맞춰 5단계 비선형 작업 흐름과 보안 전문가의 사고방식을 자동으로 적용합니다.
- 검증 및 보고서 작성: 발견된 취약점의 심각도를 평가하고 격리 및 보고서 작성을 지원합니다.

## 참고·주의
- 권한이 없는 시스템이나 네트워크를 대상으로 사용할 경우 법적 문제가 발생할 수 있으므로 허가된 대상에만 사용해야 합니다.

# elie222/rakazo

> 직접 호스팅하여 기억, 루틴, 가상 컴퓨터를 활용하는 오픈소스 AI 에이전트 협업 프로그램입니다.

## 개요
사용자가 직접 모델과 실행 환경을 선택해 자신만의 AI 팀원을 만들 수 있는 도구입니다. AI가 직접 브라우저와 터미널을 조작하며 업무를 처리하고 공유 문서를 작성하지 못하는 불편을 해결합니다. 설치 후 웹이나 앱에서 계정을 만들고 API 키를 연결하면 AI와 대화하며 작업을 맡길 수 있습니다.

## 주요 기능
- 루틴: 정해진 일정이나 이메일, 웹훅에 맞춰 AI 에이전트를 자동으로 실행할 수 있습니다.
- 메모리: AI가 이전 대화와 중요한 정보를 기억하여 지속적인 작업에 활용합니다.
- 컴퓨터와 브라우저 사용: AI가 가상의 컴퓨터 환경에서 브라우저와 터미널을 직접 조작해 일합니다.
- 그룹 채팅: 여러 AI를 한 대화방에 모아 서로 역할을 나누고 협업하게 만들 수 있습니다.
- 대시보드와 문서 제작: AI가 작업 결과를 바탕으로 공유 가능한 웹 페이지와 문서를 직접 만듭니다.
- 앱 연동: 지메일, 슬랙, 깃허브 등 수많은 외부 서비스와 MCP를 연결해 사용할 수 있습니다.

## 참고·주의
- 설치를 위해 Docker Engine, Compose 플러그인, curl, OpenSSL이 필요합니다.

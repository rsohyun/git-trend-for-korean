# esengine/estella

> AI 에이전트가 에디터 내부의 181개 도구를 직접 사용해 2D 및 3D 게임을 제작하고 배포할 수 있는 게임 엔진입니다.

## 개요
AI 에이전트와 게임 에디터를 연동하여 직접 코드를 짜거나 마우스로 조작하지 않고도 게임을 만들 수 있는 도구입니다. 기존 게임 에디터는 사람이 직접 UI를 조작해야 하는 번거로움이 있지만, 이 엔진은 MCP(AI 에이전트가 외부 도구를 호출하는 표준 방식)를 지원하여 에이전트가 화면을 보고 스스로 수정할 수 있습니다. 사용자는 AI 에이전트에게 원하는 게임 기능을 지시하고 화면 캡처나 실행 결과를 확인하며 게임을 완성할 수 있습니다.

## 주요 기능
- 에이전트 제어: Claude Code나 Cursor 같은 MCP 클라이언트를 연결해 에이전트가 에디터를 직접 조작할 수 있습니다.
- 에디터 연동 도구: 181개의 도구를 통해 오브젝트 생성, 컴포넌트 수정, 타일맵 편집 등을 수행할 수 있습니다.
- 시각적 검증: 에이전트가 실행 중인 게임의 스크린샷을 찍고 프레임을 분석하여 스스로 오류를 점검할 수 있습니다.
- 에셋 제작: 에이전트가 직접 이미지, 효과음, 음악, 3D 모델 등의 게임 에셋을 만들 수 있습니다.
- 다양한 플랫폼 배포: 완성된 게임을 웹, 미니게임 플랫폼, 데스크톱, 모바일 기기로 곧바로 내보낼 수 있습니다.

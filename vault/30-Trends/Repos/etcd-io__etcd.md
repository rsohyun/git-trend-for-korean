# etcd-io/etcd

> 분산 시스템의 핵심 데이터를 안전하게 저장하고 관리할 수 있게 해 주는 분산 키-값 저장소입니다.

## 개요
etcd는 분산 시스템에서 중요한 데이터를 안정적으로 보관하기 위해 사용하는 키-값 저장소입니다. 여러 서버에 데이터를 복제하여 일부 서버가 고장 나도 시스템이 멈추지 않도록 돕습니다. 사용자는 전용 명령줄 도구나 API를 통해 데이터를 저장하고 조회할 수 있습니다.

## 주요 기능
- 단순한 API: gRPC 기반의 명확한 사용자 인터페이스를 제공합니다.
- 보안 기능: 자동 TLS 인증과 클라이언트 인증서를 지원합니다.
- 고성능: 초당 1만 건 이상의 쓰기 연산을 처리할 수 있습니다.
- 안정성: Raft 합의 알고리즘을 사용해 데이터를 분산 관리합니다.

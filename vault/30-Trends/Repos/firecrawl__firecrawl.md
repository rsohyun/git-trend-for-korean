# firecrawl/firecrawl

> 웹사이트를 AI가 읽기 쉬운 마크다운이나 구조화된 데이터로 바꿔 주고, AI 에이전트와 연동할 수 있게 해 주는 지식 인프라 도구입니다.

## 개요
웹사이트의 복잡한 구조와 자바스크립트(동적 웹 페이지 렌더링 기술) 때문에 AI가 웹 데이터를 직접 수집하기 어려운 문제를 해결합니다. 사용자는 로컬 기기나 클라우드 API를 통해 웹페이지를 긁어오거나(스크래핑), 사이트 전체를 탐색(크롤링)하고, AI 에이전트용 도구로 바로 연결할 수 있습니다. 로컬 환경에서는 명령어 도구나 MCP(AI 에이전트가 외부 도구를 호출하는 표준 방식) 서버로 동작하며, 대규모 작업은 클라우드 서비스와 연동해 처리합니다.

## 주요 기능
- 웹페이지 변환: 웹사이트를 깔끔한 마크다운 문서나 구조화된 데이터로 바꿉니다.
- 사이트 탐색: 웹사이트의 전체 페이지를 크롤링하거나 URL 목록을 추출합니다.
- 문서 분석: PDF와 오피스 문서를 로컬에서 직접 읽어와 텍스트로 변환합니다.
- AI 에이전트 연동: Claude, Cursor 등 주요 AI 도구에 MCP 서버로 간편하게 추가합니다.
- 로컬 API 제공: 로컬 기기에서 파이어크롤(Firecrawl) API 서버를 띄워 기존 코드를 그대로 실행합니다.

## 참고·주의
- 로컬에서 실행하려면 러스트(Rust) 환경과 C 컴파일러가 필요합니다.
- AI 에이전트 연동 기능인 MCP 서버는 노드제이에스(Node.js) 22 버전 이상이 필요합니다.

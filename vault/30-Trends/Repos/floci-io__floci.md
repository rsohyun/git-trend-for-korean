# floci-io/floci

> 클라우드 계정이나 유료 구독 없이 로컬 환경에서 AWS 기능을 그대로 테스트할 수 있는 오픈소스 에뮬레이터입니다.

## 개요
로컬 환경에서 AWS(Amazon Web Services) 기반 개발과 테스트를 수행할 수 있도록 돕는 도구입니다. 실제 클라우드 계정, 인증 토큰, 유료 요금제 없이도 AWS 환경을 똑같이 흉내 내어 비용과 설정의 번거로움을 해결해 줍니다. Docker나 제공되는 전용 명령어로 실행한 뒤 기존 AWS 도구의 접속 주소를 로컬 주소로 지정하기만 하면 바로 사용할 수 있습니다.

## 주요 기능
- 로컬 AWS 에뮬레이션: 클라우드 계정이나 유료 인증 없이 로컬에서 AWS 서비스들을 사용할 수 있습니다.
- 기존 도구 호환: AWS SDK, CLI, Terraform 등을 수정 없이 그대로 로컬 에뮬레이터에 연결할 수 있습니다.
- 웹 콘솔 제공: 브라우저로 로컬 에뮬레이터에 생성된 리소스를 시각적으로 확인하고 관리할 수 있습니다.
- LocalStack 대체: 기존 LocalStack 환경에서 이미지 교체만으로 간편하게 전환할 수 있습니다.

## 참고·주의
- 도커 환경 혹은 지원되는 운영체제별 단독 실행 파일이 필요합니다.

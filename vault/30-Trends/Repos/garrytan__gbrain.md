# garrytan/gbrain

> 여러 AI 에이전트가 공통으로 사용할 수 있는 외부 기억 저장소를 만들어, 사용자의 메모와 사실 관계를 일관되게 관리해 주는 도구입니다.

## 개요
AI 에이전트마다 기억이 따로 놀아 중요한 맥락을 잃어버리는 문제를 해결합니다. 회의록, 이메일, 메모 등의 사실 정보를 출처와 함께 저장하고 필요할 때 출처가 포함된 정확한 답변과 분석을 제공합니다. 사용자는 기존에 쓰던 에이전트에 기억 기능을 붙이거나 원격으로 연결하여 명령어 한 줄로 에이전트가 공통 기억을 조회하게 만들 수 있습니다. 키워드 검색부터 의미 기반 검색, 자동 요약, 지식 그래프 구축까지 점진적으로 기능을 확장할 수 있습니다.

## 주요 기능
- 메모 공유: 여러 AI 에이전트가 동일한 기억 저장소를 함께 사용할 수 있습니다.
- 출처 기반 답변: 단순 문서 목록이 아니라 출처와 누락된 정보까지 포함된 완성된 답변을 제공합니다.
- 원격 접근: 명령어 하나로 MCP(AI 에이전트가 외부 도구를 호출하는 표준 방식)를 통해 언제 어디서나 기억 저장소에 접근할 수 있습니다.
- 지식 그래프: 인물과 회사 간의 관계를 구조화하여 빠르고 정확하게 연관 정보를 조회합니다.
- 자동 정돈: 백그라운드에서 내용을 스스로 정리하고 출처를 검증하며 기억을 최신 상태로 유지합니다.

## 참고·주의
- 상시 운영과 배경 데이터 정리를 위해서는 별도의 컴퓨팅 자원과 모델 API 설정이 필요합니다.
- 공유 접근 기능을 설정할 때는 민감한 로컬 파일이나 데이터베이스 권한 범위를 주의 깊게 확인해야 합니다.

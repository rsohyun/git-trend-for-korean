# garrytan/gstack

> Claude Code 등의 AI 코딩 도구를 CEO부터 QA까지 전담 역할 팀으로 만들어 주는 가상 엔지니어링 팀 도구입니다.

## 개요
AI 코딩 도구를 사용할 때 기획부터 아키텍처 검토, QA, 배포까지 체계적으로 관리할 수 있게 돕습니다. 빈 프롬프트 대신 정해진 역할과 슬래시 명령어를 통해 제품 구조를 설계하고 버그를 찾을 수 있습니다. 설치 후 명령어 몇 개로 개발 과정 전반을 AI와 함께 진행하고 결과물을 얻을 수 있습니다.

## 주요 기능
- 기획 검토: 아이디어를 구체화하고 디자인 문서를 자동으로 작성합니다.
- 코드 검토: CI를 통과하더라도 실서비스에서 발생할 수 있는 잠재적 버그를 찾고 수정합니다.
- 브라우저 QA: 실제 브라우저를 열어 버그를 재현하고 검증합니다.
- 보안 감사: OWASP 및 STRIDE 기준에 따라 보안 취약점을 검사합니다.

## 참고·주의
- Claude Code, Git, Bun v1.4.2 이상이 필수로 필요합니다.
- macOS에서는 Aside 브라우저를 권장하며, 일부 기능은 네이티브 도구 체인이 필요합니다.

# getarcaneapp/arcane

> 복잡한 명령어 없이 웹 화면에서 도커(Docker) 컨테이너를 쉽게 관리하고 모니터링할 수 있는 프로그램입니다.

## 개요
도커 컨테이너를 관리할 때 겪는 복잡한 설정과 명령어 입력의 번거로움을 해결해 주는 도구입니다. 웹 기반의 대시보드를 통해 누구나 직관적으로 컨테이너 상태를 확인하고 제어할 수 있습니다. 프로그램 설치 후 웹 브라우저에서 대시보드에 접속해 컨테이너와 관련된 다양한 작업을 수행하면 됩니다.

## 주요 기능
- 웹 대시보드 관리: 복잡한 명령어 없이 웹 화면에서 도커 컨테이너를 손쉽게 다룰 수 있습니다.
- 상태 모니터링: 실행 중인 컨테이너의 상태와 운영 상황을 한눈에 파악할 수 있습니다.
- 다국어 지원: Crowdin을 통해 여러 언어로 번역되어 다양한 언어 환경에서 쓸 수 있습니다.

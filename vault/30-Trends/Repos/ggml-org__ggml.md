# ggml-org/ggml

> 다양한 기기에서 머신러닝 모델을 가볍고 빠르게 실행할 수 있도록 도와주는 텐서(데이터 배열) 연산 라이브러리입니다.

## 개요
머신러닝 모델을 다양한 하드웨어에서 효율적으로 구동할 수 있게 해 주는 도구입니다. 복잡한 외부 의존성 없이 C와 C++로만 작성되어 설치와 실행이 매우 간편합니다. 소스 코드를 내려받아 빌드한 뒤 제공되는 예제를 통해 행렬 연산 등을 수행할 수 있습니다. 다양한 프로세서와 그래픽카드 환경에서 최적화된 성능을 냅니다.

## 주요 기능
- 외부 의존성 없는 구현: 추가 프로그램 설치 없이 C와 C++만으로 간편하게 빌드하고 실행할 수 있습니다.
- 폭넓은 기기 지원: 다양한 컴퓨터 아키텍처와 웹 브라우저 환경에서 동작합니다.
- 다양한 하드웨어 가속: CPU와 GPU 등 다양한 장치를 백엔드로 활용해 연산 속도를 높여 줍니다.
- 효율적인 데이터 압축: 정수 양자화와 미세조정 포맷을 지원해 모델 크기를 줄이고 메모리 사용량을 아껴 줍니다.

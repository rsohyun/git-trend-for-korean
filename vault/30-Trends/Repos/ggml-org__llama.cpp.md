# ggml-org/llama.cpp

> 다양한 하드웨어 환경에서 대형 언어 모델(LLM)을 빠르게 실행할 수 있게 해 주는 C/C++ 기반의 인프런스 도구입니다.

## 개요
다양한 하드웨어 환경에서 대형 언어 모델과 비전 언어 모델을 최소한의 설정으로 빠르게 실행하는 도구입니다. 고성능 장비가 없거나 다양한 기기에서 모델을 직접 구동하고 싶을 때 발생하는 성능 저하 문제를 해결합니다. 사용자는 설치 후 명령어를 통해 모델을 내려받아 바로 실행하거나 API 서버로 띄워 웹 화면에서 활용할 수 있습니다.

## 주요 기능
- 모델 양자화: 1.5비트부터 8비트까지 정수 양자화를 지원하여 실행 속도를 높이고 메모리 사용량을 줄입니다.
- 다양한 하드웨어 지원: 애플 실리콘, 엔비디아 GPU, AMD GPU 등 다양한 기기에서 모델을 최적화하여 실행할 수 있습니다.
- CPU와 GPU 혼합 연산: 그래픽카드 메모리 용량보다 큰 모델을 CPU와 나누어 처리할 수 있습니다.
- API 서버 제공: 오픈AI 호환 API 서버를 띄워 내장된 웹 인터페이스나 다른 프로그램과 연결할 수 있습니다.
- 명령줄 도구: 터미널 환경에서 모델을 내려받고 대화나 이미지 분석 세션을 바로 시작할 수 있습니다.

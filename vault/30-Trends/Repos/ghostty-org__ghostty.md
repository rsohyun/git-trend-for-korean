# ghostty-org/ghostty

> 그래픽카드 가속과 운영체제 맞춤형 인터페이스를 지원하여 속도와 기능을 모두 챙긴 터미널 에뮬레이터입니다.

## 개요
기존 터미널 프로그램들이 속도와 기능, 운영체제 기본 인터페이스 중 일부를 포기해야 했던 문제를 해결합니다. 그래픽 처리 장치(GPU) 가속과 다중 스레드 구조를 활용해 매우 빠른 속도로 화면을 그려냅니다. 사용자는 운영체제에 최적화된 창 관리 기능과 다양한 부가 기능을 갖춘 터미널 환경을 바로 이용할 수 있습니다.

## 주요 기능
- 빠른 속도: 그래픽카드 가속과 멀티스레딩 구조를 사용하여 지연 없는 빠른 화면 출력을 제공합니다.
- 운영체제 맞춤형 화면: 맥OS에서는 네이티브 인터페이스를 사용하고, 리눅스에서는 GTK를 사용하여 각 환경에 어울리는 자연스러운 UI를 제공합니다.
- 창 관리 기능: 여러 개의 창, 탭, 화면 분할 기능을 지원하여 작업을 체계적으로 정리할 수 있습니다.
- 표준 호환성: 주요 표준 규격과 xterm 동작을 폭넓게 지원하여 기존의 모든 터미널 프로그램을 문제없이 실행합니다.
- 내장 라이브러리 제공: 다른 프로그램에서도 터미널 기능을 쉽게 가져다 쓸 수 있도록 C와 Zig 언어 기반의 라이브러리를 제공합니다.

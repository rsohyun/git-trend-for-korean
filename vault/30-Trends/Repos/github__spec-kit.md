# github/spec-kit

> AI 코딩 에이전트가 체계적인 명세 기반 개발과 문제 해결 과정을 따르도록 돕는 도구 모음입니다.

## 개요
AI 코딩 에이전트가 주관적으로 코드를 작성하면서 생기는 품질 저하와 방향 상실 문제를 해결합니다. 개발자가 명세 중심 개발, 버그 수정, 아이디어 검증 등의 표준화된 절차를 선택하면 에이전트가 이에 맞춰 계획을 세우고 실행합니다. 사용자는 명령어를 통해 프로젝트를 초기화하고 에이전트와 대화하며 구조화된 개발 결과를 얻을 수 있습니다.

## 주요 기능
- 사전 정의된 프로세스: 기능 개발, 버그 수정, 아이디어 검증 등 목적에 맞는 개발 단계를 제공합니다.
- 에이전트 연동: GitHub Copilot 등 다양한 AI 코딩 에이전트와 연결하여 사용할 수 있습니다.
- 템플릿 및 프리셋 커스텀: 프로젝트 환경이나 조직 기준에 맞춰 템플릿과 용어를 바꿀 수 있습니다.
- 확장 기능 및 워크플로우: 외부 도구를 연결하거나 자동화된 작업 단계를 추가할 수 있습니다.
- 카탈로그 검색: 커뮤니티나 조직이 공유하는 컴포넌트를 검색하고 설치할 수 있습니다.

## 참고·주의
- Python 3.11 이상 버전과 uv 패키지 관리자가 필요합니다.
- 커뮤니티 카탈로그의 소스 코드는 설치 및 실행 전에 직접 검토해야 합니다.

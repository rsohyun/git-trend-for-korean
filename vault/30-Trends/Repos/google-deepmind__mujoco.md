# google-deepmind/mujoco

> 로봇 공학, 머신러닝, 생체 역학 등에서 활용되는 빠르고 정확한 범용 물리 시뮬레이터입니다.

## 개요
로봇이나 관절 구조물이 환경과 상호작용하는 물리 현상을 정밀하게 시뮬레이션하는 도구입니다. 복잡한 물리 계산을 빠르게 처리해야 하는 연구 및 개발 과정의 어려움을 해결해 줍니다. 사용자는 웹 브라우저에서 모델을 바로 테스트하거나, C 언어 API 및 파이썬 패키지를 설치해 시뮬레이션을 실행하고 결과를 얻을 수 있습니다.

## 주요 기능
- 웹 브라우저 지원: 설치 없이 웹에서 바로 물리 모델을 시각화하고 조작할 수 있습니다.
- 파이썬 연동: 파이썬 패키지를 설치하여 시뮬레이션과 머신러닝 모델을 함께 다룰 수 있습니다.
- 다양한 플랫폼 지원: 리눅스, 윈도우, 맥OS에서 사전 빌드된 바이너리를 사용할 수 있습니다.
- 유니티 엔진 연동: C# 바인딩과 유니티 플러그인을 통해 게임 엔진에서도 활용할 수 있습니다.

## 참고·주의
- 파이썬 버전 3.11 이상이 필요합니다.

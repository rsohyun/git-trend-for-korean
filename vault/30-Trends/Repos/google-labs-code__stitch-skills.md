# google-labs-code/stitch-skills

> Google Stitch 환경에서 코딩 에이전트가 디자인 작업과 코드 생성을 수행할 수 있도록 돕는 에이전트 스킬 모음입니다.

## 개요
AI 코딩 에이전트가 디자인 도구와 원활하게 연동되지 않아 수동으로 화면을 옮기거나 코드를 작성해야 하는 불편함을 해결합니다. 사용자는 프로젝트 환경에 플러그인을 설치하고 에이전트에게 디자인 생성이나 컴포넌트 변환을 지시할 수 있습니다. 이를 통해 에이전트가 디자인 시스템을 관리하고 프론트엔드 코드를 자동으로 만들어 줍니다.

## 주요 기능
- 코드 디자인 변환: 프론트엔드 코드를 분석해 Stitch 디자인으로 변환하고 업로드할 수 있습니다.
- 화면 자동 생성: 텍스트나 이미지 기반으로 새로운 화면을 만들고 디자인 시안을 여러 개 생성할 수 있습니다.
- 디자인 시스템 관리: 디자인 규칙 문서인 DESIGN.md를 업로드하고 화면에 일괄 적용할 수 있습니다.
- React 컴포넌트 생성: Stitch 디자인을 검증된 React 컴포넌트 시스템으로 자동 변환합니다.
- React Native 지원: 디자인 시안을 모바일 앱 개발용 React Native 코드로 변환할 수 있습니다.
- 동영상 생성: Stitch 프로젝트 화면을 부드러운 전환 효과가 포함된 둘러보기 영상으로 제작할 수 있습니다.

## 참고·주의
- 사용하려면 Google Stitch MCP 서버가 환경에 미리 설정되어 실행 중이어야 합니다.

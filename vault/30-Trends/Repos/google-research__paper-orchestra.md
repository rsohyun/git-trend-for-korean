# google-research/paper-orchestra

> 아이디어와 실험 기록을 바탕으로 학회 제출용 LaTeX 논문을 자동으로 작성해 주는 다중 에이전트 프레임워크입니다.

## 개요
연구 아이디어와 실험 로그 같은 원시 연구 자료를 학회 제출용 논문으로 바꿔 주는 도구입니다. 연구자가 직접 논문 초안을 작성하고 문헌을 조사해야 하는 번거로움을 해결해 줍니다. 여러 전문 에이전트가 협력하여 목차 구성, 문헌 조사, 본문 작성, 내용 수정, 시각화 작업을 차례대로 수행합니다. 사용자는 연구 자료와 논문 템플릿 경로를 지정하여 실행하면 완성된 LaTeX 원고와 생성된 시각 자료를 얻을 수 있습니다.

## 주요 기능
- 다중 에이전트 파이프라인: 목차, 문헌 조사, 본문 작성, 내용 다듬기, 시각화 등 역할별 에이전트가 협력해 논문을 처음부터 끝까지 작성합니다.
- 종합적 문헌 조사: 관련 논문을 자동으로 검색하고 우선순위를 매겨 원고에 자연스럽게 녹여냅니다.
- 시각화 자료 생성: 논문에 들어갈 그래프를 그리고 개념 다이어그램을 포함할 수 있도록 지원합니다.
- LaTeX 자동화: 목표로 하는 학회의 양식 템플릿에 맞춘 제출용 LaTeX 원고를 만들어 냅니다.

## 참고·주의
- 논문 생성을 위한 연구 데이터셋은 이 저장소에 포함되어 있지 않으며 추후 별도로 공개될 예정입니다.
- AI 모델을 사용하기 위해 OpenAI, Vertex AI, Gemini 등의 API 키가 필요합니다.

# harry0703/MoneyPrinterTurbo

> 주제나 키워드만 입력하면 AI가 대본 작성부터 자막, 배경음악, 영상 소재 매칭까지 자동으로 처리해 고화질 단편 영상을 만들어 주는 도구입니다.

## 개요
수동으로 영상 편집과 소재를 찾느라 시간을 낭비하는 문제를 해결해 주는 AI 기반 쇼츠 영상 자동 제작 도구입니다. 사용자는 웹 화면이나 API를 통해 영상 주제만 입력하면, AI가 자동으로 전체 대본을 짜고 어울리는 화면과 음악을 조합해 완성된 영상 파일을 만들어 줍니다. 다양한 AI 언어 모델과 미디어 API를 연동하여 누구나 손쉽게 고품질 콘텐츠를 대량으로 생산할 수 있습니다.

## 주요 기능
- 자동 대본 생성: 입력한 주제와 키워드를 바탕으로 AI가 쇼츠 영상용 대본을 작성합니다.
- 맞춤 소재 매칭: 대본 내용에 가장 잘 어울리는 이미지와 영상 클립을 자동으로 찾아 배치합니다.
- 자막 및 음성 합성: 영상에 필요한 자막을 자동으로 생성하고 자연스러운 내레이션을 입힙니다.
- 배경음악 추가: 영상 분위기에 맞는 배경음악을 자동으로 더해 완성도를 높입니다.
- 웹 인터페이스 제공: 직관적인 웹 화면(WebUI)을 통해 코딩 없이 버튼 클릭만으로 영상을 만들 수 있습니다.

## 참고·주의
- AI 모델 연동을 위해 외부 서비스의 API Key나 유료 크레딧이 필요할 수 있습니다.

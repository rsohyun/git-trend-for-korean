# herdrdev/herdr

> AI 코딩 에이전트와 터미널 작업을 백그라운드에서 안정적으로 실행하고 관리할 수 있는 개발자용 런타임입니다.

## 개요
여러 AI 코딩 에이전트를 동시에 실행할 때 터미널 창이 닫히거나 연결이 끊어져 작업이 중단되는 문제를 해결합니다. 백그라운드 서버에서 에이전트와 터미널 상태를 유지하며, 명령어 입력으로 언제든지 작업 화면을 다시 불러올 수 있습니다. 가벼운 러스트(Rust) 단일 파일로 동작하여 기존에 사용하던 터미널에서 바로 실행할 수 있습니다.

## 주요 기능
- 작업 분리 유지: 터미널 창을 닫거나 원격 연결이 끊어져도 백그라운드에서 작업을 계속 유지합니다.
- 원격 머신 통합 관리: 여러 컴퓨터의 로컬 작업과 원격 접속 화면을 하나의 창에서 함께 관리합니다.
- 상태 표시 기능: 모든 창의 에이전트가 작업 중인지, 멈춰 있는지, 답변을 기다리는지 한눈에 파악할 수 있습니다.
- 에이전트 연동 지원: 명령어와 소켓 API를 통해 에이전트가 직접 창을 열거나 다른 에이전트와 상호작용할 수 있습니다.
- 키보드와 마우스 지원: 단축키와 마우스 클릭, 드래그 화면 분할을 모두 지원합니다.

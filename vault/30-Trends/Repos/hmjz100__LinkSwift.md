# hmjz100/LinkSwift

> 다양한 중국 클라우드 스토리지의 파일 직링크를 브라우저에서 바로 얻어 다운로드할 수 있게 해 주는 Tampermonkey 사용자 스크립트입니다.

## 개요
이 스크립트는 웹 브라우저에서 동작하는 사용자 스크립트로, 주요 중국 클라우드 스토리지의 공유 페이지에서 파일의 직접 다운로드 URL을 추출합니다. 기존에 클라이언트가 없거나 복잡한 절차 때문에 다운로드가 어려운 상황을 해결합니다. Tampermonkey를 설치하고 스크립트를 추가한 뒤, 지원되는 클라우드 서비스의 공유 링크를 열면 UI가 표시되고 클릭 한 번으로 직링크를 복사하거나 IDM·Aria2 등 외부 다운로드 프로그램에 전달할 수 있습니다. 스크립트는 각 서비스의 공개 API를 이용해 링크를 생성하므로 별도의 인증 절차가 필요하지 않습니다.

## 주요 기능
- 직링크 추출: 지원되는 9개 클라우드 서비스의 파일 직다운로드 URL을 바로 얻을 수 있습니다.
- UI 개선: 페이지에 깔끔한 버튼과 팝업을 추가해 사용성이 향상됩니다.
- 다중 다운로드기 연동: IDM, Aria2, cURL 등 외부 다운로드 프로그램에 바로 전송할 수 있습니다.
- 링크 캐시 및 복사: 추출한 URL을 자동으로 클립보드에 복사하고 캐시해 재사용이 가능합니다.
- 쿠키·토큰 자동 처리: 서비스별 인증 쿠키와 AccessToken을 자동으로 사용해 별도 로그인 없이 동작합니다.
- 최신 서비스 대응: 광鸭, 123 등 신규 클라우드 서비스와 업데이트된 공유 페이지 구조를 지속적으로 지원합니다.

## 참고·주의
- Tampermonkey(또는 Violentmonkey 등)와 Chrome ≥ 76, Edge ≥ 88 등 최신 브라우저가 필요합니다.
- 스크립트는 각 서비스의 공개 API에 의존하므로 서비스 정책 변경 시 동작이 중단될 수 있습니다.
- 본 스크립트는 다운로드 속도 향상을 보장하지 않으며, 속도 향상은 서비스 제공자의 정책에 따라 달라집니다.
- 법적 책임은 사용자에게 있으며, 저작권이 있는 파일을 무단으로 다운로드하는 행위는 금지됩니다.

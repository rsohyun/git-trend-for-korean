# hoochanlon/fq-book

> 인터넷 차단을 우회하는 원리와 설정 방법을 상세히 설명한 전자책입니다.

## 개요
《这本书能让你连接互联网》는 프록시·터널·VPN 등 인터넷 우회 기술의 동작 원리와 GFW 차단 기법을 설명하는 전자책입니다. 차단된 주소·포트, DNS 위조, SSL 차단 등 실제 사례와 해결 방법을 제공합니다. 사용자는 레포를 포크하거나 로컬에 클론한 뒤 docsify로 사이트를 빌드하고 GitHub Pages 혹은 localhost에서 책을 열어볼 수 있습니다. 필요 시 upstream을 pull하여 최신 업데이트를 반영합니다.

## 주요 기능
- 우회 원리 설명: 프록시·터널·VPN 작동 방식과 GFW 차단 메커니즘을 자세히 풉니다
- 실전 설정 가이드: DNS 교체, 인증서 오류 해결, Windows 프록시 설정 등 구체적인 트러블슈팅을 제공합니다
- 온라인·오프라인 배포: GitHub Pages와 로컬 docsify 서버 모두에서 책을 손쉽게 열람할 수 있습니다
- 업데이트 동기화: 포크 레포에 upstream을 pull하여 최신 내용으로 쉽게 갱신할 수 있습니다
- 추천 도구 연동: Ip‑Switch, DNSCrypt 등 유용한 네트워크 도구 링크를 함께 제공합니다

## 참고·주의
- 본 책은 연구·학습 목적에만 사용해야 하며 상업적 이용은 금지됩니다
- 중국 거주자는 책을 열람 후 24시간 이내에 모든 관련 콘텐츠를 삭제해야 합니다
- 로컬 배포 시 Git과 Node.js가 필요합니다

# hyprwm/Hyprland

> 화려한 시각 효과와 다양한 창 배치 방식을 제공하는 리눅스용 윈도우 관리 프로그램입니다.

## 개요
컴퓨터 화면에 나타나는 창들을 효율적으로 정렬하고 시각적으로 보기 좋게 꾸며 주는 도구입니다. 기존 화면 관리 프로그램들이 단조롭거나 원하는 대로 꾸미기 어려웠던 불편을 해결합니다. 사용자가 설정 파일을 수정하여 창의 애니메이션이나 테두리 등을 자유롭게 바꿀 수 있습니다.

## 주요 기능
- 화려한 시각 효과: 그라데이션 테두리, 배경 흐림 효과, 애니메이션, 그림자 등을 제공합니다.
- 다양한 창 배치 방식: 화면 분할, 전체 화면, 탭 모드, 플로팅 등 여러 가지 방식을 지원합니다.
- 강력한 확장 기능: 내장 플러그인 관리자를 통해 기능을 쉽게 확장할 수 있습니다.
- 즉시 설정 반영: 설정 파일을 저장하면 프로그램을 다시 시작하지 않아도 즉시 적용됩니다.
- 전역 단축키: 원하는 앱에 전역 단축키를 연결하여 간편하게 실행할 수 있습니다.

# ifixai-ai/iFixAi

> iFixAi는 AI 에이전트가 의도대로 동작하는지 120초 이내에 독립적으로 검증해 주는 도구입니다.

## 개요
iFixAi는 에이전트를 비즈니스 시뮬레이션에 배치하고 실제 업무 요청을 보내어 응답을 평가합니다. 이를 통해 에이전트의 정렬성, 거버넌스, 위험을 빠르게 확인할 수 있습니다. 사용자는 Python 3.10 이상 환경에 패키지를 설치하고, 데모 에이전트로 흐름을 확인한 뒤 실제 엔드포인트와 평가자를 지정해 감사를 실행합니다. 실행 결과는 터미널에 점수표와 상세 보고서 파일로 제공됩니다.

## 주요 기능
- 시뮬레이션 환경 구축: 에이전트를 비즈니스 상황에 맞는 가상 환경에 배치합니다.
- 데모 에이전트와 빠른 체험: API 키 없이 기본 에이전트와 검증 흐름을 1분 내에 확인합니다.
- 다중 평가자 지원: OpenAI, Anthropic, Gemini 등 다양한 제공자의 모델을 심판으로 사용할 수 있습니다.
- 플러그인 연동: Claude Code와 Codex 플러그인을 통해 코딩 에이전트에게 직접 감사를 요청할 수 있습니다.
- 자동 보고서 생성: 감사 결과를 점수표와 상세 보고서 파일로 자동 출력합니다.

## 참고·주의
- Python 3.10 이상이 필요합니다.
- 실제 감사 시 외부 LLM 제공자의 API 키가 필요하며, 사용량에 따라 비용이 발생할 수 있습니다.
- 감사 결과는 제공된 모델과 시뮬레이션 설정에 따라 달라질 수 있습니다.

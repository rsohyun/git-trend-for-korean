# isair/jarvis

> 음성과 텍스트로 자연스럽게 대화하며 내 컴퓨터에서 안전하게 실행되는 개인용 로컬 AI 비서입니다.

## 개요
클라우드 서비스에 의존하지 않고 사용자의 컴퓨터에서 직접 음성 인식, 언어 모델, 음성 합성을 실행하는 인공지능 비서입니다. 프라이버시가 침해될 수 있는 환경이나 외부 서버 비용 문제를 해결합니다. 앱을 설치하고 실행한 뒤 안내에 따라 로컬 모델을 연결하면, 화면에 나타나는 가상의 비서와 음성으로 대화하거나 일상적인 작업을 처리할 수 있습니다.

## 주요 기능
- 대화 맥락 이해: 주변 대화 내용을 일시적으로 기억하여 'Jarvis, 어떻게 생각해?' 같은 질문에 맥락에 맞는 답변을 제공합니다.
- 개인 기억 저장소: 과거 대화 내용, 선호도, 계획을 로컬 컴퓨터의 일지와 지식 그래프에 안전하게 저장하고 조회합니다.
- 다양한 내장 도구: 웹 검색, 날씨 확인, 화면 OCR, 파일 접근, 영양 성분 추적 등의 기능을 기본으로 제공합니다.
- 외부 도구 확장: MCP 서버를 연결해 웹 브라우저 자동화나 스마트홈 제어 등 다양한 기능을 추가할 수 있습니다.
- 음성 받아쓰기: 단축키를 누른 채 말하면 음성을 텍스트로 변환하여 다른 앱에 바로 입력합니다.
- 조용한 텍스트 대화: 음성 대화와 기억을 공유하는 별도의 채팅창을 열어 소리 없이 텍스트로 대화할 수 있습니다.

## 참고·주의
- macOS 26 이상 버전에서는 음성 받아쓰기 기능을 사용할 수 없습니다.
- 리눅스 환경에서 음성 받아쓰기를 쓰려면 X11이 필요하며 Wayland 환경에서는 지원이 제한됩니다.

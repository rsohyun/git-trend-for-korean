# jakubkrehel/skills

> AI 에이전트가 화면 디자인, 접근성, 글쓰기 등을 점검하고 완성도 높은 UI를 만들 수 있도록 돕는 기술 모음입니다.

## 개요
사용자 인터페이스(UI)를 제작할 때 디자인, 색상, 접근성 등 고려해야 할 요소가 많아 완성도를 높이기 어렵다는 문제를 해결합니다. 에이전트에게 필요한 기능 모음을 설치하면 화면 검토부터 디자인 구현, 상태 테스트까지 UI 개발 전반을 지원받을 수 있습니다. 사용자는 명령어 한 줄로 도구를 설치한 뒤 에이전트를 통해 화면을 진단하고 필요한 디자인 요소를 수정할 수 있습니다.

## 주요 기능
- 전체 화면 검토: 접근성, 레이아웃, 문구, 색상 등을 종합적으로 진단해 순위가 매겨진 보고서를 반환합니다.
- UI 세부 다듬기: 테두리 곡률, 그림자, 아이콘 상태, 애니메이션 등에 정확한 수값을 적용해 완성도를 높입니다.
- 타이포그래피 설정: 글자 크기, 자간, 줄바꿈, 문장부호 처리 등 텍스트 렌더링 방식을 점검하고 설정합니다.
- 색상 시스템 구축: 색상 팔레트를 만들고 의미론적 토큰 이름을 지정하며 명암비를 측정합니다.
- 접근성 검토: 키보드 초점, 화면 판독기 안내, 줌 기능 등을 웹 접근성 지침(WCAG 2.2)에 맞춰 확인하고 수정합니다.
- 디자인 파일 구현: 피그마 파일이나 디자인 이미지를 바탕으로 프로젝트의 기존 토큰을 활용해 UI를 구현합니다.

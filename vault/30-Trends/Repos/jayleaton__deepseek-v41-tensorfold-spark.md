# jayleaton/deepseek-v41-tensorfold-spark

> 엔비디아 DGX 스파크 환경에서 딥시크(DeepSeek-V4.1-Flash) 인공지능 모델을 텐서폴드 엔진으로 빠르게 구동할 수 있게 해 주는 설정 및 실행 도구입니다.

## 개요
대규모 인공지능 모델을 고성능 하드웨어에서 효율적으로 서빙하기 위한 레시피와 설정 스크립트를 제공합니다. 다중 기기 환경에서 메모리 부족이나 속도 저하가 발생하는 문제를 해결합니다. 사용자는 제공되는 모델 가중치와 설정 파일을 내려받은 뒤 실행 스크립트를 구동하여 오픈AI 호환 API를 통해 모델을 사용할 수 있습니다.

## 주요 기능
- 모델 서빙: 오픈AI와 호환되는 API 형태로 인공지능 모델을 구동합니다.
- 멀티 기기 연동: 2대의 엔비디아 DGX 스파크 기기를 묶어서 모델을 병렬 처리합니다.
- 비전 및 도구 지원: 이미지 입력과 도구 호출 및 구조화된 출력 기능을 제공합니다.

## 참고·주의
- 2대의 엔비디아 DGX 스파크 하드웨어가 필요합니다.

# jingyaogong/minimind

> 대규모 언어 모델을 처음부터 직접 만들고 학습해 볼 수 있는 64M 파라미터 크기의 초소형 인공지능 학습 프로젝트입니다.

## 개요
대형 언어 모델의 내부 구조가 복잡하고 거대하여 개인 기기에서 직접 학습하고 원리를 파악하기 어려운 문제를 해결합니다. PyTorch 기반으로 토크나이저부터 사전 학습, 미세 조정, 강화 학습까지 전 과정을 직접 구현하여 제공합니다. 사용자는 소스 코드를 내려받아 개인 그래픽카드에서 직접 모델을 학습시키고, 챗봇 웹 인터페이스나 API를 통해 완성된 모델의 동작을 확인할 수 있습니다.

## 주요 기능
- 초소형 모델 학습: 64M 파라미터 규모의 언어 모델을 개인용 그래픽카드로 몇 시간 만에 직접 처음부터 학습할 수 있습니다.
- 전체 학습 파이프라인 제공: 사전 학습(Pretrain), 미세 조정(SFT), 로라(LoRA), 강화 학습(DPO/GRPO)까지 전 과정을 코드로 제공합니다.
- 오픈소스 프레임워크 호환: 학습한 모델을 변환하여 vLLM, ollama, llama.cpp 등 인기 있는 추세 및 인프라 엔진에서 실행할 수 있습니다.
- 웹 UI 및 API 지원: Streamlit 기반의 채팅 화면과 OpenAI API 호환 서버를 제공하여 즉시 대화하고 테스트할 수 있습니다.
- 다양한 확장 기능: 도구 호출(Tool Call), 생각 체인(Reasoning), 혼합 전문가 모델(MoE) 등 최신 인공지능 기술 요소를 포함하고 있습니다.

## 참고·주의
- 모델을 직접 처음부터 학습하려면 PyTorch 구동이 가능한 NVIDIA 그래픽카드가 필요합니다.

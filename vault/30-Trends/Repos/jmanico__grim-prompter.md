# jmanico/grim-prompter

> Claude Code, Codex 등 AI 코딩 에이전트가 저장소를 분석하여 코드에 기반한 위협 모델을 작성할 수 있게 해 주는 도구입니다.

## 개요
소프트웨어 개발 과정에서 보안 취약점을 미리 파악하기 위한 위협 모델링 도구입니다. 코드를 수동으로 분석해야 하는 번거로움을 해결하기 위해, AI 에이전트가 아키텍처와 코드를 체계적으로 검토하도록 돕습니다. 사용자가 AI 에이전트에 관련 명령어와 분석 방식을 전달하면, 에이전트가 코드를 읽고 신뢰 경계와 잠재적 위협, 대응 방안이 정리된 보고서를 생성합니다.

## 주요 기능
- 아키텍처별 분석: 웹, API, 모바일, 서버소스, AI 등 36가지 아키텍처 작업 흐름을 제공합니다.
- 구조화된 검토: 신뢰 경계, 기존 보안 통제, 잠재적 위협, 제안된 완화 조치를 체계적으로 검토합니다.
- 에이전트 연동: Claude Code 및 Codex CLI에 명령어(Skill)로 쉽게 연결할 수 있습니다.
- 코드 변경 추적: 브랜치 간 변경 사항을 기존 위협 모델과 비교하여 리뷰할 수 있습니다.
- 증거 기반 보고서: 발견된 내용과 코드 위치가 명시된 마크다운 및 JSON 보고서를 생성합니다.

## 참고·주의
- 생성된 보고서에는 민감한 세부 정보가 포함될 수 있으므로 검토 전까지 버전 관리(Git)에 포함하지 않아야 합니다.
- AI가 생성한 위협 모델은 시스템이 안전함을 보장하지 않으므로 결과를 직접 확인하고 검증해야 합니다.

# jonathanong/no-mistakes

> 코드 변경이 영향을 미치는 파일과 테스트를 찾아내고, 유지보수가 어려운 코드를 미리 차단해 주는 정적 분석 도구입니다.

## 개요
코드 변경이 백엔드와 프론트엔드 전체에 미치는 영향을 정확하게 파악하지 못해 발생하는 실수를 해결하는 도구입니다. 로컬 저장소를 직접 분석하여 연관된 파일과 테스트 목록을 보여주고, 성능 문제를 일으키는 코드 패턴을 검사합니다. 개발자는 의존성 그래프를 조회하거나 영향받는 테스트만 골라 실행하는 방식으로 사용합니다.

## 주요 기능
- 변경 영향 범위 분석: 코드 수정이 닿는 프론트엔드 페이지와 테스트를 의존성 그래프로 찾습니다.
- 테스트 선별 실행: 전체 테스트 대신 변경된 코드와 연관된 Playwright 및 Vitest 테스트만 골라 실행합니다.
- 코드 규칙 검사: 동적 임포트나 중복 식별자 등 그래프 분석을 방해하는 코드를 사전에 차단합니다.
- 데이터베이스 패턴 검사: 성능 저하를 유발하는 잘못된 PostgreSQL 쿼리 및 스키마 패턴을 검사합니다.

# jquery/jquery

> 웹페이지의 요소를 쉽게 조작하고 이벤트를 처리할 수 있게 해 주는 자바스크립트 라이브러리입니다.

## 개요
복잡하고 브라우저마다 다른 자바스크립트 코드를 단순하게 작성할 수 있도록 돕는 도구입니다. 웹 개발 시 DOM(웹 문서 구조) 조작이나 서버 통신 코드가 브라우저별로 다르게 동작하는 문제를 해결해 줍니다. 소스 코드를 내려받아 직접 빌드하거나 필요한 모듈만 골라 커스텀 버전을 만들어 사용할 수 있습니다.

## 주요 기능
- 버전 지원: 최신 4.x 버전을 포함해 다양한 브라우저 환경에서 안정적으로 동작합니다.
- 맞춤형 빌드: 사용하지 않는 모듈을 제외하고 필요한 기능만 골라 경량화된 버전을 만들 수 있습니다.
- 모듈형 지원: 표준 ECMAScript 모듈 형태로 빌드하여 가져다 쓸 수 있습니다.
- 유연한 환경 지원: 웹 브라우저뿐만 아니라 Node.js나 브라우저 확장 프로그램 등 다양한 환경을 지원합니다.

## 참고·주의
- 버전 1.x와 2.x는 더 이상 공식 지원되지 않으며 최신 버전으로 업그레이드가 권장됩니다.
- 소스 코드를 직접 빌드하려면 Node.js와 Git 설치가 필요합니다.

# jxxghp/MoviePilot

> 개인 미디어 서버의 영화와 드라마를 자동으로 검색하고 내려받아 정리해 주는 NAS(네트워크 결합 스토리지) 관리 프로그램입니다.

## 개요
개인 미디어 서버를 운영할 때 영상 파일을 직접 찾고 정리해야 하는 번거로움을 해결해 주는 도구입니다. 원하는 콘텐츠를 구독해 두면 프로그램이 알아서 검색, 다운로드, 파일 정리, 메타데이터 생성 및 미디어 서버 갱신까지 처리합니다. 도커(Docker)나 리눅스 환경에 설치한 뒤 웹 인터페이스에 접속하여 다운로더와 미디어 서버를 연결하면 자동으로 미디어 라이브러리가 관리됩니다.

## 주요 기능
- 자동화 파이프라인: 영화와 드라마의 구독, 검색, 다운로드, 파일 정리, 메타데이터 생성, 미디어 서버 갱신 과정을 자동으로 처리합니다.
- 확장 가능한 아키텍처: 백엔드와 프론트엔드가 분리되어 있으며 다양한 다운로더, 미디어 서버, 메타데이터 소스, 플러그인을 지원합니다.
- 인공지능 비서 연동: 자연어 명령으로 검색과 다운로드 같은 관리 작업을 수행할 수 있는 AI 에이전트 기능을 제공합니다.
- 외부 도구 연동: MCP(AI 에이전트가 외부 도구를 호출하는 표준 방식) 클라이언트나 외부 스크립트에서 시스템 기능을 호출할 수 있습니다.

## 참고·주의
- 학습 및 교류 목적으로만 사용해야 하며 상업적 용도나 불법 활동에 사용할 수 없습니다.
- 중국 내 플랫폼에서의 프로젝트 홍보가 금지되어 있습니다.

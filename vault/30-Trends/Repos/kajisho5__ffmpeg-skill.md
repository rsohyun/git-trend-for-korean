# kajisho5/ffmpeg-skill

> AI 코딩 에이전트가 로컬에서 안전하게 동영상을 편집하고 검증할 수 있게 해 주는 42가지 FFmpeg 도구 모음입니다.

## 개요
동영상을 편집해야 할 때 AI 에이전트가 직접 FFmpeg 명령어를 실행하며 겪는 시행착오 문제를 해결합니다. 사용자는 Claude Code나 Cursor 같은 에이전트에 이 도구를 연결하여 자르기, 자막 생성, 크기 조절, 음량 조절 등의 편집 작업을 맡길 수 있습니다. 에이전트는 로컬 환경에서 작업을 수행한 뒤 결과물을 직접 검증하여 정확한 파일을 완성해 줍니다. 클라우드나 외부 API 키 없이 로컬에 설치된 FFmpeg와 파이썬 표준 라이브러리만으로 동작합니다.

## 주요 기능
- 영상 자르기 및 이어붙이기: 불필요한 구간을 제거하거나 여러 동영상을 하나로 연결할 수 있습니다.
- 자막 및 가라오케 효과: 영상에 자막을 넣고 애니메이션이나 가라오케 강조 효과를 적용할 수 있습니다.
- 무음 구간 제거: 소리가 없는 빈 구간을 자동으로 찾아내어 타임라인을 짧게 줄일 수 있습니다.
- 화면 비율 및 크기 조절: 다양한 플랫폼 규격에 맞춰 영상의 비율과 구도를 변경할 수 있습니다.
- 음량 평준화: 방송 표준에 맞춰 오디오 음량을 자동으로 조절하고 균일하게 맞출 수 있습니다.
- MCP 서버 지원: Claude Code나 Cursor 등의 AI 에이전트와 연동하여 도구를 호출할 수 있습니다.

## 참고·주의
- 시스템에 FFmpeg와 Python 3가 설치되어 있어야 합니다.

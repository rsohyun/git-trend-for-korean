# keyvanarasteh/os-lab

> Windows, Android, iOS, Linux 등 다양한 운영체제와 방화벽 보안 실습을 격리된 가상 환경에서 손쉽게 수행할 수 있게 해 주는 통합 보안 실습 도구입니다.

## 개요
운영체제 보안을 공부하거나 악성코드 분석을 진행할 때 각 환경을 개별로 구축해야 하는 번거로움을 해결해 줍니다. 통합 관리 도구나 웹 콘솔을 통해 각 운영체제 가상 환경의 실행, 상태 확인, 실습 관리를 한 번에 처리할 수 있습니다. 사용자는 제공되는 설치 스크립트로 도구를 설치한 뒤 관리 명령어를 이용해 원하는 운영체제 실습 환경을 실행하고 웹 화면이나 원격 접속으로 실습을 진행합니다.

## 주요 기능
- Windows 실습 환경: 웹 데스크톱과 원격 데스크톱을 지원하는 윈도우 가상 머신 실행
- Android 실습 환경: 에뮬레이터와 보안 분석 도구를 연동한 정적·동적 분석 수행
- Linux 실습 환경: 악성코드 분석과 취약점 실습을 위한 격리된 가상 환경 제공
- 통합 관리 도구: 명령줄 도구와 웹 콘솔을 통한 전체 가상 환경 상태 확인 및 제어
- 다국어 지원: 영어, 터키어, 독일어, 프랑스어 등 다양한 언어와 RTL(우측 정렬) 인터페이스 지원

## 참고·주의
- Windows 및 macOS 가상 환경을 사용할 때는 정품 라이선스를 직접 준비해야 합니다.

# l0ng-ai/openidea

> Rust로 재구성된 IntelliJ IDEA 스타일의 IDE로, 빠른 시작과 낮은 메모리 사용을 제공합니다.

## 개요
OpenIDEA는 IntelliJ IDEA와 동일한 키맵·툴 윈도·전역 검색 방식을 Rust 기반 네이티브 애플리케이션으로 구현한 통합 개발 환경입니다. 기존 Java 기반 IDE가 무겁고 느리다는 문제를 해결해, 프로젝트 열기와 준비 시간이 크게 단축되고 메모리 사용량이 적습니다. 사용자는 다운로드 후 설치하고, 원하는 프로젝트를 열면 에디터·코드 인사이트·디버거·Git·터미널·데이터베이스·HTTP 클라이언트를 즉시 사용할 수 있습니다. 지원 언어는 60개 이상이며 macOS·Windows·Linux에서 동작합니다.

## 주요 기능
- IntelliJ‑style 키맵: 익숙한 단축키로 빠르게 작업할 수 있습니다.
- 다중 언어 지원: 60개 이상의 프로그래밍 언어에 대한 편집·코드 인사이트를 제공합니다.
- 통합 디버거: 코드 실행을 중단하고 변수·스택을 실시간으로 확인할 수 있습니다.
- Git 통합: 버전 관리 작업을 IDE 내부에서 바로 수행할 수 있습니다.
- 터미널·데이터베이스·HTTP 클라이언트: 명령 실행·쿼리·API 요청을 별도 도구 없이 처리합니다.

# lidge-jun/opencodex

> 다양한 AI 코딩 도구에서 OpenAI Codex나 Claude Code뿐만 아니라 Claude, Gemini, DeepSeek, Ollama 등 원하는 LLM을 골라 쓸 수 있게 해 주는 로컬 중계 프로그램입니다.

## 개요
코딩 도구마다 지원하는 AI 모델이 제한되어 원하는 모델을 쓰기 어렵거나 여러 도구를 함께 쓸 때 설정을 따로 관리해야 하는 불편함을 해결합니다. 사용자는 컴퓨터에서 중계 프로그램을 실행하고 웹 대시보드에서 원하는 AI 제공자와 모델을 선택한 뒤, 평소 쓰던 코딩 도구를 그대로 실행하면 됩니다. 각 도구의 요청을 자동으로 변환하여 스트리밍, 도구 호출, 이미지 인식 기능을 그대로 지원합니다.

## 주요 기능
- 다양한 AI 모델 연동: Claude, Gemini, Grok, DeepSeek, Ollama 등 40개가 넘는 AI 제공자의 모델을 코딩 도구에서 자유롭게 쓸 수 있습니다.
- 통합 대시보드 제공: 웹 브라우저나 전용 데스크톱 앱에서 AI 제공자 계정과 사용할 모델을 한곳에서 관리할 수 있습니다.
- 주요 코딩 도구 지원: Codex, Claude Code, Claude Desktop, Grok Build 등 다양한 AI 코딩 환경과 간편하게 연결됩니다.
- 자동 프로토콜 변환: 클라이언트와 AI 제공자 간의 요청 형식을 자동으로 맞춰 주어 스트리밍과 도구 호출 기능이 끊김 없이 작동합니다.
- 백그라운드 실행: 명령어를 통해 백그라운드 서비스나 시스템 트레이 앱으로 항상 켜 두고 쓸 수 있습니다.

## 참고·주의
- Node.js 18 이상 버전이 필요합니다.
- 연동하려는 각 AI 모델 제공자의 유료 계정이나 API 키가 필요합니다.

# louislam/uptime-kuma

> 웹사이트나 서버, 도커 컨테이너 등의 상태를 실시간으로 모니터링하고 문제가 생기면 알려 주는 자체 호스팅 모니터링 도구입니다.

## 개요
웹 서비스나 서버가 갑자기 다운되거나 응답하지 않는 문제를 실시간으로 파악할 수 있는 도구입니다. 관리자는 웹 대시보드에서 모니터링할 주소나 서버를 등록해 전체 가동 상태를 한눈에 확인할 수 있습니다. 설치 후 웹 인터페이스에 접속하여 모니터링 대상을 추가하면 20초 주기로 상태를 확인하고 결과를 시각화해 줍니다. 장애가 발생하면 텔레그램이나 디스코드 등 다양한 채널을 통해 즉시 알림을 받을 수 있습니다.

## 주요 기능
- 다양한 프로토콜 모니터링: HTTP, TCP, 핑, DNS, 도커 컨테이너 등의 가동 상태를 확인할 수 있습니다.
- 실시간 알림 연동: 텔레그램, 디스코드, 이메일 등 90개 이상의 서비스로 장애 알림을 받을 수 있습니다.
- 상태 페이지 제공: 모니터링 결과를 외부에 공개하거나 특정 도메인에 연결할 수 있는 상태 페이지를 만들 수 있습니다.
- 빠른 상태 확인: 최소 20초 간격으로 대상의 응답 상태를 확인합니다.
- 상세 정보 시각화: 핑 응답 속도 차트와 SSL 인증서 유효기간 정보를 확인할 수 있습니다.

## 참고·주의
- 네트워크 파일 시스템(NFS) 환경은 데이터 저장소로 지원하지 않으므로 로컬 디렉터리를 사용해야 합니다.

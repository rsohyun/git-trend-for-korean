# lz4/lz4

> 파일을 매우 빠른 속도로 압축하고 해제할 수 있게 해 주는 무손실 데이터 압축 프로그램입니다.

## 개요
데이터를 저장하거나 전송할 때 용량을 줄여 주는 초고속 압축 도구입니다. 느린 압축 속도로 인해 발생하는 대용량 데이터 처리의 병목 현상을 해결합니다. 소스 코드를 빌드하거나 패키지 관리자를 통해 설치한 뒤 명령어와 라이브러리로 파일 압축 및 해제를 수행합니다.

## 주요 기능
- 초고속 압축 및 해제: 코어당 초당 수백 메가바이트에서 수기가바이트에 이르는 빠른 속도로 파일을 처리합니다.
- 압축률 조절: 속도와 압축률 중 원하는 방향에 맞춰 가속도를 동적으로 조절할 수 있습니다.
- 고압축 모드 제공: CPU 시간을 더 사용하여 압축률을 높이는 고압축 모드를 지원합니다.
- 사전 압축 지원: 특정 파일을 사전으로 사용하여 작은 파일의 압축 성능을 크게 높일 수 있습니다.

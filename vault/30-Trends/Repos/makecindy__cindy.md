# makecindy/cindy

> Cindy는 로컬에서 바로 실행되는 오픈소스 AI 에이전트로, 다양한 모델과 도구를 하나에 묶어 실제 작업을 자동으로 수행합니다.

## 개요
Cindy는 여러 AI 모델과 도구를 결합해 사용자의 컴퓨터, 브라우저, 모바일에서 작업을 수행하는 에이전트입니다. 복잡한 설정 없이 Node.js와 pnpm만 설치하면 바로 사용할 수 있어 초기 진입 장벽을 낮춥니다. 설치 후 데스크톱 또는 모바일 앱을 실행하면 파일·앱을 조작하거나 코드를 작성·검토하는 등 실질적인 결과를 얻을 수 있습니다. 필요에 따라 Cindy 클라우드 계정으로 로그인해 호스팅 서비스와 연동하거나, 로그인 없이 로컬 에이전트만 사용할 수 있습니다.

## 주요 기능
- 다중 모델 전환: Claude Code·Codex 등 여러 모델을 작업 중에 자유롭게 교체할 수 있습니다.
- 로컬 환경 제어: 브라우저·컴퓨터·휴대폰을 직접 조작해 실제 파일과 앱에 작업을 수행합니다.
- 지속적 메모리·스킬: 한 번 가르친 내용이 에이전트 메모리에 저장돼 이후 작업에 재사용됩니다.
- 자동화 스케줄링: 반복 작업을 예약하고 자동 실행·보고하도록 설정할 수 있습니다.
- MCP 연동: 내부 도구·비즈니스 시스템을 연결해 에이전트가 직접 호출하도록 합니다.
- 플러그인·마켓플레이스: 기능·UI를 플러그인으로 확장하고 공유할 수 있습니다.

## 참고·주의
- Node.js 22.x와 pnpm 10.x가 필요합니다.
- Git LFS를 설치하고 레포지토리를 pull해야 합니다.
- 전체 기능을 사용하려면 Cindy 클라우드 계정이 필요합니다.
- 공식 배포 빌드에는 사용 통계 수집(TapDB) 텔레메트리가 포함됩니다.

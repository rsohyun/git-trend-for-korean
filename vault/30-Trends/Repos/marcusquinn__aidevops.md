# marcusquinn/aidevops

> AI 에이전트와 Git 워크플로우를 자동화하여 앱과 비즈니스 개발을 돕는 오픈소스 프레임워크입니다.

## 개요
소프트웨어 개발과 운영 전반에서 반복되는 작업을 AI 에이전트가 자율적으로 수행하도록 돕는 도구입니다. 매번 대화로 지시해야 하는 불편을 줄이고, 필요한 문맥만 불러와 안전하고 효율적으로 프로젝트를 관리합니다. 사용자는 터미널에서 전용 명령어로 도구를 설치하고 프로젝트를 등록한 뒤 AI 세션을 시작해 결과를 얻을 수 있습니다.

## 주요 기능
- 전용 에이전트 연동: 17개의 주요 AI 에이전트와 수천 개의 하위 에이전트를 활용해 다양한 작업을 처리할 수 있습니다.
- 모델 라우팅: 작업 성격에 맞는 AI 모델과 연산 능력을 선택해 토큰 비용을 아낄 수 있습니다.
- 보안 및 자격 증명 관리: API 키와 민감한 정보를 AI 채팅이나 Git에 노출되지 않도록 안전하게 관리합니다.
- 작업 자동화: 프로젝트 상태를 지속해서 점검하고 백그라운드에서 필요한 작업을 처리합니다.
- 명령어 인터페이스: 슬래시 명령어와 터미널 명령어로 복잡한 개발 및 운영 작업을 쉽게 실행할 수 있습니다.

## 참고·주의
- macOS 또는 Linux 환경이 필요합니다.
- OpenCode 계정이나 지원되는 모델 제공자의 API 키 또는 구독 계정이 필요합니다.

# mattpocock/skills

> 실제 개발 업무에서 AI 코딩 에이전트의 완성도와 소통 방식을 개선해 주는 맞춤형 스킬 모음입니다.

## 개요
AI 코딩 에이전트가 개발자의 의도를 제대로 이해하지 못하거나 불필요하게 장황한 코드를 만드는 문제를 해결합니다. 에이전트와 상세한 사전 질의를 거치고 공통 용어를 정리할 수 있게 돕습니다. 사용하려는 에이전트에 플러그인을 설치하고 설정 명령을 실행하면 바로 적용됩니다.

## 주요 기능
- 사전 질의 기능: 작업을 시작하기 전에 에이전트가 상세한 질문을 던져 개발자의 의도를 명확하게 파악합니다.
- 공통 용어 정립: 프로젝트 내에서 쓰는 전문 용어를 정의하여 에이전트가 더 간결하고 정확하게 소통하게 만듭니다.
- 테스트 주도 개발 지원: 에이전트가 실패하는 테스트를 먼저 작성한 뒤 이를 고치는 방식을 따르도록 유도합니다.

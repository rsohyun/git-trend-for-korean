# max-sixty/worktrunk

> 여러 개의 독립된 작업 공간을 쉽게 만들고 오갈 수 있게 해 주는 깃(Git) 작업 디렉토리 관리 도구입니다.

## 개요
여러 AI 에이전트를 동시에 실행할 때 각 에이전트마다 별도의 폴더와 브랜치를 할당해 작업 충돌을 막아 주는 도구입니다. 기본 깃 명령어로는 번거로운 작업 공간 생성, 이동, 삭제 과정을 간단한 명령어로 줄여 줍니다. 사용자는 간단한 명령어 입력만으로 새 작업 공간을 만들고 그 안에서 바로 작업을 시작할 수 있습니다.

## 주요 기능
- 작업 공간 전환: 브랜치 이름만으로 원하는 작업 공간으로 쉽게 이동할 수 있습니다.
- 통합 실행: 작업 공간을 만들면서 동시에 AI 에이전트 같은 도구를 바로 실행할 수 있습니다.
- 상태 목록 보기: 현재 열려 있는 모든 작업 공간의 상태를 한눈에 확인할 수 있습니다.
- 워크플로우 자동화: 작업 공간 생성이나 병합 전후에 원하는 명령어가 자동으로 실행되도록 설정할 수 있습니다.
- 빌드 캐시 공유: 디스크 공간을 아끼면서 여러 작업 공간이 빌드 결과물을 공유하게 설정할 수 있습니다.

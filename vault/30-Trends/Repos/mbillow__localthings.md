# mbillow/localthings

> 삼성 가전제품을 홈 어시스턴트(Home Assistant)와 로컬 네트워크로 연결하여 클라우드 계정 없이 제어할 수 있게 해 주는 연동 프로그램입니다.

## 개요
삼성 스마트싱스(SmartThings) 앱을 지원하는 세탁기, 냉장고, 에어컨 등의 가전제품을 인터넷 연결 없이 집 안 네트워크에서 직접 제어할 수 있도록 돕는 도구입니다. 삼성 서버를 거치지 않고 로컬 네트워크 통신을 사용하므로 데이터가 외부로 유출되지 않는 장점이 있습니다. 사용자는 홈 어시스턴트에 기기의 IP 주소를 입력하여 설치한 뒤, 가전제품의 상태를 모니터링하고 원격으로 조작할 수 있습니다.

## 주요 기능
- 실시간 상태 반영: 지원하는 가전제품은 변경 사항이 생기는 즉시 홈 어시스턴트에 반영됩니다.
- 로컬 네트워크 제어: 인터넷 연결이 끊긴 상태에서도 홈 네트워크를 통해 정상적으로 작동합니다.
- 다양한 기기 지원: 세탁기, 건조기, 냉장고, 에어컨, 오븐 등 폭넓은 삼성 가전제품을 연결할 수 있습니다.
- 자동 기기 감지: 기기의 IP 주소를 입력하면 자동으로 종류와 모델을 파악해 제어 화면을 만듭니다.

## 참고·주의
- 최초 기기 등록 시 공개 식별자를 가져오기 위해 삼성 서버에 단 한 번 접속하며, 이후 추가 기기 등록부터는 인터넷 연결이 필요 없습니다.
- 일부 구형 기기나 보안 설정이 다른 기기는 사전 공유 키나 장치 토큰 같은 추가 인증 정보가 필요할 수 있습니다.

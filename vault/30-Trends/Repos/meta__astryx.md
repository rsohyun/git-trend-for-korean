# meta/astryx

> 사람과 AI 어시스턴트가 함께 웹 애플리케이션을 만들 수 있도록 지원하는 오픈소스 디자인 시스템입니다.

## 개요
메타에서 8년 동안 사용된 검증된 UI 구성 요소를 제공하여 개발자가 일일이 디자인을 구현해야 하는 번거로움을 해결합니다. 150개 이상의 접근성 검증된 컴포넌트와 CLI 도구를 프로젝트에 설치하여 일관된 웹 화면을 빠르게 구축할 수 있습니다. AI 어시스턴트도 사람과 동일한 참조 문서를 바탕으로 코드를 작성할 수 있도록 설계되었습니다.

## 주요 기능
- 컴포넌트 제공: 접근성과 타입스크립트가 지원되는 150개 이상의 UI 구성 요소를 사용할 수 있습니다.
- 스타일 자유도: 기존 프로젝트에서 쓰던 CSS나 Tailwind 등을 그대로 써서 디자인을 덮어쓸 수 있습니다.
- 테마 커스텀: CSS 변수를 수정해 포크나 래핑 없이 브랜드에 맞는 테마를 쉽게 적용할 수 있습니다.
- 코드 추출: 소스 코드를 프로젝트로 완전히 가져와 직접 수정할 수 있습니다.
- AI 협업 지원: API와 CLI가 표준화되어 있어 AI 어시스턴트가 사람과 동일한 방식으로 코드를 작성할 수 있습니다.

## 참고·주의
- 리액트 19 버전 이상이 필요합니다.

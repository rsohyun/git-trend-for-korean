# microsoft/TokenEconomizer

> TokenEconomizer는 코딩 에이전트가 동일한 레포지토리에서 반복 작업할 때 비용을 줄여 주는 플러그인입니다.

## 개요
이 도구는 코딩 에이전트가 레포지토리에서 작업할 때 발생하는 중복 토큰 사용과 불필요한 도구 로드를 학습해 제거합니다. 기존 에이전트의 모델이나 코드를 바꾸지 않고, 플러그인을 설치한 뒤 에이전트를 실행하면 세션 시작 시 기억된 사실과 최적화된 도구 목록이 자동으로 적용됩니다. 각 세션이 끝날 때마다 로그를 분석해 마이크로 스킬, 도구 프루닝, 실패 루프 개입을 업데이트합니다. 결과적으로 동일 레포지토리에서 반복 작업 시 평균 18‑31% 정도 비용이 감소합니다.

## 주요 기능
- 마이크로 스킬: 레포지토리의 빌드 단계, 명령어, 환경 변수 등 반복되는 사실을 기억해 세션 시작 시 제공
- 도구 프루닝: 사용되지 않은 도구를 자동으로 제외해 요청 토큰을 절감
- 실패 루프 개입: 동일 오류가 반복될 때 판단 모델이 개입해 다른 접근법을 제시
- 다중 에이전트 지원: Claude Code, Codex, GitHub Copilot CLI, Pi 등 주요 코딩 에이전트와 플러그인 형태로 연동
- 학습 내용 로컬 저장: 학습된 사실과 설정이 사용자의 홈 디렉터리(~/.tokeneconomizer)에 안전하게 보관

## 참고·주의
- Python 3.10 이상이 필요합니다
- 지원되는 코딩 에이전트가 사전에 설치·로그인돼 있어야 합니다
- 플러그인 자체 모델 호출이 추가 비용을 발생시키며, 비용 절감 효과는 이후 세션에 반영됩니다
- 학습 데이터는 로컬에 저장되지만, 민감한 레포지토리 정보를 포함할 수 있으니 보안 정책을 확인하세요

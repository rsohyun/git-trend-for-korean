# microsoft/VibeVoice

> 음성 인식과 합성을 아우르는 오픈소스 음성 인공지능 모델 모음으로, 긴 음성을 한 번에 처리하고 실시간으로 변환할 수 있게 해 줍니다.

## 개요
음성 데이터를 문자로 변환하거나 텍스트를 음성으로 바꾸는 작업을 수행하는 도구입니다. 기존 음성 인식 도구가 긴 음성을 짧게 쪼개서 처리하면서 발생하는 문맥 유실 문제를 해결합니다. 사용자는 제공되는 모델과 코드를 다운로드하여 긴 음성 파일의 화자 분리 및 자막 생성, 실시간 음성 인식 등에 활용할 수 있습니다. 초저속 프레임 토크나이저와 대형 언어 모델을 결합해 긴 분량의 음성도 효율적으로 처리합니다.

## 주요 기능
- VibeVoice-ASR: 최대 60분의 긴 음성을 한 번에 처리하여 화자와 타임스탬프가 포함된 구조화된 텍스트를 생성합니다.
- 스트리밍 ASR: 음성이 들어오는 동안 실시간으로 텍스트를 변환합니다.
- VibeVoice-ASR-BitNet: GPU 없이 CPU 환경에서 실시간으로 음성 인식을 실행합니다.
- 사용자 맞춤형 단어 지원: 전문 용어 등 특정 단어를 등록하여 인식 정확도를 높일 수 있습니다.
- VibeVoice-Realtime-0.5B: 실시간 텍스트 입력과 장문 음성 생성을 지원합니다.

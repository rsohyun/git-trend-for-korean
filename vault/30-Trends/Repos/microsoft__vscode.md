# microsoft/vscode

> 프로그래밍 코드 작성부터 디버깅, 도구 연동까지 지원하는 소스 코드 편집기입니다.

## 개요
코드 작성과 편집을 간편하게 처리할 수 있도록 돕는 소스 코드 편집기입니다. 복잡한 개발 환경 구성이나 여러 도구를 따로 쓰며 겪는 불편함을 해결해 줍니다. 프로그램을 설치한 뒤 코드를 작성하고 필요한 기능을 확장하여 빌드와 디버깅을 진행할 수 있습니다. 커뮤니티와 함께 개발되는 오픈소스 저장소로 소스 코드를 직접 확인하고 기여할 수 있습니다.

## 주요 기능
- 코드 편집 및 탐색: 종합적인 코드 작성과 이해를 돕는 편집 기능을 제공합니다.
- 가벼운 디버깅: 프로그램의 오류를 찾고 해결하는 디버깅 작업을 가볍게 수행할 수 있습니다.
- 확장 기능 모델: 다양한 확장 기능을 설치하여 편집기 기능을 풍부하게 늘릴 수 있습니다.
- 도구 통합: 기존에 사용하던 개발 도구들과 가볍게 연동하여 쓸 수 있습니다.
- 오픈소스 기여: 소스 코드 변경 내역을 확인하고 직접 문제 해결이나 기능 개발에 참여할 수 있습니다.

## 참고·주의
- 전체 빌드를 수행하려면 4코어 이상, 6GB 이상의 램(8GB 권장) 환경이 필요합니다.

# milind-soni/OpenMausBot

> 채팅 앱 형태로 여러 인공지능 봇과 대화하며 작업을 맡길 수 있는 오픈소스 프로그램입니다.

## 개요
인공지능 봇마다 개별 성격과 가상 컴퓨터를 부여해 여러 작업을 동시에 처리할 수 있도록 돕는 도구입니다. 기존 인공지능 서비스들이 데이터를 클라우드에 저장하는 문제를 해결하여, 내 컴퓨터에서 직접 봇을 실행하고 데이터를 보관할 수 있습니다. 프로그램을 설치한 뒤 대화창에서 봇에게 업무를 지시하면 봇이 가상 컴퓨터나 연결된 앱을 통해 작업을 수행합니다.

## 주요 기능
- 나만의 에이전트 사용: Claude나 Codex 등 사용자가 이미 보유한 인공지능 계정과 도구를 그대로 활용할 수 있습니다.
- 로컬 데이터 저장: 대화 기록과 설정 파일이 외부 클라우드가 아닌 사용자 컴퓨터에 안전하게 저장됩니다.
- 가상 컴퓨터 연동: 각 봇이 독립된 가상 컴퓨터 환경을 사용하여 파일 조작이나 프로그램 실행을 직접 처리합니다.

## 참고·주의
- 이 프로젝트는 어떠한 가상 화폐나 토큰 발행과도 관련이 없습니다.
- 우분투 Wayland 환경에서는 호스트 제어 기능이 제한될 수 있습니다.

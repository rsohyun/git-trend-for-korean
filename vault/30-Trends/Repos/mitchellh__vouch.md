# mitchellh/vouch

> 프로젝트 기여자들의 신뢰 여부를 관리하여 무분별한 저품질 기여나 AI 생성 스팸을 막아 주는 커뮤니티 신뢰 관리 시스템입니다.

## 개요
오픈소스 프로젝트에서 신뢰할 수 없는 사용자의 무분별한 기여가 늘어나는 문제를 해결합니다. 신뢰할 수 있는 관리자가 특정 사용자를 보증하거나 거부하는 목록을 관리할 수 있게 돕습니다. 사용자는 깃허브 액션(GitHub Actions)이나 명령줄 도구를 설정하여, 보증받지 않은 사용자가 올린 이슈나 풀 리퀘스트를 자동으로 차단할 수 있습니다.

## 주요 기능
- 이슈 및 풀 리퀘스트 검사: 보증받지 않은 사용자가 올린 기여를 자동으로 확인하고 필요시 차단합니다.
- 댓글을 통한 권한 관리: 관리자가 이슈나 토론 댓글로 사용자를 쉽게 보증하거나 거부할 수 있습니다.
- 상태 확인 명령어: 명령줄에서 특정 사용자의 신뢰 상태를 간편하게 조회할 수 있습니다.
- 코드 소유자 동기화: 저장소의 코드 소유자 목록을 신뢰된 보증 목록에 자동으로 반영합니다.

## 참고·주의
- 깃허브 연동 기능을 사용하려면 깃허브 액션 및 관련 환경 설정이 필요합니다.
- 명령줄 도구는 누쉘(Nushell) 환경에서 동작합니다.

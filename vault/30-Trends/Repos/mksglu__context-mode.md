# mksglu/context-mode

> 코딩 에이전트가 참고하는 대화창에 대용량 도구 출력 결과가 쌓이지 않도록 막아 주어 토큰 사용량을 대폭 줄여 주는 로컬 플러그인입니다.

## 개요
코딩 에이전트가 파일 읽기나 명령어 실행 같은 작업을 수행할 때 발생하는 방대한 출력 결과가 그대로 대화창에 들어가 에이전트의 기억 용량을 낭비하는 문제를 해결합니다. 작업 결과를 로컬 샌드박스와 SQLite 데이터베이스에 안전하게 보관하고, 에이전트가 요청하는 핵심 내용만 골라 대화창에 전달합니다. 사용자는 지원하는 코딩 에이전트에 플러그인을 설치하기만 하면 백그라운드에서 자동으로 대화창 최적화가 이루어집니다.

## 주요 기능
- 토큰 절감: 대용량 도구 출력 결과를 대화창에 넣지 않고 요약하여 토큰 낭비를 줄입니다.
- 로컬 데이터 관리: 모든 인덱스와 사용 데이터는 외부로 전송되지 않고 로컬 기기에만 저장됩니다.
- 다양한 에이전트 지원: Claude Code, Codex, Gemini CLI 등 여러 코딩 에이전트와 연동됩니다.
- 오프라인 실행: 설치 후 인터넷 연결 없이도 로컬 환경에서 샌드박스와 검색 기능을 수행합니다.

## 참고·주의
- Node.js 24.15.0 이상 버전이 필요합니다.
- Windows 환경에서는 Git Bash(Git for Windows) 설치가 필요합니다.

# momo5502/sogen

> 가상 운영체제 없이 Windows, Linux, macOS 프로그램을 실행하고 모든 동작을 감시·제어할 수 있는 사용자 공간 에뮬레이터입니다.

## 개요
운영체제 API를 처음부터 다시 구현하는 대신 실제 시스템 DLL을 그대로 불러와 실행하여 프로그램이 실제 OS와 똑같이 동작하도록 돕는 도구입니다. 프로그램의 모든 명령어, 메모리 접근, API 호출을 가로채거나 수정할 수 있으며 실행 상태를 저장하고 복원할 수 있습니다. 사용자는 분석할 프로그램을 에뮬레이터에 전달하여 실행하고, 웹 브라우저나 디버거를 통해 내부 동작을 확인하거나 제어할 수 있습니다.

## 주요 기능
- 실제 시스템 DLL 실행: 가짜 함수가 아니라 실제 운영체제의 ntdll, kernel32, user32 등을 그대로 구동합니다.
- 코드 후킹 및 수정: 프로그램이 실행되는 동안 메모리, 명령어, 시스템 호출, API 호출을 가로채고 바꿀 수 있습니다.
- 상태 저장 및 복원: 전체 에뮬레이터 상태를 빠르게 저장하고 불러오거나 미니 덤프를 로드할 수 있습니다.
- 숨겨진 디버깅: IDA Pro나 GDB 같은 친숙한 도구 또는 내장 웹 브라우저 디버거로 프로그램의 안티 디버깅 탐지를 우회하며 분석할 수 있습니다.
- 샌드박스 게임 실행: 그래픽 가상화와 그래픽 변환 계층을 통해 실제 GPU 가속을 활용해 게임과 GUI 프로그램을 구동합니다.
- 결정적 실행: 모든 실행 과정이 명령어 단위로 완벽하게 재현 가능합니다.

## 참고·주의
- macOS 프로그램 실행 기능을 쓰려면 실제 macOS 환경과 해당 라이선스가 필요하며, 타사 하드웨어에서는 실행 제한이 있을 수 있습니다.

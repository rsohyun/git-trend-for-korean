# morluto/rea

> AI 에이전트를 통해 앱, 바이너리, 웹 등 모든 소프트웨어를 역공학하고 동작을 분석할 수 있게 해 주는 도구입니다.

## 개요
REA는 AI 에이전트가 MCP 표준을 이용해 다양한 소프트웨어를 역공학하도록 연결해 주는 플랫폼입니다. 소스 코드가 없거나 복잡한 바이너리, 웹, Electron 등에서 동작 원리를 파악하고 증거를 제공함으로써 개발자와 보안 전문가의 분석 부담을 줄여 줍니다. 사용자는 Node.js 환경에서 setup 명령으로 에이전트와 REA를 등록하고, 원하는 대상 경로나 실행 파일을 지정해 분석을 요청하면 결과와 증거가 로컬에 반환됩니다. 내부적으로 REA는 MCP 서버와 도구 체인을 호출해 정적·동적 정보를 수집하고 구조화된 스키마로 반환합니다.

## 주요 기능
- 다중 플랫폼 역공학: JavaScript/Electron, .NET, 네이티브 바이너리 등을 하나의 인터페이스로 분석합니다.
- AI 에이전트 연동: Claude, Gemini, Grok 등 지원되는 AI와 MCP를 통해 질문만으로 상세 분석을 수행합니다.
- 로컬 증거 제공: 분석 결과와 함께 코드 조각, 호출 흐름 등 증거를 구조화된 JSON 형태로 반환합니다.
- 기존 디스어셈블러 활용: Hopper, Ghidra, IDA 등 설치된 도구와 연동해 정교한 바이너리 분석이 가능합니다.
- 자동 워크플로우 설정: setup 명령으로 에이전트에 REA MCP 서버와 워크플로우를 자동 등록하고 백업합니다.

## 참고·주의
- Node.js와 npm이 필요합니다.
- Linux에서는 `ps` 명령이 PATH에 있어야 합니다.
- 네이티브 바이너리 분석을 위해 Hopper, Ghidra, IDA 등 외부 디스어셈블러가 별도로 설치되어 있어야 합니다.
- 지원되는 AI 서비스(Claude, Gemini 등)의 계정 및 사용량 제한이 적용될 수 있습니다.
- 분석은 로컬에서 실행되지만, 민감한 파일을 외부에 전송하지 않도록 주의해야 합니다.

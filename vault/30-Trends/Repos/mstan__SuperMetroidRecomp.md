# mstan/SuperMetroidRecomp

> 슈퍼 메트로이드(Super Metroid) 게임을 정적 재컴파일 기술로 네이티브 프로그램으로 변환하여 실행할 수 있게 해 주는 프로젝트입니다.

## 개요
슈퍼 메트로이드 원본 게임을 현대 기기에서 고성능으로 즐길 수 있게 해 주는 에뮬레이션·재컴파일 도구입니다. 기존 에뮬레이터의 성능 한계나 호환성 문제를 해결하며, 사용자가 직접 보유한 게임 롬(ROM) 파일을 불러와 실행 파일과 결합하여 네이티브 환경에서 바로 플레이할 수 있습니다.

## 주요 기능
- 정적 재컴파일: 게임의 핵심 CPU 코드를 네이티브 C 코드로 변환하여 실행합니다.
- 화면 비율 및 해상도 조절: 와이드스크린 지원과 함께 HUD 배치를 자유롭게 바꿀 수 있습니다.
- 프레임레이트 설정: 고정 프레임 또는 자동 프레임 타겟을 설정할 수 있습니다.
- 모드 설정: 다양한 게임플레이 및 편의 기능을 모드 메뉴를 통해 켜고 끌 수 있습니다.
- 자동 로그 및 리플레이 기록: 문제 발생 시 디버깅을 위한 세션 로그와 입력 리플레이를 자동으로 저장합니다.

## 참고·주의
- 게임 롬 파일은 제공되지 않으며 사용자가 직접 준비해야 합니다.

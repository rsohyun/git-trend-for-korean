# multica-ai/andrej-karpathy-skills

> AI 코딩 도우미인 Claude Code가 혼자서 잘못된 가정을 하거나 코드를 복잡하게 만드는 실수를 줄이도록 돕는 규칙 파일입니다.

## 개요
AI가 혼자서 섣부르게 코드를 작성하거나 불필요한 기능을 추가하는 문제를 해결해 주는 도구입니다. 개발자가 지정한 원칙에 따라 AI가 묵묵히 가정하여 코드를 망치지 않고, 명확한 목표와 검증 과정을 거치도록 유도합니다. 저장소에서 규칙 파일을 내려받아 프로젝트 폴더에 넣거나 Claude Code 플러그인으로 설치하면 바로 적용됩니다.

## 주요 기능
- 사전 검토: AI가 코드를 작성하기 전에 가정과 모순을 먼저 확인하도록 유도합니다.
- 단순함 유지: 요청받지 않은 복잡한 추상화나 불필요한 코드 작성을 막습니다.
- 최소한의 수정: 수정이 필요한 부분만 정확히 고치고 주변 코드는 건드리지 않습니다.
- 목표 중심 실행: 테스트 코드를 먼저 작성하고 통과하는 방식으로 작업을 완료합니다.

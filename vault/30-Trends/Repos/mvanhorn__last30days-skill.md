# mvanhorn/last30days-skill

> AI 에이전트를 이용해 레딧, 엑스(X), 유튜브, 해커뉴스 등 여러 플랫폼의 최신 정보를 동시에 검색하고 요약해 주는 검색 도구입니다.

## 개요
여러 플랫폼에 흩어져 있는 최근 한 달간의 실사용자 반응과 여론을 한 번에 모아볼 수 있는 도구입니다. 기존 검색 엔진이 찾기 어려운 소셜 미디어의 실시간 토론이나 실제 돈이 오가는 예측 시장 데이터까지 종합해 줍니다. 사용자가 원하는 주제나 인물을 입력하면 에이전트가 각 플랫폼에서 정보를 수집한 뒤 핵심 내용만 간추려 브리핑을 제공합니다.

## 주요 기능
- 다중 플랫폼 동시 검색: 레딧, 엑스(X), 유튜브, 해커뉴스, 폴리마켓 등 다양한 소스의 최신 정보를 한 번에 검색합니다.
- 실사용자 중심 순위 산정: 편집자의 주관 대신 투표, 좋아요, 실제 자금 등 대중의 반응을 기준으로 정보를 정렬합니다.
- 심층 콘텐츠 요약: 긴 유튜브 영상이나 복잡한 토론 스레드에서 핵심 문장과 논점을 정확하게 추출합니다.
- 맞춤형 설정 마법사: 첫 실행 시 간단한 설정 과정을 거쳐 추가 플랫폼과 전문 연구 소스를 간편하게 활성화할 수 있습니다.

## 참고·주의
- 일부 플랫폼은 전체 기능을 사용하기 위해 별도의 계정 인증이나 API 키, 브라우저 세션 설정이 필요할 수 있습니다.

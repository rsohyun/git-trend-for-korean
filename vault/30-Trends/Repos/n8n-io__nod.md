# n8n-io/nod

> 사용자의 컴퓨터에서 직접 실행되며 이메일 확인, 웹 서핑, 일정 관리 등의 반복 업무를 대신 처리해 주는 오픈소스 개인 AI 비서입니다.

## 개요
개인 컴퓨터나 서버에서 실행되며 사용자를 대신해 웹사이트와 앱에서 반복적인 작업을 수행하는 도구입니다. 이메일 정리, 일정 관리, 웹 서핑 등 손이 많이 가는 업무를 자동화하여 시간 낭비를 해결합니다. 사용자가 프로그램을 설치하고 원하는 AI 모델을 연결한 뒤 지시를 내리면, AI가 자체 가상 컴퓨터와 브라우저를 이용해 작업을 완수합니다.

## 주요 기능
- 업무 자동화: 이메일, 캘린더, 슬랙, 노션 등을 연동해 자료를 정리하고 필요한 작업을 수행합니다.
- 승인 기반 실행: 메시지 전송이나 결제 같은 중요한 작업은 반드시 사용자의 확인을 거친 뒤 실행합니다.
- 일정 기반 모니터링: 지정한 웹페이지의 변경 사항을 주기적으로 확인하고 변동이 생기면 알려 줍니다.
- 맞춤형 학습: 사용자의 평소 말투와 대화 스타일을 학습하여 이메일 답변 등을 자연스럽게 작성합니다.
- 기억 유지: 한 번 알려준 수정 사항이나 규칙을 기억하고 이후 업무에 계속 반영합니다.

## 참고·주의
- macOS 14 이상(Apple Silicon 또는 Intel), Windows 11 프리뷰, Linux x64 프리뷰 환경이 필요합니다.
- ChatGPT Plus, Pro 계정 또는 별도의 AI 모델 API 키가 필요합니다.

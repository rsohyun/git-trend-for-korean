# nginx/nginx

> 웹 서버, 부하 분산기(로드 밸런서), 리버스 프록시 등으로 사용할 수 있는 오픈소스 프로그램입니다.

## 개요
웹사이트와 애플리케이션을 인터넷에 안정적으로 서비스할 수 있도록 트래픽을 처리하는 도구입니다. 대규모 접속을 효율적으로 분산하고 보안을 강화해야 하는 문제를 해결합니다. 서버에 공식 패키지나 소스 코드를 설치한 뒤 텍스트 설정 파일을 작성하여 실행하면 웹 요청을 처리할 수 있습니다. 마스터 프로세스와 작업자 프로세스 구조로 동작하여 시스템 자원을 효율적으로 활용합니다.

## 주요 기능
- 웹 서버: 정적 파일을 빠르게 서빙하고 웹사이트를 인터넷에 서비스할 수 있습니다.
- 부하 분산: 여러 서버로 들어오는 네트워크 트래픽을 나누어 처리할 수 있습니다.
- 역방향 프록시: 클라이언트의 요청을 받아 백엔드 서버로 전달하고 응답을 돌려줍니다.
- 콘텐츠 캐싱: 자주 찾는 데이터를 임시로 저장해 두어 응답 속도를 높일 수 있습니다.
- SSL 인증서 적용: HTTPS 암호화 통신을 설정하여 안전한 데이터 전송을 지원합니다.
- 속도 제한: 특정 클라이언트의 과도한 요청을 제한하여 서버 부하를 방지할 수 있습니다.

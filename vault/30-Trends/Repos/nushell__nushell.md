# nushell/nushell

> 파일과 데이터를 단순한 텍스트 대신 표 형태의 구조화된 데이터로 다루어, 직관적인 명령어 조합을 지원하는 새로운 형태의 셸입니다.

## 개요
컴퓨터 명령을 입력하고 실행하는 텍스트 기반 인터페이스 도구입니다. 기존 셸 명령의 출력이 단순 텍스트여서 가공하기 번거롭고 복잡했던 문제를 해결합니다. 설치 후 프로그램을 실행하고 구조화된 데이터를 다루는 명령어를 입력하면 표 형태의 정돈된 결과와 유용한 기능을 얻을 수 있습니다.

## 주요 기능
- 구조화된 데이터 처리: 파일 목록이나 프로세스 정보를 단순 텍스트가 아닌 표 형태로 다룹니다.
- 파이프라인 연동: 여러 명령어를 연결해 데이터를 생성하고 필터링하며 원하는 형태로 소비할 수 있습니다.
- 파일 형식 자동 인식: TOML 등의 파일을 구조화된 데이터로 바로 불러와 내용을 탐색할 수 있습니다.
- 플러그인 확장: 다양한 기능을 필요에 따라 추가하여 셸의 기능을 확장할 수 있습니다.

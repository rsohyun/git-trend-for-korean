# nvm-sh/nvm

> 명령줄에서 여러 Node.js 버전을 간편하게 설치하고 전환할 수 있게 해 주는 버전 관리 도구입니다.

## 개요
프로젝트마다 서로 다른 Node.js 버전을 요구할 때 발생하는 충돌 문제를 해결합니다. 사용자는 간단한 명령어로 특정 버전을 설치하고 전환하여 즉시 사용할 수 있습니다. 유닉스 계열 환경과 POSIX 호환 셸에서 사용자별로 독립적으로 설치하여 동작합니다.

## 주요 기능
- 버전 관리: 명령어 하나로 다양한 버전의 Node.js를 설치하고 전환할 수 있습니다.
- 자동 버전 전환: 프로젝트 폴더에 있는 설정 파일을 인식해 자동으로 버전을 바꿀 수 있습니다.
- 전역 패키지 이전: Node.js 버전을 바꿀 때 사용하던 패키지를 쉽게 옮길 수 있습니다.
- 장기 지원 버전 지원: 안정적인 장기 지원 버전을 간편하게 확인하고 설치할 수 있습니다.
- 셸 연동: 다양한 셸 환경에서 명령어 자동 완성 기능을 사용할 수 있습니다.

## 참고·주의
- Windows 시스템에서는 기본 지원되지 않으며 WSL(Windows Subsystem for Linux) 환경이 필요합니다.

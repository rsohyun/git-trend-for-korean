# obra/superpowers

> AI 코딩 도구가 무작정 코드를 작성하는 대신, 철저한 설계와 계획을 거쳐 자율적으로 개발을 진행하도록 돕는 프레임워크입니다.

## 개요
AI 코딩 에이전트가 즉흥적으로 코드를 짜며 생기는 실수를 막고 체계적인 개발을 돕는 도구입니다. 요구사항 분석, 설계, 테스트 주도 개발(TDD) 단계를 거쳐 에이전트가 스스로 구현 계획을 세우고 작업을 수행하게 만듭니다. 사용자는 지원되는 AI 개발 도구에 플러그인 형태로 설치한 뒤 평소처럼 대화하며 개발을 진행하면 됩니다.

## 주요 기능
- 요구사항 구체화: 코드를 작성하기 전에 사용자와 대화하여 명확한 명세를 먼저 도출합니다.
- 구현 계획 수립: 테스트 중심 개발 원칙을 반영한 세부적인 작업 계획을 자동으로 세웁니다.
- 자율 하위 에이전트 개발: 계획에 따라 여러 작업 단계를 에이전트가 스스로 검토하며 자율적으로 실행합니다.

## 참고·주의
- Claude Code, Cursor, GitHub Copilot 등 지원되는 AI 코딩 도구 중 최소 하나를 사용하고 있어야 합니다.

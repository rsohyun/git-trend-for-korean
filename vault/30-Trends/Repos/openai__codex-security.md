# openai/codex-security

> 코드의 보안 취약점을 찾고, 검증하며, 수정 패치를 생성해 주는 OpenAI의 보안 도구입니다.

## 개요
코드에 숨겨진 보안 취약점을 자동으로 찾아내어 위험을 분석하고 해결책을 제시하는 도구입니다. 복잡한 소스 코드 분석 과정에서 수동으로 취약점을 찾고 검증해야 하는 번거로움을 해결해 줍니다. 명령줄 인터페이스(CLI), 타입스크립트(TypeScript) SDK, 또는 깃허브 액션(GitHub Actions)을 통해 저장소를 스캔하고 상세한 보안 보고서를 얻을 수 있습니다.

## 주요 기능
- 취약점 스캔: 전체 저장소, 특정 경로, 또는 깃(Git) 변경 사항에서 보안 취약점을 찾습니다.
- 패치 생성 및 검증: 발견된 취약점에 대한 수정 패치를 만들고 기존 수정 사항을 검증합니다.
- 보안 정책 작성: 프로젝트의 보안 정책 문서(SECURITY.md) 초안을 작성하고 위협 모델을 저장합니다.
- 외부 도구 연동: 타사 스캐너 결과를 가져오거나, 리니어(Linear), 지라(Jira), 깃허브로 취약점을 추적합니다.
- 다양한 형식 내보내기: 스캔 결과를 SARIF, JSON, CSV 형식으로 내보내거나 클라우드에 게시할 수 있습니다.

## 참고·주의
- Node.js 22.13.0 이상(22.x 버전), 24.x 또는 26.x 버전과 Python 3.10 이상이 필요합니다.

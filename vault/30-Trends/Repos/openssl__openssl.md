# openssl/openssl

> 웹 통신 보안과 암호화 기능을 구현할 수 있도록 돕는 오픈소스 라이브러리 및 도구 모음입니다.

## 개요
안전한 인터넷 통신을 위해 TLS와 같은 보안 프로토콜을 구현해야 하는 개발자의 불편을 해결합니다. 소스 코드를 내려받아 빌드하거나 운영체제별 패키지를 설치해 프로그램 개발과 보안 관리 작업에 활용합니다. 강력한 암호화 알고리즘과 인증서 관리 기능을 제공하여 안전한 네트워크 환경을 구축할 수 있습니다.

## 주요 기능
- TLS 통신 구현: 최신 버전의 TLS 및 QUIC 프로토콜을 프로그램에 적용할 수 있습니다.
- 암호화 라이브러리 제공: 독립적으로 사용할 수 있는 강력한 범용 암호화 기능을 제공합니다.
- 암호화 작업 도구: 명령줄 도구를 통해 인증서 생성, 키 관리, 암호화 테스트 등을 수행할 수 있습니다.
- FIPS 표준 준수: 보안 표준을 충족하는 검증된 암호화 모듈을 포함하고 있습니다.

## 참고·주의
- 국가별로 암호화 기술의 사용이나 수출에 법적 제한이 있을 수 있으므로 확인이 필요합니다.

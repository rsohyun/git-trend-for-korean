# openvinotoolkit/openvino

> 다양한 딥러닝 모델의 연산 속도를 최적화하고 CPU, GPU, NPU 등 여러 하드웨어에서 실행할 수 있게 해 주는 AI 배포 도구입니다.

## 개요
인공지능 모델을 실제 서비스나 기기에 적용할 때 발생하는 속도 저하와 자원 소모 문제를 해결합니다. PyTorch나 TensorFlow 등으로 만든 모델을 변환하여 가벼운 형태로 최적화합니다. 사용자는 파이썬 환경에서 패키지를 설치한 뒤 모델을 변환하고 컴파일하여 빠른 속도로 추론 결과를 얻을 수 있습니다. 인텔 프로세서와 다양한 하드웨어 가속기에서 효율적으로 동작하도록 설계되었습니다.

## 주요 기능
- 인공지능 모델 최적화: 딥러닝 모델의 연산 속도를 높이고 자원 사용량을 줄입니다.
- 다양한 프레임워크 지원: PyTorch, TensorFlow, ONNX 등 여러 도구로 만든 모델을 변환할 수 있습니다.
- 다양한 하드웨어 호환성: CPU, 그래픽카드(GPU), NPU(신경망 처리 장치) 등 여러 기기에서 모델을 실행할 수 있습니다.
- 생성형 AI 지원: 대형 언어 모델과 이미지 생성 모델을 효율적으로 실행하는 파이프라인을 제공합니다.

## 참고·주의
- 최적화된 성능을 내기 위해 지원되는 하드웨어 및 시스템 요구 사양을 확인해야 합니다.

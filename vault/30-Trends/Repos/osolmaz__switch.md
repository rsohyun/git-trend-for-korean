# osolmaz/switch

> 텍스트를 생성하지 않고 확률로만 답하는 '결정 모델'을 활용해 작업 수행 과정을 자동화하는 프로그램 개발 틀입니다.

## 개요
텍스트 생성이 아닌 제한된 보기 중에서 선택만 하는 인공지능 모델을 활용해 복잡한 태스크를 단계별로 해결할 수 있도록 돕는 도구입니다. 기존 대형 언어 모델이 문서 전체를 한 번에 읽으며 겪는 높은 비용과 맥락 낭비 문제를 해결합니다. 사용자가 직접 정의한 규칙에 따라 모델이 필요한 정보만 골라 읽으며 다음 단계를 스스로 결정하도록 코드를 작성할 수 있습니다.

## 주요 기능
- 단계별 상태 관리: 복잡한 작업을 여러 개의 상태와 질문으로 나누어 처리할 수 있습니다.
- 선택지 기반 제어: 인공지능 모델이 직접 도구 호출 명령을 내리지 않고 프로그램이 제공한 보기 중에서 선택하게 만듭니다.
- 기록과 재생: 실행 과정을 파일로 저장하고 모델 호출 없이 그대로 다시 실행할 수 있습니다.
- 다양한 예제 지원: 체스 게임, 문서 채점 기준 평가, 위키피디아 문서 탐색 등의 예제를 제공합니다.

## 참고·주의

# p-e-w/heretic

> 비싼 재학습 과정 없이 대형 언어 모델의 검열을 해제하고 특정 성향을 조절할 수 있는 프로그램입니다.

## 개요
일반 컴퓨터에서 대형 언어 모델의 내부 동작을 수학적 기법으로 조절해 원하는 성향으로 바꾸는 도구입니다. 기존에는 대규모 컴퓨팅 자원이 필요했던 모델 수정 작업을 복잡한 전문 지식 없이도 직접 수행할 수 있게 해 줍니다. 사용자가 명령어를 실행해 모델을 처리하면, 검열이 해제되거나 특정 문체와 감정이 조절된 새로운 모델 파일을 얻을 수 있습니다.

## 주요 기능
- 검열 해제: 인공지능의 거부 응답을 억제하고 검열을 제거하는 기본 기능을 제공합니다.
- 성향 조절: 불필요한 미사여구, 지나친 아첨, 감정 표현 등을 설정 파일에 따라 줄일 수 있습니다.
- 하드웨어 최적화: 실행 시 시스템을 분석하여 사용 가능한 하드웨어에 최적화된 배치 크기를 자동으로 설정합니다.
- 모델 테스트 및 공유: 처리가 끝난 모델을 바로 대화로 테스트하거나 허깅 페이스(Hugging Face)에 업로드할 수 있습니다.
- 플러그인 지원: 사용자가 직접 평가 도구나 수정 방식을 만들어 원하는 대로 모델 제어 방식을 확장할 수 있습니다.

## 참고·주의
- 파이썬 3.10 이상 버전과 하드웨어에 맞는 파이토치(PyTorch) 2.6 이상 환경이 필요합니다.
- 허거틱(Heretic) 1.x 버전용 설정 파일은 2.x 버전과 호환되지 않습니다.

# patch-gg/pixelfx

> 244개의 픽셀 아트 효과와 애니메이션을 제공하고, Claude 스킬로 새로운 효과를 직접 만들 수 있게 해 주는 라이브러리입니다.

## 개요
pixelfx는 다양한 카테고리의 픽셀 아트 VFX를 코드 형태로 모아 둔 도구입니다. 브라우저 게임이나 엔진에서 직접 import해 실시간으로 재생하거나, 스프라이트 시트와 메타 데이터를 추출해 기존 파이프라인에 바로 사용할 수 있습니다. 설치 후 원하는 효과를 import하고 프레임을 생성·업데이트·그리기만 하면 화면에 효과가 나타납니다. 추가로 Claude Code 스킬을 이용해 텍스트 프롬프트만으로 새로운 효과 코드를 생성할 수 있습니다.

## 주요 기능
- 실시간 재생: 브라우저 환경에서 효과를 바로 실행하고 캐릭터와 겹쳐 그릴 수 있습니다.
- 스프라이트 시트 출력: Node 도구로 PNG 시트와 Aseprite 호환 JSON을 생성해 모든 엔진에서 사용합니다.
- 팔레트 교체: 색상 팔레트를 바꿔 같은 효과를 다양한 색상으로 재현할 수 있습니다.
- 액팅 지원: 캐릭터 동작과 연계된 효과(윈드업·히트·리커버리)를 데이터로 제공해 완전한 공격 연출을 만들 수 있습니다.
- Claude 스킬: 텍스트 설명만으로 새로운 픽셀 효과 코드를 자동 생성합니다.

## 참고·주의
- Node.js와 npm이 필요합니다.
- Claude 스킬을 사용하려면 Anthropic Claude 계정 및 API 접근 권한이 필요합니다.

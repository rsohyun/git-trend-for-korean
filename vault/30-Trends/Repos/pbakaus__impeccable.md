# pbakaus/impeccable

> Impeccable은 코딩 에이전트용 디자인 어휘 체계로, 디자인을 조정·검토하고 AI가 만든 UI의 품질 문제를 사전에 탐지합니다.

## 개요
Impeccable은 코딩 에이전트가 UI 코드를 생성·수정할 때 사용할 수 있는 디자인 명령어 집합을 제공하는 도구입니다. 사용자는 프로젝트 루트에서 설치 후 에이전트에 /impeccable init를 실행해 제품 정보를 기록하고, 이후 polish, bolder, critique, audit 등 명령어로 디자인을 조정하거나 품질을 검토합니다. 명령어는 UI 요소를 지정해 구체적인 변형을 적용하거나 자동으로 디자인 규칙을 검사해 슬롭을 감지하고, 결과는 코드에 바로 반영됩니다. CLI와 Chrome 확장, CI 연동도 지원해 로컬·CI·브라우저 어디서든 검사를 실행할 수 있습니다.

## 주요 기능
- 스티어링 명령: bolder, quieter 등으로 디자인 스타일을 강화하거나 완화할 수 있습니다.
- 리뷰 명령: critique와 audit으로 사용성·접근성·성능을 점수화하고 개선 항목을 확인할 수 있습니다.
- 슬롭 탐지: 62개의 결정적 규칙이 UI의 레이아웃·색상·텍스트 문제를 자동으로 찾아냅니다.
- 라이브 모드: 브라우저에서 요소를 선택해 실시간으로 변형을 적용하고 코드를 즉시 업데이트합니다.
- CI·터미널 스캔: npx impeccable detect 명령으로 프로젝트 디렉터리·URL을 검사해 JSON·GitHub Annotations 등으로 결과를 출력합니다.
- 디자인 문서화: document 명령으로 현재 시각 시스템을 DESIGN.md에 기록해 일관성을 유지합니다.

## 참고·주의
- Node.js와 npx가 설치된 환경이 필요합니다.
- 디자인 훅은 지원되는 코딩 에이전트에만 자동 설치됩니다.
- 라이브 모드 사용 시 로컬 개발 서버와 CSP 설정을 확인해야 합니다.

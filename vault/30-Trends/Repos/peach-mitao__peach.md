# peach-mitao/peach

> Peach는 개인용 로컬 우선 비디오 메타데이터 스크래퍼이자 미디어 관리 프로그램입니다.

## 개요
Peach는 로컬 및 클라우드 저장소에 있는 비디오 파일의 메타데이터를 자동으로 수집하고 정리해 주는 도구입니다. 파일명, NFO, 영상 코드 등을 인식해 제목·출연자·스튜디오·표지를 여러 출처에서 가져와 사용자가 직접 편집한 내용은 보존합니다. 설치 후 미디어 폴더를 지정하고 스캔하면 웹 기반 인터페이스에서 검색·필터·플레이어를 통해 영상을 감상하고 기록을 확인할 수 있습니다. 메타데이터와 시청 기록은 로컬에 저장되며, 필요 시 클라우드 드라이브나 SMB 공유와도 함께 탐색할 수 있습니다.

## 주요 기능
- 메타데이터 스크래핑: 영상 코드·NFO 등을 읽어 다중 출처에서 제목·출연자·표지 등을 자동으로 채워 줍니다.
- 로컬·클라우드 라이브러리 통합: 로컬 디스크·SMB·클라우드 스토리지·PikPak를 하나의 뷰에서 탐색합니다.
- 재생·히스토리 관리: 웹·외부 플레이어 지원, 자막·속도·회전·이어보기·타임라인 미리보기 기능을 제공합니다.
- 팔로우·발견 기능: 출연자·제작자 업데이트를 추적하고 새로운 작품을 발견해 원하는 목록에 추가합니다.
- 클라우드 다운로드: 영상 코드를 검색하거나 마그넷 링크를 제출해 다운로드 후 자동으로 라이브러리에 정리합니다.
- 라이브러리 관리: 태그·중복·버전·파트를 관리하고 메타데이터와 시청 기록을 로컬에 안전하게 보관합니다.

## 참고·주의
- Windows, macOS, Docker 등 지원 운영체제에서 실행해야 합니다.
- 소스에서 빌드하려면 Git, uv, Python 3.14 이상이 필요합니다.
- 데스크톱 빌드는 서명되지 않았으며 macOS 빌드는 notarized되지 않아 보안 경고가 나타날 수 있습니다.
- 저작권이 있는 영상은 사용자가 직접 소유하거나 적법한 권한이 있어야 합니다.

# php/php-src

> 세계적인 웹 사이트와 블로그를 만드는 데 널리 쓰이는 PHP 스크립트 언어의 공식 소스 코드 저장소입니다.

## 개요
웹 개발에 최적화된 범용 프로그래밍 언어인 PHP를 직접 빌드하고 실행할 수 있게 해 주는 소스 코드 모음입니다. 소스 코드를 직접 컴파일하여 최신 기능을 테스트하거나 자신만의 PHP 실행 환경을 구축할 수 있습니다. 사용자는 소스 코드를 내려받아 빌드 과정을 거친 뒤 직접 PHP 프로그램을 실행하고 테스트할 수 있습니다.

## 주요 기능
- 소스 코드 빌드: 운영체제별 빌드 도구를 이용해 PHP 소스 코드를 직접 컴파일할 수 있습니다.
- 내장 테스트 실행: 방대한 자체 테스트 스위트를 실행하여 빌드된 PHP의 정상 작동 여부를 확인할 수 있습니다.
- 확장 기능 관리: 다양한 기본 확장 기능과 추가 확장 기능을 활용해 PHP 기능을 확장할 수 있습니다.

## 참고·주의
- 소스 코드를 빌드하려면 autoconf, bison, re2c 등의 추가 개발 도구가 필요합니다.

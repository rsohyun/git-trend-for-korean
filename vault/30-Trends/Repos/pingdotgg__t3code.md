# pingdotgg/t3code

> T3 Code는 로컬에 설치된 다양한 코딩 AI 에이전트를 모바일·웹·데스크톱 앱으로 제어할 수 있게 해 주는 도구입니다.

## 개요
T3 Code는 Claude, Codex, Cursor 등 여러 코딩 AI 에이전트를 하나의 인터페이스에서 관리합니다. 각 에이전트를 별도로 설치·인증하면, T3 서버를 실행해 모바일 앱이나 웹·데스크톱 클라이언트에서 바로 호출할 수 있습니다. 서버를 시작하고 앱에 연결하면, 코드 작성·디버깅·테스트 등을 에이전트에게 요청하고 결과를 실시간으로 확인합니다. 내부적으로는 MCP(에이전트와 외부 도구를 연결하는 표준) 프로토콜을 사용합니다.

## 주요 기능
- 다중 에이전트 지원: Claude, Codex, Cursor 등 여러 코딩 AI를 한 화면에서 제어합니다.
- 멀티플랫폼 앱 제공: iOS·Android 모바일, 웹, Electron 기반 데스크톱 앱으로 언제든 접근합니다.
- 원격 서비스 실행: `t3` 명령으로 서버를 시작하고 백그라운드 서비스로 유지할 수 있습니다.
- 자동 업데이트 기능: `t3 update` 명령으로 최신 릴리스를 손쉽게 적용합니다.
- 키보드 단축키 및 UI 커스터마이징: 사용자 정의 단축키와 테마 설정을 지원합니다.
- 소스 제어 연동: Git 등 버전 관리와 연동해 에이전트 작업을 관리합니다.

## 참고·주의
- 사용하려면 최소 하나의 에이전트 CLI를 설치하고 인증해야 합니다.
- 각 에이전트마다 별도 설치·로그인 절차가 필요합니다.
- 아직 초기 단계라 버그가 존재할 수 있습니다.
- 대규모 기여는 현재 받지 않으며, 작은 수정만 고려됩니다.

# prometheus/prometheus

> 시스템과 서비스의 상태를 주기적으로 수집하고 모니터링할 수 있게 해 주는 시계열 데이터베이스 시스템입니다.

## 개요
서버나 애플리케이션의 성능 지표를 수집하고 분석하여 시스템 장애나 이상 징후를 빠르게 파악할 수 있도록 돕는 도구입니다. 분산 저장소에 대한 의존성 없이 독립적으로 동작하며, 수집된 데이터를 바탕으로 경고를 발생시키거나 시각화할 수 있습니다. 사용자는 프로그램과 설정 파일을 내려받아 실행한 뒤 웹 인터페이스를 통해 모니터링 결과를 확인할 수 있습니다.

## 주요 기능
- 다차원 데이터 모델: 메트릭 이름과 키-값 차원으로 정의되는 시계열 데이터를 제공합니다.
- PromQL 쿼리 언어: 수집된 데이터를 유연하고 강력하게 조회할 수 있습니다.
- 풀 모델 수집: HTTP 요청을 통해 주기적으로 대상 서버에서 지표를 수집합니다.
- 서비스 자동 발견: 정적 설정이나 서비스 디스커버리를 통해 모니터링 대상을 자동으로 찾습니다.
- 경고 시스템: 특정 조건이 충족되면 관리자에게 알림을 보낼 수 있습니다.

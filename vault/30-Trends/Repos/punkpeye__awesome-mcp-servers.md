# punkpeye/awesome-mcp-servers

> 다양한 외부 서비스와 도구를 AI 모델에 연결해 주는 Model Context Protocol(MCP) 서버들의 모음입니다.

## 개요
인공지능 모델이 파일, 데이터베이스, 외부 API 등 다양한 자원에 안전하게 접근할 수 있도록 돕는 MCP 서버 목록을 제공합니다. 개발자가 자신의 AI 애플리케이션에 필요한 연동 기능을 직접 찾아 구현하거나 참고할 수 있도록 분야별로 분류되어 있습니다. 사용자는 원하는 서버의 저장소에 접속하여 설치하고 자신의 AI 클라이언트에 연결하면 됩니다.

## 주요 기능
- 분야별 서버 탐색: 데이터베이스, 개발자 도구, 클라우드 플랫폼 등 다양한 목적의 MCP 서버를 카테고리별로 찾을 수 있습니다.
- 공식 구현체 확인: 제작사가 직접 제공하는 신뢰할 수 있는 공식 MCP 서버를 식별할 수 있습니다.
- 사용 언어 및 운영체제 안내: 파이썬, 타입스크립트 등 구현 언어와 지원하는 운영체제 정보를 미리 확인할 수 있습니다.
- 원격 및 로컬 서버 구분: 직접 설치해 실행하는 로컬 서버와 URL로 바로 연결하는 원격 서버를 골라 쓸 수 있습니다.
- 튜토리얼 및 가이드 제공: MCP 설정 방법과 활용법을 익힐 수 있는 학습 자료를 함께 제공합니다.

# rails/rails

> 데이터베이스와 연결된 웹 사이트와 애플리케이션을 쉽고 빠르게 만들 수 있게 해 주는 웹 개발 프레임워크입니다.

## 개요
웹 애플리케이션을 체계적으로 개발할 수 있도록 돕는 도구입니다. 데이터 관리, 화면 구성, 요청 처리 과정이 복잡하게 얽히는 문제를 해결합니다. 사용자는 명령어를 통해 프로젝트를 생성하고 서버를 실행하여 웹 서비스를 구축할 수 있습니다. 모델, 뷰, 컨트롤러 구조를 바탕으로 필요한 기능을 효율적으로 조립할 수 있습니다.

## 주요 기능
- 모델 레이어: 데이터베이스의 정보를 객체로 다루고 비즈니스 로직을 처리할 수 있습니다.
- 뷰 레이어: HTML과 루비 코드를 조합하여 웹 페이지나 이메일 화면을 생성할 수 있습니다.
- 컨트롤러 레이어: 들어오는 웹 요청을 받아 적절한 모델과 뷰를 연결하고 응답을 돌려줍니다.
- 액션 메일러: 애플리케이션에서 이메일을 손쉽게 생성하고 발송할 수 있습니다.
- 액티브 잡: 백그라운드에서 실행할 작업을 정의하고 다양한 대기열 시스템에서 처리할 수 있습니다.
- 액션 케이블: 웹소켓을 연동하여 실시간 통신 기능을 구현할 수 있습니다.

# ranxianglei/billion-context

> AI 대화 도구의 입력 데이터 양을 대폭 줄여 주어, 대화 기록이 길어져도 성능 저하 없이 장기간 한 세션을 유지할 수 있게 해 주는 맥락 압축 플러그인입니다.

## 개요
인공지능 대화 프로그램과 모델 API 사이에 위치해 대화 내용을 계층적으로 압축하는 도구입니다. 대화가 길어질수록 비용이 늘어나고 컨텍스트 한계로 대화가 끊기는 문제를 해결합니다. 프로그램을 설치하고 대화를 시작하면 모델이 직접 필요한 내용을 요약하여 토큰 사용량을 줄여 줍니다. 이를 통해 사용자는 제한된 컨텍스트 환경에서도 수개월 동안 이어지는 장기 대화를 유지할 수 있습니다.

## 주요 기능
- 모델 주도 압축: AI 모델이 직접 언제 무엇을 압축할지 판단하여 고품질 요약을 생성합니다.
- 토큰 절약: 전체 대화 기록을 유지하면서도 토큰 사용량을 5배 이상 줄여 줍니다.
- 장기 세션 유지: 컨텍스트 한계 걱정 없이 수개월 동안 하나의 대화 세션을 이어갈 수 있습니다.
- 소형 창 지원: 100K 수준의 작은 컨텍스트 창으로도 대규모 대화 처리가 가능합니다.

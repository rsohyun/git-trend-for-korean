# react/react

> 웹과 모바일 앱에서 사용자 화면을 쉽게 만들 수 있게 해 주는 자바스크립트 라이브러리입니다.

## 개요
웹사이트와 모바일 앱의 사용자 인터페이스(UI)를 효율적으로 개발할 수 있도록 돕는 도구입니다. 화면이 복잡해질 때 코드가 복잡해지고 유지보수가 어려워지는 문제를 해결해 줍니다. 개발자는 독립된 조각인 컴포넌트를 조합하여 화면을 만들고 데이터 변화에 맞춰 자동으로 화면이 갱신되도록 구현할 수 있습니다. 기존 프로젝트에 점진적으로 추가하거나새로운 애플리케이션의 기반으로 사용할 수 있습니다.

## 주요 기능
- 선언적 UI: 화면 상태에 따라 변경된 부분만 효율적으로 렌더링하여 코드를 예측 가능하고 쉽게 디버깅할 수 있습니다.
- 컴포넌트 기반: 독립적으로 상태를 관리하는 컴포넌트를 만들어 복잡한 사용자 인터페이스를 조립할 수 있습니다.
- 다양한 플랫폼 지원: 웹 환경뿐만 아니라 서버 사이드 렌더링과 모바일 앱 개발까지 확장하여 사용할 수 있습니다.
- 점진적 도입: 전체 프로젝트를 한 번에 바꾸지 않고 필요한 부분만 골라서 기존 기술 스택에 추가할 수 있습니다.

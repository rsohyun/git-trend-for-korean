# richiemcilroy/Tov

> 기존 자바스크립트와 타입스크립트 코드를 수정 없이 그대로 읽어 가볍고 빠른 네이티브 실행 파일로 만들어 주는 언어 및 컴파일러입니다.

## 개요
타입스크립트 코드를 실행할 때 노드(Node)나 뷘(Bun)보다 훨씬 빠르고 적은 메모리를 쓰게 해 주는 도구입니다. 기존 자바스크립트 실행 환경에서 겪던 속도 저하나 높은 메모리 사용량 문제를 해결합니다. 사용자는 명령어 한 줄로 코드를 실행하거나 컴파일하여 독립된 프로그램으로 만들 수 있습니다.

## 주요 기능
- 타입스크립트 실행: 기존 타입스크립트, 뷘, 노드용 코드를 수정 없이 그대로 빌드하고 실행할 수 있습니다.
- 네이티브 바이너리 컴파일: 소스 코드를 크기가 작고 실행 속도가 빠른 네이티브 실행 파일로 변환합니다.
- 내장 API 지원: 노드와 뷘의 기본 라이브러리 및 npm 패키지를 그대로 사용할 수 있습니다.
- 제스트(Jest) 스타일 테스트: 제스트 문법을 지원하는 테스트 도구로 소스 코드를 검증할 수 있습니다.

## 참고·주의
- 현재 macOS(arm64)와 리눅스 환경만 지원하며 윈도우는 아직 지원하지 않습니다.
- 설치 시 깃(git), C 컴파일러가 필요하며 러스트(Rust)가 없으면 함께 설치됩니다.
- 버전 0.1.0 단계의 초기 프로젝트로 사양이 자주 바뀔 수 있습니다.

# rust-lang/rust

> 누구나 안전하고 효율적인 프로그램을 만들 수 있게 해 주는 프로그래밍 언어 저장소입니다.

## 개요
안전성과 성능이 뛰어난 프로그램을 작성할 수 있게 해 주는 프로그래밍 언어 개발 도구입니다. 메모리 오류나 다중 작업 관련 버그를 실행 전에 미리 잡아 주어 프로그램의 안정성을 높여 줍니다. 소스 코드를 작성한 뒤 컴파일러를 통해 실행 파일을 만들어 프로그램을 완성할 수 있습니다.

## 주요 기능
- 성능: 빠르고 메모리 효율성이 높아 중요한 서비스나 임베디드 기기에 적합합니다.
- 안전성: 풍부한 형식 시스템과 소유권 모델로 메모리와 스레드 안전성을 보장합니다.
- 생산성: 상세한 문서와 친절한 오류 안내를 제공하여 개발을 돕습니다.
- 개발 도구: 패키지 관리자, 자동 형식 지정기, 코드 분석기 등 다양한 부가 도구가 포함되어 있습니다.

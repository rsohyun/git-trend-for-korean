# scenario-labs/skills

> 클로드 코드나 커서 같은 AI 코딩 도구가 이미지, 영상, 3D 에셋을 직접 제작할 수 있도록 시나리오(Scenario) 연동 기능을 가르쳐 주는 에이전트 스킬 모음입니다.

## 개요
이 도구는 AI 코딩 에이전트가 게임과 콘텐츠 제작에 필요한 그래픽 에셋을 전문적으로 생성할 수 있도록 돕습니다. AI가 적절한 모델을 선택하고 비용을 미리 확인한 뒤 일관된 캐릭터를 만들지 못하는 문제를 해결합니다. 사용자는 명령어 입력 한 번으로 필요한 스킬을 설치하고, AI 에이전트에 시나리오(Scenario) 계정을 연결해 원격으로 미디어 콘텐츠를 생성할 수 있습니다.

## 주요 기능
- 시나리오 MCP 연동: AI 에이전트가 시나리오 서비스와 통신하여 이미지를 생성하고 모델을 관리할 수 있습니다.
- 에셋 제작 및 편집: 게임 개발과 콘텐츠 제작에 필요한 이미지, 영상, 오디오, 3D 에셋을 AI로 직접 만들 수 있습니다.
- 캐릭터 일관성 유지: 여러 장의 이미지나 영상에서 동일한 캐릭터와 브랜드 스타일을 유지할 수 있습니다.
- 전문 제작 도구 제어: 블렌더(Blender), 마야(Maya), 유니티(Unity) 등 외부 전문 그래픽 프로그램과 게임 엔진을 조작하는 전문가 팀 스킬을 제공합니다.

## 참고·주의
- 시나리오(Scenario) 계정 및 API 키 또는 MCP 서버 연결이 필요합니다.
- 외부 3D 및 영상 제작 도구(Blender, Unreal Engine 등)를 제어하려면 해당 프로그램이 PC에 설치되어 있어야 합니다.

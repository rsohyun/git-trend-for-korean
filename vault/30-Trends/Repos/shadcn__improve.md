# shadcn/improve

> 능력이 뛰어난 AI 모델로 소스 코드를 분석해 문제를 찾고, 저렴한 모델이 실행할 수 있는 상세한 구현 계획서를 작성해 주는 도구입니다.

## 개요
AI 에이전트(AI 기반 작업 도구)를 활용해 소스 코드의 보안, 성능, 기술 부채 등을 종합적으로 진단하는 도구입니다. 복잡하고 비용이 많이 드는 코드 분석과 계획 수립은 똑똑한 모델이 맡고, 실제 코드를 수정하는 작업은 저렴한 모델에게 맡겨 개발 비용을 아낄 수 있게 해 줍니다. 사용자가 명령어 하나를 실행하면 코드 문제점 목록과 우선순위가 담긴 보고서가 나오고, 마음에 드는 항목을 지정하면 다른 AI나 사람이 바로 실행할 수 있는 독립된 계획서 파일이 만들어집니다.

## 주요 기능
- 코드 분석 및 계획 작성: 소스 코드를 면밀히 진단하고 다른 AI가 바로 실행할 수 있는 상세한 구현 계획서를 작성합니다.
- 맞춤형 감사 수행: 전체 코드 분석뿐만 아니라 보안, 성능, 현재 브랜치 변경 사항 등 목적에 맞는 집중 진단이 가능합니다.
- 실행 및 검증 관리: 저렴한 모델을 격리된 환경에서 실행시켜 계획서대로 잘 구현되었는지 검토하고 결과를 보고받습니다.
- 작업 백로그 관리: 완료된 작업과 남은 작업을 정리하고 변경된 코드에 맞춰 계획서를 최신 상태로 유지합니다.

## 참고·주의
- 에이전트 기술(Agent Skills) 규격을 지원하는 AI 에이전트 환경에서만 사용할 수 있습니다.
- 이 도구 자체는 직접 소스 코드를 수정하지 않으며, 계획서 작성과 검토 역할만 수행합니다.

# sheprd-labs/sheprd

> macOS, Linux, Windows에서 터미널, Git 작업 트리, AI 에이전트를 한 화면에서 관리할 수 있는 네이티브 프로그램입니다.

## 개요
터미널 세션과 Git 저장소가 여러 개 흩어져 있어 개발 환경을 한눈에 파악하기 불편할 때 사용하는 도구입니다. 로컬, 원격(SSH), 클라우드 환경의 저장소와 AI 에이전트 상태를 사이드바 하나로 모아 보여 줍니다. 사용자는 앱을 설치하고 실행하여 여러 탭과 분할 화면으로 터미널을 다루고, AI 에이전트의 변경 사항을 리뷰하며 작업을 원격 호스트로 옮길 수 있습니다. 별도의 백그라운드 프로세스가 터미널을 관리하므로 앱을 닫아도 작업은 계속 유지됩니다.

## 주요 기능
- 작업 공간 관리: 로컬, SSH, 클라우드 환경의 저장소, Git 작업 트리, 터미널 탭, 분할 화면을 한 곳에서 정리할 수 있습니다.
- AI 에이전트 협업: 에이전트의 상태를 실시간으로 확인하고, 변경된 코드에 주석을 달아 피드백을 보낼 수 있습니다.
- 작업 공간 텔레포트: 커밋과 실행 중인 프로그램, AI 세션까지 포함한 작업 트리를 다른 원격 호스트로 통째로 옮길 수 있습니다.
- 브라우저 미리보기: 에이전트가 띄운 웹페이지를 앱 내에서 직접 확인하고, 특정 요소를 지정해 메모를 남길 수 있습니다.
- 시스템 모니터링: CPU, 메모리, GPU 사용량을 호스트별로 실시간 추적하고 AI 서비스 이용량을 확인할 수 있습니다.

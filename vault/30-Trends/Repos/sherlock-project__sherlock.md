# sherlock-project/sherlock

> 특정 사용자 이름으로 400개가 넘는 소셜 미디어 플랫폼에서 계정 존재 여부를 한 번에 찾아 주는 도구입니다.

## 개요
지정한 사용자 이름이 여러 웹사이트에 가입되어 있는지 일일이 확인해야 하는 번거로움을 해결해 주는 프로그램입니다. 사용자가 찾으려는 이름을 입력하고 실행하면, 400개가 넘는 소셜 네트워크와 플랫폼을 자동으로 검색해 계정을 찾아 줍니다. 검색 결과는 화면에 바로 표시되거나 텍스트, CSV, Excel 파일로 저장할 수 있습니다.

## 주요 기능
- 다중 계정 검색: 여러 사용자 이름을 동시에 입력하여 한 번에 검색할 수 있습니다.
- 결과 파일 저장: 찾아낸 계정 목록을 텍스트 파일이나 표 형식 파일로 저장할 수 있습니다.
- 특정 사이트 지정: 전체 사이트 대신 원하는 특정 플랫폼만 선택해서 검색할 수 있습니다.
- 프록시 지원: 프록시 서버를 통해 요청을 우회하여 검색을 진행할 수 있습니다.

## 참고·주의
- ParrotOS 및 Ubuntu 24.04의 일부 제3자 패키지는 문제가 있을 수 있어 uv, pipx, pip 또는 Docker 사용을 권장합니다.

# shiyu-coder/Kronos

> 전 세계 45개 이상의 금융 거래소 데이터로 학습한 최초의 오픈소스 금융 캔들스틱(K라인) 기반 파운데이션 모델입니다.

## 개요
금융 시장의 복잡하고 노이즈가 많은 시계열 데이터를 분석하고 예측하기 위한 딥러닝 모델입니다. 기존 일반적인 시계열 모델이 금융 데이터의 특성을 반영하지 못하는 문제를 해결하기 위해, 캔들스틱 데이터를 이산 토큰으로 변환한 뒤 트랜스포머 모델로 학습시킵니다. 사용자는 파이썬 환경에서 사전 학습된 모델과 예측 도구를 불러와 과거 주가 데이터를 입력하고 향후 가격 변동을 예측할 수 있습니다.

## 주요 기능
- 토큰화 처리: 연속적인 다차원 K라인 데이터(OHLCV)를 계층적 이산 토큰으로 변환합니다.
- 다양한 모델 크기 제공: 연산 능력과 용도에 맞춰 4.1M부터 499.2M 파라미터까지 선택할 수 있습니다.
- 간편한 예측 파이프라인: KronosPredictor 클래스를 통해 데이터 전처리부터 정규화, 예측까지 몇 줄의 코드로 처리합니다.
- 확률적 예측 지원: 샘플링 온도와 누적 확률 값을 조절하여 다양한 시나리오의 예측 경로를 생성할 수 있습니다.
- 배치 예측 지원: 여러 시계열 데이터를 동시에 병렬로 처리하여 효율적으로 예측 결과를 얻을 수 있습니다.
- 미세 조정 가능: 제공되는 스크립트를 활용해 사용자의 고유한 금융 예측 작업에 맞게 모델을 추가 학습할 수 있습니다.

## 참고·주의
- Python 3.10 이상 버전이 필요합니다.
- Kronos-small 및 Kronos-base 모델의 최대 입력 컨텍스트 길이는 512입니다.

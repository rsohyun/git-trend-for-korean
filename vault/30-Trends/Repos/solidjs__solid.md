# solidjs/solid

> 가상 DOM 없이 실제 DOM을 직접 조작해 빠르고 효율적으로 웹 사용자 인터페이스를 만들 수 있는 자바스크립트 라이브러리입니다.

## 개요
가상 DOM 비교 과정 없이 컴포넌트를 한 번만 실행하고 상태 변화에 반응하는 부분만 직접 갱신하는 자바스크립트 라이브러리입니다. 기존 프레임워크에서 전체 화면이 다시 그려지면서 발생하는 성능 저하 문제를 해결합니다. 사용자는 템플릿 프로젝트를 내려받거나 기존 프로젝트에 설치한 뒤 상태를 선언하는 방식으로 화면을 구현합니다. 빌드 시점에 JSX를 실제 DOM 조작 코드로 변환하여 매우 빠른 속도로 동작합니다.

## 주요 기능
- 실제 DOM 세밀한 갱신: 가상 DOM 비교 없이 상태가 바뀐 부분의 실제 DOM만 직접 수정합니다.
- 렌더-오번스 컴포넌트: 컴포넌트 함수가 한 번만 실행되고, 이후에는 각 표현식 단위로 반응성이 유지됩니다.
- 자동 의존성 추적: 반응형 상태를 읽는 코드만 자동으로 감지하여 구독 관계를 맺습니다.
- 비동기 및 스트리밍 지원: 비동기 데이터 처리와 스트리밍 방식의 서버 렌더링을 기본으로 지원합니다.
- 타입스크립트 및 JSX 우선 지원: 타입스크립트와 JSX 환경에서 편리하게 개발할 수 있습니다.

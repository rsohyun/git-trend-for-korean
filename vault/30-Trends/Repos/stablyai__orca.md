# stablyai/orca

> Orca는 여러 코딩 AI 에이전트를 한 곳에서 실행·관리해 주는 AI 오케스트레이터입니다.

## 개요
Orca는 Codex, ClaudeCode 등 다양한 코딩 에이전트를 데스크톱, 모바일, 원격 환경에서 동시에 사용할 수 있게 해 줍니다. 각 에이전트를 독립된 git worktree에 배치해 결과를 비교·병합함으로써 멀티‑에이전트 작업의 복잡성을 낮춥니다. 앱을 설치하고 계정을 연결하면 에이전트를 선택·실행하고, 모바일 앱으로 진행 상황을 모니터링하거나 SSH를 통해 원격 박스에서 작업할 수 있습니다. 내부적으로는 각 worktree을 별도 프로세스로 관리하고, CLI를 통해 스크립트화된 워크플로도 지원합니다.

## 주요 기능
- Mobile Companion: 스마트폰에서 에이전트 진행 상황을 확인하고 응답을 보낼 수 있습니다.
- Parallel Worktrees: 하나의 프롬프트를 여러 에이전트에 동시에 보내고 결과를 비교·병합할 수 있습니다.
- Terminal Splits: 무제한 분할 터미널을 제공해 작업 중에도 명령을 지속적으로 실행할 수 있습니다.
- Design Mode: 브라우저 UI 요소를 클릭하면 HTML·CSS·스크린샷을 에이전트 프롬프트에 바로 전달합니다.
- SSH Worktrees: 원격 서버에 에이전트를 배치하고 파일 편집·터미널을 로컬처럼 사용할 수 있습니다.

## 참고·주의
- macOS, Windows, Linux 중 하나의 운영체제가 필요합니다.
- 코딩 에이전트를 사용하려면 해당 서비스의 구독이 필요합니다.
- 원격 SSH 작업을 위해 별도 서버와 네트워크 접근 권한이 필요합니다.

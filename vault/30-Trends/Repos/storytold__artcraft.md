# storytold/artcraft

> 아티스트와 디자이너가 AI 이미지와 영상을 2D와 3D 공간에서 정밀하게 제작할 수 있는 통합 개발 환경(IDE)입니다.

## 개요
인공지능(AI)을 활용해 이미지와 영상을 만들 때 텍스트 명령만으로는 구도를 정확히 제어하기 어려운 문제를 해결합니다. 사용자는 2D 레이어 편집과 3D 가상 공간 배치를 활용해 원하는 장면을 직접 구성한 뒤 AI 생성 결과를 얻을 수 있습니다. 익숙한 시각 도구를 사용해 구도와 캐릭터 포즈를 정교하게 통제하면서 원하는 결과물을 반복해서 만들어 낼 수 있습니다.

## 주요 기능
- Image to Location: 가상 배우를 일관된 환경에 배치하고 같은 방에서 여러 샷을 계획할 수 있습니다.
- 3D Image Compositing: 배경, 전경, 소품을 3D로 겹쳐 깊이감이 있는 구도를 만들 수 있습니다.
- 2D Image Compositing: 이미지 레이어, 배경 제거, 드로잉 도구로 장면에 요소를 조합할 수 있습니다.
- Image to 3D Mesh: 이미지를 3D 객체로 변환하여 위치를 잡고 회전하며 정확히 프레임을 맞출 수 있습니다.
- Character Posing: 캐릭터의 포즈를 잡고 최종 샷을 생성하기 전에 카메라를 설정할 수 있습니다.

# storytold/craft-anything

> 웹사이트, 앱, 게임 등의 작동 방식을 분석하고 AI 코딩 에이전트를 통해 자신만의 버전을 새로 만들어 주는 오픈소스 프로그램입니다.

## 개요
기존 소프트웨어나 웹사이트가 어떻게 구현되었는지 파악하기 어려운 불편을 해결합니다. 사용자가 분석할 대상을 지정하고 원하는 바를 입력하면, 프로그램이 원본을 조사한 뒤 AI 에이전트를 통해 새로운 프로젝트를 구축하고 원본과 비교해 완성도를 높여 줍니다. 순수 러스트(Rust) 언어로 작성되었으며, 맥OS, 윈도우, 리눅스, FreeBSD, 웹 환경을 지원합니다.

## 주요 기능
- 원본 분석: 웹사이트, 데스크톱 앱, 모바일 앱, 게임, 파일 등의 구조와 작동 방식을 실제 검사 도구로 파악합니다.
- 나만의 버전 제작: 원하는 대상을 지정해 요청하면 코딩 에이전트가 지정한 기술 스택으로 새로운 프로젝트를 구축합니다.
- 결과 검증 및 개선: 제작된 결과물을 원본과 비교하여 일치하지 않는 부분을 확인하고 완성될 때까지 정교하게 다듬습니다.
- 두 가지 사용 모드: 간편하게 목표만 입력하는 일반 모드와 세부 도구를 직접 다루는 고급 작업대 모드를 제공합니다.
- 에이전트 연동: 300개가 넘는 내장 도구를 통해 외부 AI 에이전트가 동일한 엔진을 제어할 수 있습니다.

## 참고·주의
- 초기 알파(early alpha) 단계의 프로그램입니다.
- AI 에이전트 기능을 사용하려면 컴퓨터에 Claude Code 등 지원되는 코딩 에이전트가 준비되어 있어야 합니다.

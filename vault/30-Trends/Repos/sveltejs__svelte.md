# sveltejs/svelte

> 작성한 컴포넌트를 효율적인 자바스크립트로 바꿔 웹 화면을 빠르게 갱신해 주는 웹 애플리케이션 개발 프레임워크입니다.

## 개요
웹 페이지를 만들 때 화면에 나타나는 요소를 선언형 컴포넌트로 쉽게 구현할 수 있게 돕는 도구입니다. 기존 방식과 달리 브라우저가 직접 무거운 작업을 처리하지 않고, 코드를 미리 최적화된 자바스크립트로 변환하여 화면을 효율적으로 갱신하는 문제를 해결합니다. 사용자는 웹 컴포넌트 코드를 작성하고 컴파일 과정을 거쳐 가볍고 빠른 웹 애플리케이션을 완성할 수 있습니다.

## 주요 기능
- 컴파일 기반 동작: 작성한 컴포넌트를 브라우저가 실행하기 좋은 효율적인 자바스크립트 코드로 미리 변환합니다.
- 선언형 컴포넌트: 직관적인 코드로 웹 화면의 구성 요소를 간편하게 만들 수 있습니다.
- 효율적인 화면 갱신: 웹 페이지에서 변경된 부분만 정확하게 골라서 빠르게 업데이트합니다.

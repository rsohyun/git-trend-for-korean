# t8y2/dbx

> 100개가 넘는 데이터베이스를 25MB의 가벼운 용량으로 관리하고 인공지능과 연동할 수 있는 통합 데이터베이스 클라이언트입니다.

## 개요
MySQL, PostgreSQL, Redis 등 백여 가지 데이터베이스를 하나의 프로그램에서 가볍고 빠르게 관리할 수 있도록 돕는 도구입니다. 여러 데이터베이스를 관리할 때 도구를 각각 띄워야 하는 번거로움을 해결해 줍니다. 설치 후 실행하면 데스크톱 앱, 도커(Docker), 명령줄 환경 등 원하는 방식을 골라 데이터베이스에 접속하고 관리할 수 있습니다.

## 주요 기능
- 다양한 데이터베이스 지원: MySQL, PostgreSQL, SQLite, Redis, MongoDB, DuckDB 등 100개가 넘는 데이터베이스에 접속할 수 있습니다.
- 가벼운 용량: 25MB의 가벼운 크기로 컴퓨터 자원을 적게 차지하며 빠르게 실행됩니다.
- 다양한 실행 환경: 데스크톱 앱뿐만 아니라 도커, 명령줄 환경 등 다양한 형태로 실행할 수 있습니다.
- 내장 AI 어시스턴트: 인공지능 비서를 활용해 데이터베이스 관련 작업을 더 쉽게 처리할 수 있습니다.
- MCP 서버 지원: AI 에이전트가 외부 도구를 호출하는 표준 방식인 MCP 서버 기능을 기본으로 제공합니다.

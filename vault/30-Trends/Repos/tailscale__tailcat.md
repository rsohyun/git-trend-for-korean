# tailscale/tailcat

> Tailscale의 내부 통신 기술을 활용해 계정이나 설정 없이 두 기기를 안전하게 연결하는 네트워크 도구입니다.

## 개요
테일스케일(Tailscale)의 암호화 및 통신 기술을 활용하여, 계정 가입이나 복잡한 라우팅 설정 없이 기기 간에 파일을 주고받거나 포트를 연결할 수 있는 도구입니다. 기존 테일스케일 계정이나 중앙 제어 서버 없이도 안전한 터널을 만들 수 있어 연결 과정이 번거롭다는 문제를 해결합니다. 서버 측에서 프로그램을 실행해 주소를 얻은 뒤 클라이언트 측에 입력하면, 두 기기 사이의 모든 트래픽이 암호화되어 직접 연결됩니다.

## 주요 기능
- 표준 입출력 연결: 두 기기 사이에서 명령어나 텍스트, 파일을 주고받을 수 있습니다.
- 로컬 포트 공유: 서버의 로컬 포트를 클라이언트가 원격으로 접근할 수 있게 열어줄 수 있습니다.
- SSH 서버 실행: 공개키 인증이나 GitHub 계정 연동을 지원하는 안전한 SSH 서버를 열 수 있습니다.
- 웹 브라우저 연동: 원격에 있는 웹 서버 화면을 로컬 브라우저로 바로 띄워 확인할 수 있습니다.
- 웹 기반 데모: 별도 설치 없이 브라우저에서 바로 파일을 주고받는 웹 버전을 지원합니다.

## 참고·주의
- 웹 브라우저 데모(WASM)는 WebRTC 지원 전까지 DERP 중계 서버를 통해서만 트래픽이 전달됩니다.
- SSH 서버를 인증 없이 실행하려면 명시적으로 관련 옵션을 지정해야 합니다.

# tashfeenahmed/freellmapi

> 수십 개의 무료 인공지능(AI) 제공 업체의 무료 사용량을 하나로 모아 오픈AI 호환 API로 쓸 수 있게 해 주는 도구입니다.

## 개요
다양한 AI 서비스의 무료 등급을 수작업으로 연동해야 하는 불편함을 해결합니다. 34개의 무료 제공 업체와 635개의 모델 엔드포인트를 단일 API 주소 뒤로 통합해 줍니다. 사용자는 오픈AI 클라이언트 설정을 이 도구의 로컬 서버로 향하게 하고, 라우터가 최적의 모델을 자동으로 선택하여 요청을 처리하게 합니다.

## 주요 기능
- 스마트 라우팅: 요청에 가장 적합한 모델을 자동으로 선택합니다.
- 자동 장애 조치(Failover): 특정 제공 업체의 요청 제한에 걸리면 다음 제공 업체로 즉시 전환합니다.
- 사용량 추적: 각 키의 사용량을 추적하여 무료 사용량 한도를 초과하지 않도록 관리합니다.
- 암호화된 키 저장: 사용자의 API 키를 안전하게 암호화하여 보관합니다.
- 오픈AI 호환: 오픈AI 클라이언트 라이브러리와 완벽하게 호환되는 단일 엔드포인트를 제공합니다.

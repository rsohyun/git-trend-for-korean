# tester-army/e2e

> 자연어 명령으로 웹과 모바일 앱의 테스트를 자동화하고 AI 호출 비용을 줄여 주는 차세대 E2E(전 과정) 테스트 프레임워크입니다.

## 개요
웹과 모바일 앱에서 사람이 직접 하던 화면 테스트 과정을 AI 에이전트가 대신 수행해 주는 도구입니다. 테스트 유지보수가 어렵고 코드가 복잡해지는 기존 테스트 방식의 불편함을 해결합니다. 사용자가 테스트 코드에 자연어로 목표를 적고 실행하면, AI가 앱을 조작한 뒤 결과를 기록하고 다음 실행부터는 AI 호출 없이 빠르게 테스트를 반복합니다.

## 주요 기능
- 자연어 테스트: 사람이 읽는 문장만으로 앱 조작과 결과 검증을 수행할 수 있습니다.
- 테스트 자동 재생: AI가 한 번 수행한 조작을 기록해 두었다가 다음 실행에는 AI 호출 없이 바로 재생합니다.
- 웹 및 모바일 지원: Chromium, Firefox, WebKit 브라우저와 iOS, Android 기기 시뮬레이터를 모두 지원합니다.
- AI 모델 선택: 사용 중인 구독 계정, API 키, 또는 로컬 모델을 직접 연결해 사용할 수 있습니다.
- 영향도 분석: 풀 리퀘스트 변경 사항과 연관된 테스트만 골라서 실행할 수 있습니다.

## 참고·주의
- 사용하려면 별도의 AI 모델 구독이나 API 키, 또는 로컬 모델이 필요합니다.

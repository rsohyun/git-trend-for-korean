# thedotmack/claude-mem

> Claude-Mem은 AI 에이전트가 세션을 종료해도 작업 기록을 자동으로 저장·압축·재활용해 지속적인 컨텍스트를 제공하는 도구입니다.

## 개요
Claude-Mem은 에이전트가 수행한 도구 사용 기록을 실시간으로 캡처하고 AI 기반 요약으로 압축합니다. 이렇게 만든 요약을 다음 세션에 자동으로 주입해 프로젝트 지식이 사라지는 문제를 해결합니다. 사용자는 npx 명령으로 설치하고 브라우저 로그인으로 메모리 키를 발급받아 실행하면, 이후 에이전트가 자동으로 컨텍스트를 유지합니다. 로컬 관찰자와 클라우드 제공자를 선택해 유연하게 운영할 수 있습니다.

## 주요 기능
- 자동 기록 캡처: 에이전트가 사용한 도구와 관찰을 실시간으로 로그에 저장합니다.
- AI 요약 압축: 수집된 로그를 의미론적 요약으로 압축해 저장 용량을 최소화합니다.
- 컨텍스트 재주입: 압축된 요약을 다음 세션에 자동으로 제공해 연속적인 작업 흐름을 유지합니다.
- 다중 제공자 지원: 클라우드 메모리(CMEM Pro), OpenRouter, Gemini, Anthropic 등 다양한 백엔드를 선택할 수 있습니다.
- Awareness Push 파일: 중요한 결정·버그·보안 알림을 날짜와 태그로 기록해 프로젝트 메모에 강조합니다.
- IDE/플랫폼 통합: Claude Code, OpenCode, T3 Code, Grok Bot 등 여러 개발 환경에 플러그인 형태로 쉽게 연결됩니다.

## 참고·주의
- Node.js 20 이상이 필요합니다.
- 클라우드 메모리를 사용하려면 Anthropic·OpenRouter·Gemini 등 API 키가 필요할 수 있습니다.
- 무료 체험은 30일이며, 이후에는 사용량이 Anthropic 플랜에 따라 과금됩니다.
- CI·비대화형 환경에서는 로그인 없이 --provider 옵션으로 로컬 모드만 사용할 수 있습니다.

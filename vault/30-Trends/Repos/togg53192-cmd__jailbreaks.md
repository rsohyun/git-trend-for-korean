# togg53192-cmd/jailbreaks

> 다양한 LLM 모델용 시스템 프롬프트와 에이전트 설정을 바로 복사해 사용할 수 있게 제공하는 컬렉션입니다.

## 개요
이 저장소는 26개 이상 모델을 대상으로 32개의 완전한 프롬프트와 AGENTS.md, Ollama Modelfile 등을 모아 둔 자료집입니다. 프롬프트를 직접 작성하거나 실험할 때 발생하는 호환성·버전 문제를 해결하고, 바로 적용 가능한 형태로 제공합니다. 사용자는 원하는 파일을 복사해 클라이언트의 system‑prompt, AGENTS.md, 혹은 Ollama create 명령에 붙여넣기만 하면 됩니다. 각 파일은 모델별 운영 정책이나 워크스페이스 지시문을 포함해 즉시 활용할 수 있습니다.

## 주요 기능
- 완전 프롬프트 제공: 복사‑붙여넣기만으로 시스템 프롬프트를 설정할 수 있습니다.
- 다양한 모델 지원: Open‑weight, 프론티어, 무료 스텔스 모델 등 26개 이상 모델에 맞춘 프롬프트가 포함됩니다.
- AGENTS.md 파일: 프로젝트 수준 지시문으로 저장해 코딩 에이전트와 연동할 수 있습니다.
- Ollama Modelfile: Ollama에서 직접 모델을 생성하도록 `FROM`·`SYSTEM` 블록을 제공합니다.
- 워크스페이스 정책: 지속적인 전역 지시를 위한 운영 프로파일 파일을 제공합니다.
- 기여 가이드: PR 규칙과 버전 관리 방식을 명시해 커뮤니티 확장을 용이하게 합니다.

## 참고·주의
- 연구·교육 목적 외 사용은 금지됩니다.
- 프롬프트 적용 시 모델 제공자의 이용 약관을 위반할 수 있습니다.
- 모델 버전이 바뀌면 동작이 달라질 수 있어 최신 버전을 확인해야 합니다.

# tokio-rs/topcoat

> 러스트 언어로 웹 애플리케이션의 전체 스택을 손쉽게 구축할 수 있게 해 주는 모듈형 프레임워크입니다.

## 개요
러스트 기반으로 웹 서비스의 서버와 클라이언트 기능을 한 번에 개발할 수 있는 풀스택 도구입니다. 별도의 API 계층을 따로 만들거나 복잡한 설정 없이, 서버에서 데이터를 직접 조회하며 웹 페이지를 구성할 수 있는 편리함을 제공합니다. 사용자는 프로젝트를 생성하고 코드를 작성한 뒤 개발 서버를 실행하여 웹 앱을 서비스할 수 있습니다. 웹소켓이나 복잡한 빌드 도구 없이 브라우저와 서버 간 상호작용을 처리합니다.

## 주요 기능
- 클라이언트 반응성: 서버에서 렌더링된 화면 속 코드를 자바스크립트로 자동 변환하여 브라우저에서 즉시 실행합니다.
- 모듈 기반 라우팅: 프로젝트 디렉토리와 파일 구조에 맞춰 URL 경로와 라우트를 자동으로 구성합니다.
- HTML 템플릿: 친숙한 러스트 문법과 제어 흐름을 HTML 안에서 그대로 사용할 수 있습니다.
- 수정 가능한 컴포넌트: 미리 만들어진 UI 요소를 프로젝트에 복사해 오므로 디자인과 기능을 자유롭게 바꿀 수 있습니다.
- 에셋 번들링: 코드 내에 포함된 정적 파일을 자동으로 감지하여 최적화된 상태로 제공합니다.

## 참고·주의

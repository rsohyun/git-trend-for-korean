# tradermonty/claude-trading-skills

> 시간이 부족한 개인 투자자가 AI를 활용해 시장 분석, 위험 관리, 매매 일지 작성 등 투자 의사결정 과정을 체계적으로 관리할 수 있게 해 주는 도구 모음입니다.

## 개요
개인 투자자가 매번 감정에 치우치거나 복잡한 자료를 정리하느라 겪는 시간 부족과 분석 누락 문제를 해결해 줍니다. 시장 동향 점검, 포트폴리오 검토, 종목 발굴, 매매 일지 작성 등의 작업 순서를 AI가 단계별로 안내합니다. 사용자는 제공되는 작업 지침과 예시에 따라 시장 데이터를 입력하고, AI의 분석과 위험 관리 지침을 받아 투자 결정을 스스로 검토합니다. 복잡한 유료 데이터 연동 없이 공개된 파일이나 화면 캡처만으로도 주요 기능을 바로 실행할 수 있습니다.

## 주요 기능
- 시장 동향 분석: 공개 데이터나 CSV 파일을 바탕으로 현재 시장의 상승 흐름과 위험 수준을 점검합니다.
- 포트폴리오 검토: 장기 투자 자산과 배당주 보유 현황을 주기적으로 점검하고 관리합니다.
- 종목 발굴: 정해진 위험 기준과 조건에 맞춰 스윙 투자 후보 종목을 찾습니다.
- 포지션 규모 계산: 계좌 상황에 맞춰 매매할 적정 투자 금액과 위험 범위를 계산합니다.
- 매매 일지 및 복기: 완료된 거래 기록을 바탕으로 실수를 분석하고 다음 투자 원칙을 보완합니다.

## 참고·주의
- 이 도구는 자동 매매 프로그램이나 투자 자문 서비스가 아니며 모든 매매 판단의 책임은 사용자에게 있습니다.
- 일부 고급 기능은 Alpaca나 FMP 같은 외부 유료 데이터 API 연동이 필요할 수 있습니다.

# unclebob/ub-mode

> 코드 작성·수정 시 엄격한 소프트웨어 엔지니어링 원칙을 자동으로 적용해 주는 AI 에이전트 스킬입니다.

## 개요
ub-mode는 AI 에이전트용 스킬로, 코드가 동작하도록 만들고, 올바르게 유지하도록 돕습니다. 작동 보장, 품질 보증, 실천 단계의 원칙을 정형화해 코드 복잡도·중복·테스트 부족을 방지합니다. 사용자는 SKILL.md 파일을 에이전트의 스킬 디렉터리에 복사하고, 에이전트에서 `/ub-mode` 명령을 호출하면 적용됩니다. 스킬은 crapper, dryer, mutator 등 외부 품질‑게이트 도구와 연동해 CRAP 점수·중복·돌연변이 테스트 결과를 검증합니다.

## 주요 기능
- 원칙 기반 가이드: ‘먼저 작동하게 만들고, 그 다음 올바르게 만들기’ 단계별 원칙을 자동으로 적용합니다.
- 품질 게이트 연동: CRAP 점수, 코드 중복, 돌연변이 테스트 결과를 실시간으로 확인하고 기준을 초과하면 경고합니다.
- 리팩터링 지원: 루트 원인 수정, 테스트 중심 검증, 불필요한 코드 삭제를 권장합니다.
- 작업 로그 및 정리: 컨텍스트 창 보호, 작업 트리 정리, 작은 순서형 커밋을 자동으로 유도합니다.
- 시각화 연동: UML‑viewer와 연동해 컴포넌트, 커버리지, 의존성 등을 시각적으로 보여줍니다.

## 참고·주의
- AI 에이전트가 SKILL.md 형식의 스킬을 로드할 수 있어야 합니다.
- crapper, dryer, mutator 등 연동 도구가 별도로 설치되어 있어야 정상 동작합니다.
- 품질 기준(CRAP <10, 중복 <0.8 등)은 도구 설정에 따라 달라질 수 있습니다.

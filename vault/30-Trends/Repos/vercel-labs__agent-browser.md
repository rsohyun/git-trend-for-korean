# vercel-labs/agent-browser

> AI 에이전트가 셸 명령어로 웹 브라우저를 조작하여 페이지를 읽고 행동할 수 있게 해 주는 브라우저 자동화 도구입니다.

## 개요
인공지능(AI) 에이전트가 웹 브라우저를 직접 제어하지 못하는 불편을 해결하는 도구입니다. 명령어 기반으로 웹페이지를 간결한 텍스트로 읽어오고 요소를 지정해 클릭이나 입력 등의 행동을 수행할 수 있습니다. 사용자는 터미널에서 명령어를 입력해 브라우저를 열고 페이지 상태를 확인하며 자동화 작업을 진행합니다. 백그라운드 프로세스가 브라우저를 유지하여 각 단계를 빠르게 실행할 수 있습니다.

## 주요 기능
- 페이지 스냅샷: 웹페이지를 요소마다 고유 번호가 부여된 간결한 텍스트로 변환합니다.
- 요소 상호작용: 번호나 선택자를 이용해 클릭, 입력, 호버 등의 동작을 수행합니다.
- 다양한 브라우저 지원: 기본 크롬 외에도 라이트판다, 모바일 사파리, 클라우드 브라우저 등을 연결할 수 있습니다.
- 에이전트 스킬 연동: AI 에이전트가 올바른 명령어를 사용할 수 있도록 가이드와 스킬을 제공합니다.

## 참고·주의
- 리눅스 환경에서는 브라우저 구동을 위한 시스템 라이브러리를 추가로 설치해야 할 수 있습니다.

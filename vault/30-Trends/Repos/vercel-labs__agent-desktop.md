# vercel-labs/agent-desktop

> Agent Desktop은 AI 에이전트가 OS 접근성 트리를 통해 데스크톱 앱을 신뢰성 있게 읽고 조작할 수 있게 해 주는 도구입니다.

## 개요
이 도구는 화면 픽셀 매칭 대신 접근성 트리를 사용해 UI 요소의 구조와 고유 ref를 제공합니다. 이를 통해 에이전트는 ref 기반으로 클릭·타입·스크롤 등을 수행하고, 다시 스냅샷을 받아 동작 결과를 검증할 수 있습니다. npm으로 설치하거나 네이티브 바이너리를 다운로드한 뒤, `agent-desktop snapshot`으로 UI를 관찰하고 `agent-desktop click @ref` 등으로 조작하면 됩니다. 각 명령은 JSON 형태로 결과와 오류 정보를 반환합니다.

## 주요 기능
- 접근성 트리 스냅샷: UI 구조와 고유 ref를 JSON으로 제공해 픽셀 의존 없이 요소를 식별합니다.
- ref 기반 액션: 클릭·타입·스크롤 등 56개의 명령을 ref에 적용하고, 실패 시 안전하게 재시도합니다.
- 헤드리스 모드: 물리적인 마우스 이동이나 포커스 없이 접근성 API만으로 동작합니다.
- 크로스 플랫폼 지원: macOS, Windows, Linux에서 동일한 CLI와 API를 사용할 수 있습니다.
- 언어 바인딩 제공: libagent_desktop_ffi를 통해 프로세스 내에서 직접 호출할 수 있습니다.
- 세션·디버깅 도구: 스크린샷, 클립보드, 로그 등 다양한 디버그 정보를 출력합니다.

## 참고·주의
- macOS에서는 접근성 권한을 부여해야 합니다.
- Linux에서는 그래픽 세션과 at-spi2-core가 필요합니다.
- 스냅샷·클립보드·스크린샷에 개인 정보가 포함될 수 있어 로그를 외부에 공개하면 안 됩니다.

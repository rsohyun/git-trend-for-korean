# vshulcz/deja-vu

> 다양한 AI 코딩 도구의 대화 기록과 작업 내역을 로컬에 통합 저장하고 검색하여, 이전에 해결했던 문제를 다시 디버깅하지 않도록 돕는 도구입니다.

## 개요
여러 AI 코딩 에이전트가 생성하는 대화와 코드 수정 이력이 흩어지는 문제를 해결합니다. 로컬에 설치하여 실행하면 43개 이상의 AI 에이전트가 남긴 세션 기록을 자동으로 색인하고 MCP(AI 에이전트가 외부 도구를 호출하는 표준 방식)와 훅을 통해 필요한 과거 기록을 다시 불러옵니다. 사용자는 터미널이나 브라우저에서 지난 작업 내용을 검색하거나 다른 에이전트로 이어갈 수 있습니다.

## 주요 기능
- 통합 검색: 43개 이상의 AI 코딩 에이전트가 남긴 지난 대화와 세션 기록을 한곳에서 검색할 수 있습니다.
- 자동 기억 불러오기: MCP와 훅을 통해 코딩을 시작하거나 명령이 실패할 때 연관된 과거 해결 기록을 자동으로 보여줍니다.
- 코드 변경 사항 추적: 단순한 대화뿐만 아니라 열었던 파일, 실행한 명령어, 정확한 코드 수정 범위까지 함께 기록합니다.
- 에이전트 간 전환 및 이어하기: 한 에이전트에서 진행하던 작업의 목표와 결정 사항을 다른 에이전트로 넘겨서 계속 진행할 수 있습니다.
- 삭제된 채팅 복구: 에이전트가 지운 세션 기록까지 보관하고 있다가 필요할 때 다시 복구할 수 있습니다.
- 로컬 보안 중심: 별도의 클라우드 계정이나 대규모 언어 모델 호출 없이 로컬 환경에서만 동작하며 민감한 자격 증명을 자동으로 가려줍니다.

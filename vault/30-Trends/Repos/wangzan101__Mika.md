# wangzan101/Mika

> Android 기기에서 음성이나 텍스트 한 줄로 명령하면 앱과 웹을 자동으로 조작해 작업을 완료해 주는 AI 비서입니다.

## 개요
Mika는 Android 스마트폰에 설치해 사용하는 AI 비서입니다. 사용자가 한 문장으로 요구하면 화면을 별도 배경 화면에서 조작해 앱 클릭·입력·스크롤 등을 자동으로 수행해 수작업을 없앱니다. APK를 설치하고 모델 API 키를 연결하거나 ChatGPT·xAI·OpenRouter 계정으로 로그인한 뒤, 설정 마법사로 전화 디버깅을 연결하면 바로 사용할 수 있습니다. 명령을 내리면 AI가 작업을 진행하고 완료되면 결과를 보고하거나 중간에 중단·수정도 가능합니다.

## 주요 기능
- 앱 자동 조작: 화면을 인식해 버튼을 찾고 탭·입력·스크롤을 수행해 메시지 전송·상품 구매·채팅 요약 등을 할 수 있습니다.
- 웹 브라우징: 내장 브라우저에서 페이지를 읽고 검색·다운로드·업로드 등을 수행하며 결과를 요약해 줍니다.
- 일정·조건 실행: 알람 설정·정기 알림·조건부 작업을 대화 중에 지정하면 지정된 시간에 자동으로 실행됩니다.
- 음성 입력 및 대화: 길게 눌러 말하면 음성 인식으로 텍스트를 편집해 전송하고, 대화 중에도 작업을 추가·수정할 수 있습니다.
- 파일·코드 실행: 대화에 첨부한 파일을 Linux 샌드박스에서 Python·Node·쉘 스크립트로 실행해 결과를 반환합니다.
- 컴퓨터 연동: CLI와 Skill/MCP를 이용해 PC에서 Mika에게 작업을 전달하고 제어할 수 있습니다.

## 참고·주의
- Android 11 이상이 필요합니다.
- AI 모델을 사용하려면 모델 제공자의 API 키 또는 ChatGPT·xAI·OpenRouter 계정이 필요합니다.
- 앱 자동 조작 기능을 사용하려면 무선 디버깅을 한 번 연결해야 합니다.
- 모델 호출은 인터넷 연결이 필요하며, 결제·구매와 같은 작업은 사전에 확인이 필요합니다.

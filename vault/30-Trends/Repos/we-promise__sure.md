# we-promise/sure

> 자신의 자산과 현금 흐름을 한눈에 관리하고 AI 비서와 상담할 수 있는 개인 자산 관리 프로그램입니다.

## 개요
중단된 오픈소스 자산 관리 프로젝트인 Maybe Finance를 커뮤니티에서 이어받아 개발하는 개인 자산 관리 도구입니다. 복잡한 자산 상태와 지출 내역을 한곳에서 파악하지 못하는 문제를 해결합니다. 도커(Docker)를 이용해 직접 서버에 설치한 뒤 웹 브라우저나 데스크톱·모바일 앱으로 접속하여 자산 대시보드와 AI 비서를 이용할 수 있습니다.

## 주요 기능
- 자산 관리 대시보드: 현금 흐름과 순자산, 지출 내역을 한눈에 확인할 수 있습니다.
- AI 비서 연동: 저축이나 자산에 관한 질문을 AI 비서에게 물어보고 답변을 얻을 수 있습니다.
- 멀티 플랫폼 지원: 웹 브라우저뿐만 아니라 맥OS, 모바일 앱, API 클라이언트 등으로 접속할 수 있습니다.
- 자가 호스팅: 도커를 활용해 사용자가 직접 서버에 프로그램을 설치하고 데이터를 관리할 수 있습니다.

## 참고·주의
- 서버에 직접 설치하여 운영하려면 도커 환경 설정이 필요합니다.

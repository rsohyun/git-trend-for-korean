# yetone/magpie

> 다양한 인공지능 에이전트와 모델을 하나의 메뉴 바 앱과 로컬 게이트웨이로 통합하여 자유롭게 연결하는 프로그램입니다.

## 개요
여러 인공지능 에이전트마다 흩어져 있는 설정과 API 키를 하나로 모아 관리하는 도구입니다. 에이전트마다 모델을 따로 설정해야 하거나 이용 한도가 초과되는 불편을 해결해 줍니다. 프로그램을 설치하고 제공자 계정을 연결한 뒤 사용할 모델을 선택하면 에이전트에 즉시 적용됩니다.

## 주요 기능
- 모델 연결 통합: 하나의 목록에서 원하는 인공지능 에이전트에 어떤 모델이든 연결할 수 있습니다.
- 계정 자동 전환: 이용 한도가 초과되면 다른 계정이나 제공자로 자동 전환되어 에이전트가 멈추지 않고 계속 작동합니다.
- 개인정보 보호: 설정에서 마스킹 기능을 켜면 프롬프트에 포함된 비밀번호나 이메일 등의 민감한 정보를 전송 전에 미리 가릴 수 있습니다.
- 명령어 제어: 메뉴 바뿐만 아니라 터미널 명령어를 통해 계정 관리나 모델 설정을 간편하게 바꿀 수 있습니다.

## 참고·주의
- 개인정보 마스킹 기능은 기본값으로 꺼져 있어 사용하려면 설정에서 직접 켜야 합니다.

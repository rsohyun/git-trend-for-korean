# zed-industries/zed

> 생각의 속도만큼 빠르게 코드를 작성할 수 있도록 돕는 고성능 다중 사용자 코드 편집기입니다.

## 개요
대규모 프로젝트에서도 끊김 없이 빠르게 코드를 작성할 수 있도록 돕는 고성능 코드 편집 프로그램입니다. 기존 편집기의 속도 저하와 협업 시 불편함을 해결해 줍니다. 프로그램을 설치한 뒤 소스 코드를 열어 일반 편집기처럼 바로 편집하고 협업 기능을 사용할 수 있습니다. 아톰(Atom)과 트리시터(Tree-sitter)의 개발진이 직접 만들어 뛰어난 성능을 제공합니다.

## 주요 기능
- 고성능 편집: 대용량 코드도 지연 없이 빠르게 읽고 수정할 수 있습니다.
- 다중 사용자 지원: 여러 사람이 동시에 접속해 코드를 함께 수정할 수 있습니다.
- 폭넓은 운영체제 지원: 맥OS, 리눅스, 윈도우 환경에 설치해 사용할 수 있습니다.

## 참고·주의
- 웹 버전은 아직 지원되지 않아 사용할 수 없습니다.

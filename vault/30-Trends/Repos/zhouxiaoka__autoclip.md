# zhouxiaoka/autoclip

> 긴 영상을 입력하면 AI가 자동으로 숏폼 영상, 자막, 썸네일, 홍보 문구를 만들어 주는 오픈소스 데스크톱 도구입니다.

## 개요
긴 인터뷰나 팟캐스트 영상을 직접 편집하고 자막을 달아야 하는 번거로움을 해결해 주는 프로그램입니다. 사용자가 영상 링크를 넣고 플랫폼을 선택하면, AI가 핵심 구간을 골라 숏폼 영상과 관련 자료를 자동으로 완성합니다. 결과물이 마음에 들지 않을 때는 내장된 편집기로 직접 세부 조정을 할 수 있습니다.

## 주요 기능
- 링크 기반 자동 편집: 영상 링크 하나만 입력하면 AI가 숏폼 영상을 자동으로 생성합니다.
- 플랫폼 맞춤 설정: 抖音, 小红书, TikTok, Reels, YouTube Shorts, B站 등 다양한 플랫폼에 맞게 영상을 제작합니다.
- 종합 콘텐츠 생성: 영상 편집뿐만 아니라 자막, 썸네일, 플랫폼별 게시용 문구까지 함께 만듭니다.
- 내장 편집기 제공: AI가 만든 결과물을 사용자가 직접 원하는 대로 수정할 수 있습니다.
